Тойм

ChatGPT-ийн Codex агентуудад Pi.mn-ийн нээлттэй цоорхойнуудыг (docs/PLATFORM-SPEC.html, G01–G41) засуулах бэлэн даалгаврууд. Даалгавар бүр яг ямар файлыг засахаа мэддэг тул олон агентыг зэрэг ажиллуулахад бие биеэ дарж бичихгүй.

Товчхондоо: 1) Codex-т репог холбоно. 2) Долгион 1-ийн 7 даалгавар тус бүрийн «Хуулах» товчийг дарж, тус тусдаа шинэ агентад буулгана. 3) Бүгд PR нээсний дараа холбоосуудыг Claude-д өгнө. 4) Claude нэгтгэсний дараа дараагийн долгион.

1. Хэрхэн ашиглах

Нэг удаагийн тохиргоо

  1. chatgpt.com/codex-ийг Safari-д нээж ChatGPT данснаараа нэвтэрнэ.
  2. GitHub-ийг холбоно (Connect GitHub) — mrbuus/Pi репод хандах эрх өгнө.
  3. Орчин (Environment) үүсгэнэ: репо mrbuus/Pi. Тохиргооны хэсэгт доорх setup script-ийг буулгана. Орчны хувьсагчид DATABASE_URL-ийг доорх хуурамч утгаар тавина (бодит өгөгдлийн сангийн хаягийг ХЭЗЭЭ Ч бүү оруул).
  4. Агентын интернэт хандалт: өгөгдмөлөөр хаалттай байж болно. G30 ба G32 даалгаварт шинэ сан суулгах тул тэр хоёрыг ажиллуулахдаа npm registry-г зөвшөөрнө (жишээ нь «Common dependencies» сонголт). Бусад даалгаварт хэрэггүй.

Codex-ийн товчнуудын нэр шинэчлэгдсэн байж болно — утгаараа ойролцоог нь сонго.



      
Долгион бүрийн ажил

      
    
        
  1. Даалгавар бүрт тусдаа шинэ task нээнэ. Branch сонгох газарт claude/100-dollar-credit-usage-ksqjev-ийг сонгоно — main БИШ. main руу орсон бүхнийг Render шууд продод гаргадаг тул алдаатай код сурагчдад хүрнэ.
    2. 
        
  2. Горимыг «Code» (кодчилох) болгоно — «Ask» биш.
    3. 
        
  3. Даалгаврын картын «Хуулах» товчийг дарна — нийтлэг контекст ба тухайн даалгавар хамт хуулагдана. Шууд буулгаад эхлүүлнэ.
    4. 
        
  4. Долгионы бүх даалгаврыг нэгэн зэрэг эхлүүлнэ (1-р долгион 7 агент). Хувилбарын тоог (attempts) 1 дээр үлдээ — шалгах PR цөөн байна.
    5. 
        
  5. Агент дуусмагц «Create PR» / «PR үүсгэх» дарна. GitHub дээр PR-ийн base нь claude/100-dollar-credit-usage-ksqjev эсэхийг шалгана; main байвал «Edit»-ээр солино.
    6. 
        
  6. Бүх PR нээгдсэний дараа холбоосуудыг 6-р хэсгийн загвараар Claude-д өгнө. Claude шалгаж, нэгтгэнэ. Та PR-ийг өөрөө бүү нэгтгэ.
    7. 
        
  7. Долгион нэгтгэгдсэний ДАРАА л дараагийн долгионыг эхлүүлнэ — шинэ агентууд шинэчлэгдсэн кодоос эхлэх ёстой.
    8. 
      


      
Яагаад долгион гэж хуваасан бэ?

      
Хоёр агент нэг файлыг зэрэг засвал хоёр дахь нь эхнийхийн ажлыг дарж бичнэ (2026-08-08-нд SMS модуль ингэж бүхэлдээ эвдэрсэн). Тиймээс нэг долгион доторх даалгаврууд огт давхцахгүй файлуудыг эзэмшдэг — «Файлын эзэмшил» хүснэгтээс харж болно. Дараагийн долгион өмнөхийн үр дүн дээр суурилдаг. 3-р долгион өгөгдлийн сангийн схемийг өөрчилдөг тул нэг нэгээр явна.

2. Эзний гараар хийх ажил (ChatGPT хийж чадахгүй)

      
Данс, төлбөр, нууц түлхүүр шаардсан ажил. Тэмдэглэсэн төлөв энэ хөтчид хадгалагдана.

      

    


    

      
3. Нийтлэг контекст

      
Агент бүрт даалгаврын өмнө өгөгдөнө. Даалгаврын «Хуулах» товч үүнийг автоматаар хамт хуулдаг — энд зөвхөн уншиж танилцах зорилготой.

      

      

    


    

      
4. Даалгаврууд

      
Карт бүрийг дэлгэхэд бүтэн prompt харагдана. «Хуулах» = нийтлэг контекст + тухайн даалгавар, нэг агентад. «Долгион бүхлээр хуулах» нь тэмдэглэлдээ хадгалах эсвэл Claude-д үзүүлэхэд — нэг агентад бүх долгионыг бүү өг.

      

    


    

      
5. Шалгагч агентын prompt (сонголттой)

      
Нэг PR-ийг тусдаа ChatGPT агентаар шалгуулах бол. Доорх хаалттай хэсгүүдийг бөглөнө. Энэ нь Claude-ийн шалгалтыг орлохгүй — нэмэлт давхарга.

      

      

    


    

      
6. Хариугаа Claude-д өгөх

      
Долгион дуусмагц PR-уудын холбоосыг энэ загвараар Claude-д илгээнэ.

      

      

    


    

      
7. Анхааруулга

      

        
    
          
  • Нэг файл дээр хоёр агентыг зэрэг бүү ажиллуул — долгионы хуваарийг л дага. Даалгаврыг өөрөө нийлүүлж, хувааж бүү өөрчил.
    • 
          
  • Агентыг main руу push хийлгэж, PR нээлгэж болохгүй — Render main-ийг шууд продод гаргадаг.
    • 
          
  • CI (GitHub-ийн шалгалт) улаан байгаа PR-ийг хэзээ ч бүү нэгтгэ. PR-ийг Claude шалгаж нэгтгэнэ.
    • 
          
  • Нууц үг, токен, API түлхүүр, продын өгөгдлийн сангийн хаягийг ChatGPT-д бүү буулга.
    • 
          
  • Сурагчдын мэдээлэлтэй xlsx файлыг (BURTGEL-2027-1.xlsx г.м.) ямар ч репод, ямар ч агентад бүү оруул.
    • 
          
  • Агентын «бүгд ногоон» гэсэн тайланг шууд бүү итгэ — өмнө нь хуурамч гаралт бичиж байсан. Claude давтан шалгана.
    • 
          
  • 3-р долгионыг нэг нэгээр: G25 нэгтгэгдсэний дараа G17, түүний дараа G27.
    • 
          
  • Вэб (Vercel) автоматаар шинэчлэгддэггүй — main руу орсны дараа Claude-д deploy хийлгэнэ.
