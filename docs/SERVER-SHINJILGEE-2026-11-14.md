## Хурд сайжруулах (үнэгүй, эрсдэл багатайгаас нь)

1. **nginx HTTP/2 асаах** — одоо HTTP/1.1. Нэг хуудас 30–40 жижиг файл татдаг тул утсан дээр мэдэгдэхүйц хурдасна. Нэг мөр тохиргоо.
2. **Статик файлыг nginx шууд өгөх** (`/_next/static`, `public/`) — одоо бүгд Node-оор дамждаг (өдөрт ~6 мянган хүсэлт).
3. **Cloudflare-ийн прокси (үнэгүй CDN)** — зураг, JS Монголд ойр серверээс очно; серверийн гарах урсгал багасна.
4. **Нүүр хуудасны том зураг**: `earth-blue-marble.webp` 598 КБ, «амжилт» хэсгийн 60 КБ-ын олон зураг — доош гүйлгэхэд л татдаг болгох.
5. **Сангийн бүтэн уншилт**: `TestProblem` хүснэгт 18 мянган удаа бүтнээр уншигдсан (нийт 229 сая мөр) — аль асуулга болохыг олж индекс нэмэх. `ClassSchedule`, `Classroom` олон дахин уншигддаг — санах ойд богино хугацаанд хадгалах.
6. `unread-count`, `presence`, `usage` — минут тутмын жижиг хүсэлтүүд нийт хүсэлтийн ~15%; давтамжийг сунгаж болно.
