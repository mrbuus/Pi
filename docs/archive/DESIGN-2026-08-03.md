# Pi.mn дизайны гэрээ

Энэ бол **заавал дагах** дүрэм. Хэд хэдэн хүн/агент зэрэг ажиллаж байгаа тул
хүн бүр өөрийн зөнгөөр шийдвэл 10 өөр дизайн гарна. Шинэ зүйл нэмэхээсээ өмнө
энэ файлыг уншина.

---

## 0. Таслахгүй дүрмүүд (эвдвэл ажил хүчингүй)

1. **Сүлжээнээс нэмэлт байт татахгүй.** Гадаад фонт, зураг, видео, WebGL,
   CDN, шинэ npm сан — бүгд ХОРИОТОЙ. Эффект бүр цэвэр CSS байна.
   *Шалтгаан: эзний шаардлага — интернэт удаан байхад UI муудах ёсгүй.*
2. **Функц устгахгүй.** Дизайн сайжруулна гэдэг нь юм хасна гэсэн үг биш.
   Товч, талбар, урсгал бүр хэвээр ажиллана.
3. **Өнгийг гараар бичихгүй.** `#fff`, `rgb(...)`, `text-blue-500` БОЛОХГҮЙ.
   Зөвхөн токен: `bg-surface`, `text-ink`, `border-line`, `text-brand-soft`,
   `bg-panel`, `text-ink-dim`, `success/warning/error/info`.
   Өнгөт дэвсгэр дээрх текст `text-on-brand` мэтийг хэрэглэнэ (`text-white` биш).
4. **`npx tsc --noEmit` цэвэр байж дуусна.** Алдаатай орхиж болохгүй.
5. **Зөвхөн өөрт оногдсон файлаа зас.** Өөр агентын файл руу оръё гэвэл
   бүү оруул — тайландаа бич.

---

## 1. Хэмнэл ба хөдөлгөөн

`globals.css`-д тодорхойлсон токен ашиглана — тоо гараар бичихгүй:

| Токен | Утга | Хэзээ |
|---|---|---|
| `--dur-micro` | 120ms | hover, дарах |
| `--dur-base` | 180ms | энгийн шилжилт |
| `--dur-enter` | 260ms | самбар нээгдэх |
| `--ease-out` | тайван гаралт | ихэнхдээ |
| `--ease-spring` | бага зэрэг үсэрнэ | popover нээгдэх |

Бэлэн анги: `.enter-fade` (агуулга гарч ирэх), `.enter-pop` (цонх нээгдэх),
`.value-bump` (тоо солигдох).

**Зөвхөн `transform` ба `opacity` дүрсжүүлнэ.** `width`, `height`, `top`,
`margin` дүрсжүүлбэл layout дахин тооцоологдож, урт жагсаалтад гацна.

---

## 2. Гүн (elevation)

| Анги | Хэрэглээ |
|---|---|
| хавтгай | жагсаалтын мөр, хүснэгтийн нүд |
| `.elev-1` | карт, самбар (тайван) |
| `.elev-2` | hover-т өргөгдсөн карт, dropdown |
| `.elev-3` | модал, popover |

Интерактив карт бүрд `.surface-interactive` нэмнэ — hover-т 1px өргөгдөж
сүүдэр нэмэгдэнэ. Жагсаалтын мөрд `.row-interactive` (сүүдэргүй, зөвхөн
дэвсгэр — 100 мөр зэрэг хөдөлбөл эвгүй).

---

## 3. Нягтрал

Мөрийн өндөр: `--row-compact` 28px · `--row-base` 32px · `--row-roomy` 38px.

- Өгөгдлийн хүснэгт, хуваарь, жагсаалт → **compact эсвэл base**
- Маягт, тохиргоо → roomy

Текст: `text-sm` үндсэн, `text-xs` туслах, `text-[11px]` шошго.
Гарчиг `font-bold`/`font-extrabold`, энгийн текст `font-normal`.

---

## 4. Хоосон ба ачаалж буй төлөв (удаан сүлжээнд ХАМГИЙН чухал)

**Хоосон цагаан дэлгэц хэзээ ч харуулахгүй.**

- Ачаалж байна → `.skeleton` ангиар бодит бүтцийн хэлбэрийг харуул
  (хүснэгт бол мөрүүд, карт бол картын хайрцаг). "Ачаалж байна…" гэсэн
  ганц мөр текст хангалтгүй.
- Өгөгдөл байхгүй → яагаад хоосон байгаа, юу хийвэл дүүрэхийг хэлсэн
  товч тайлбар + үйлдлийн товч.
- Алдаа → монголоор ойлгомжтой мессеж + "Дахин оролдох" товч.
  Техникийн англи алдаа хэрэглэгчид харуулахгүй.

---

## 4.5 Өгөгдлөөс ирдэг өнгө (анги, банк, шошго)

**Өгөгдлөөс ирдэг өнгийг ТЕКСТ дээр ХЭЗЭЭ Ч тавихгүй.**

`lib/classroomColor.ts`-ийн 13 өнгө нь **дэвсгэрт** зориулж сонгогдсон. Текст
болгоход зарим нь уншигдахгүй: `#42d4f4` цагаан дээр 1.6:1, `#3cb44b` 2.6:1,
`#f58231` 2.9:1 — бүгд WCAG AA (4.5:1)-аас доогуур. `text-ink` нь 16.4:1.

Өнгө зөвхөн эдгээр газарт гарна:

| Зөв | Буруу |
|---|---|
| зүүн зурвас (`border-left: 3px`) | `style={{ color }}` текст дээр |
| дугуй цэг / жижиг тэмдэг | дүрсийн `fill` эсвэл `stroke` |
| маш зөөлөн дэвсгэр (12–18%) | ханасан дэвсгэр дээр текст |

Бэлэн анги: `.class-row` (зурвас) + `.class-row-interactive` (hover/сонгогдсон
дэвсгэр). Өнгийг `style={{ "--cls": color } as React.CSSProperties}` -ээр өгнө.

Өнгө дангаараа мэдээлэл дамжуулахгүй (WCAG 1.4.1) — нэр эсвэл дүрс дагалдана.

## 4.6 Танхимын дүрс (`schedule/RoomShape.tsx`)

**БУДАЛТГҮЙ.** `fill="none"`, зөвхөн зураас. Эзний шаардлага: *«дүрсийг нь
будалгүй, хүн шууд хараад мэдэхээр ТОД»*. Жижиг хэмжээнд дүрсийн танигдах
чадвар **силуэтийн ирмэгээс** хамаардаг — дотоод будалт ирмэгийн контрастыг
бууруулж, квадрат/ромбо, трапец/гурвалжин хосыг ялгахад хүндрүүлдэг.

**Зураас нь `currentColor` (ink).** Ангийн өнгийг дүрс рүү дамжуулахгүй — цайвар
өнгө (жишээ `#42d4f4`) дээр дүрс бүдгэрнэ. Өнгө = мөрийн зурвас, дүрс = танхим.

Геометр 24×24 сүлжээнд, оптикоор ижил жинтэй болгож тааруулсан. Зураасны зузаан
`(24 / size) × strokePxFor(size)` — хэмжээ өөрчлөгдөхөд оптик зузаан тогтмол
үлдэнэ. Дүрсийг өөрчилвөл 16px дээр **8 дүрс бүгд ялгарч байгааг нүдээр шалга**.

## 4.7 Мета тусгаарлагч — `·` тэмдэгт ХОРИОТОЙ

Мета мэдээллийг зааглахдаа `·` (U+00B7) эсвэл `•`-ыг **гараар бичихгүй**.

Шалтгаан: эдгээр нь фонтын глиф. Фонт бүр өөр диаметр, өөр өндөрт зурдаг тул
зарим дэлгэцэнд бүдүүн толбо болно — эзний шүүмж: *«маш соёлгүй, сонин бүдүүн
хар цэг»*. Хэрэглэгчийн фонт солигдвол хянах аргагүй.

Оронд нь `components/ui/Meta.tsx`:

```tsx
<Meta items={[room, teacher, time]} />   // олон зүйл, null-ыг алгасна
<Dot />                                  // ганц тусгаарлагч
<MetaTitle>{test.title}</MetaTitle>      // ӨС-ээс ирсэн «А · Б» гарчиг
```

Цэгийг CSS зурна (`globals.css` → `.meta-dot`): яг 3px, 35% тунгалаг,
`currentColor`. Фонтоос үл хамаарна, дэлгэц уншигч юу ч уншихгүй.

Мөр (string) заавал байх ёстой газарт (`title=`, `aria-label=`, `alt=`) CSS
ажиллахгүй тул зураас « — » эсвэл таслал хэрэглэнэ.

**Үл хамаарах зүйл:** «100×100», «200×200», «300×300» — эдгээр нь номын
цувралын бодит нэр, `×` нь тэндээ байх ЁСТОЙ.

## 5. Дүрс (icon)

`lucide-react` **л**. Emoji, unicode глиф (`⚠ ✓ → ✕ ✎`) хэрэглэхгүй —
Lucide-ийн харгалзах дүрсээр солино (`TriangleAlert`, `Check`, `ArrowRight`,
`X`, `Pencil`).

Хэмжээ: жагсаалтад 14-16px, товчинд 16px, гарчигт 18-20px. `aria-hidden`
нэмнэ (текст хажууд нь байгаа тул).

---

## 6. Хүртээмж

- Интерактив бүх зүйл гарнаас хүрнэ; фокусын цагираг автоматаар ирнэ
  (`globals.css`-д глобал). Гараар `outline-none` бичиж БҮҮ ус.
- Дүрс дангаар байвал `aria-label`.
- Өнгө дангаараа утга илэрхийлэхгүй — дүрс эсвэл текст дагалдана
  (өнгө ялгадаггүй хэрэглэгч ~8% эрэгтэй).
- Модалд `role="dialog"` + `aria-modal` + `aria-labelledby`.

---

## 7. Бичвэрийн өнгө аяс

Монгол, товч, хүндэтгэлтэй. Техникийн үг хэрэглэхгүй
("API", "server", "null"). Тушаах биш, тайлбарлах.

Математик бичвэр ҮРГЭЛЖ `MathText` компонентоор (LaTeX) — `π`, `²`, `⅓`
гэх мэт энгийн тэмдэгт хэрэглэхийг эзэн хатуу хориглосон.

---

## 8. Монгол бичвэрийн онцлог

Монгол үг латинаас **20–30% урт**. Мобайл (375px) дээр бүхэл үгнүүд
нэг мөрт багтахгүйгээс шалтгаалж, хоёр мөрөнд задтага шавалдана.

### 8.1 Текст нягтрал

Гарчиг, шошго, товч текст — зайг багасгаж ашигла:

```tsx
<h3 className="cyrillic-heading">Сурах явцын зураглал</h3>
<label className="cyrillic-tight">Сургалтын төлөвлөгөө</label>
```

**Гарчиг** → `.cyrillic-heading` (letter-spacing -0.02em, word-spacing -0.06em)
**Шошго/товч** → `.cyrillic-tight` (letter-spacing -0.01em, word-spacing -0.04em)

**Урт эгшиглэл текст** → ангийн класс тавихгүй, байгалийн мөр хэвээр.
Мөрийн хэмжээ --measure (68ch) автоматаар удирдана.

### 8.2 Эргүүлэх (rotation) утсыг БҮУ ХЭРЭГЛЭ

CSS `transform: rotate()` болон `writing-mode: vertical-rl` нь кириллийн
үсгүүдийг гажигтай дүүдүүлдэг (бүтээлийн текстийг эргүүлэхэд оптикал
төлбөрөлт биш). Эргүүлэх шаардлагатай үг байвал:

1. **SVG дотор** — `<tspan>` дээр transform эсвэл `<text rotate="">`
2. **Мат индекс/зэрэг** — `<MathText>` ашигла, эргүүлэхгүй
3. **Хүйс диаграмм/төлөв** — дүрсийн туллаа, монгол үг үл ашигла

### 8.3 Мөрийн өндөр

`--leading-body: 1.55` нь латинаас арай өндөр. Кириллийн үсгүүдийн өндөр
(х-өндөр) латинаас арай их байдаг тул энэ өндөрлөл нь зөв. Өөрчлөхгүй.

### 8.4 Фонт сонголт

System font stack (`ui-sans-serif`, `system-ui`, "-apple-system",
`BlinkMacSystemFont`, "Segoe UI", `sans-serif`) ашигладаг.
Төхөөрөмжийн түрхээр хамгийн үзэсгэлэнтэй фонт ирнэ.

Гадаад фонт (өөрөөр хэлбэл CDN) **ХОРИОТОЙ** — интернэт удаан байхад
сүлжээний фонт ирэхийг хүлээж, UI мөгөлдөнө.

### 8.5 Кодын бүтэлгэй

Монгол үг, латин үг, тоо, тэмдэгт холоор ашигладаг текстэд `​`
(zero-width space) эсвэл `<wbr />` нэмэлтээр тавих нь шаардлагагүй бөгөөд
гажигтай уншигдана. Браузер өөрөө сайн боловсруулна.

Жишээ: "ЭЕШ-ийн 2024 №342 бодлого" — нэмэлт хонхын цоо оруулахгүй.
