# Номыг «wow» түвшний бодит дүрслэлтэй болгох зам

Огноо: 2026-10-08.

---

## 1. Яагаад одоогийн 3D хангалтгүй вэ

Одоогийн мокап нь **real-time** 3D (Three.js / WebGL): браузер секундэд 60 удаа дахин зурдаг тул гэрлийг **ойролцоогоор** тооцдог. Гэрэл гадаргаас гадаргуу руу ойх, цаасны ширхэг, ирмэгийн зөөлөн бөөрөнхий, бодит сүүдэр — эдгээрийг хуурамчаар дуурайдаг. Дээр нь утас бүрийн график чип өөр тул нэг төхөөрөмж дээр ном бүхэлдээ хар болж байна.

**Мэргэжлийн хүмүүс ингэж хийдэггүй.**

| Хэн | Яаж хийдэг |
|---|---|
| Apple (iPhone, AirPods хуудас) | 3D загварыг **path tracing**-ээр урьдчилан дүрсэлж, 60–150 зураг болгон гаргаад, scroll хийхэд солино |
| Номын хэвлэлийн газрууд | Photoshop mockup эсвэл **KeyShot / Blender Cycles** рендер |
| Бүтээгдэхүүний брэндүүд | Жинхэнэ студийн гэрэл зураг эсвэл CGI рендер |

**Path tracing** гэдэг нь гэрлийн цацраг бүрийг физикийн дагуу хэдэн мянган удаа ойлгож тооцдог арга. Нэг зураг гаргахад секунд, минут зарцуулдаг ч кино, сурталчилгааны түвшний бодит дүр гардаг. Үр дүн нь зүгээр л **зураг** тул ямар ч утас дээр яг адилхан харагдана.

## 2. Санал болгож буй зам: Blender Cycles (үнэгүй)

Blender бол үнэгүй, нээлттэй эхийн, Pixar/Netflix-ийн түвшний 3D программ. Cycles нь түүний path tracing рендерер.

**Таны хийх зүйл:** Blender суулгахыг зөвшөөрөх (≈400MB). Бусдыг нь би Python скриптээр хийнэ — та Blender-ийг нээх ч шаардлагагүй.

**Миний хийх зүйл:**

| Алхам | Юу |
|---|---|
| Загвар | Зөөлөн хавтастай ном: бага зэрэг бөөрөнхий ирмэг, нурууны нугалаа, хуудасны блок, цаасны ширхэг |
| Материал | Гялгар ламинат (clearcoat), офсет цаас, хавтасны зүсмэл ирмэг |
| Гэрэл | Мэргэжлийн студийн HDRI (Poly Haven — CC0, үнэгүй) + softbox, градиент тууз, хар хаалт |
| Камер | Бүтээгдэхүүний зургийн линз (85–100мм), гүний бүдгэрэл (depth of field) |
| Гаралт | 72 зургийн эргэлт (5° тутам) + 3–4 hero зураг (4K) |
| Вэб | Apple-ийн арга: scroll хийхэд зургууд солигдоно. WebGL шаардахгүй — бүх утсан дээр ажиллана |

**Нэг хязгаарлалт:** хавтасны бичгийн тод байдал эх файлаас хамаарна. 1084px задгай зургаар 4K рендер хийвэл бичиг бүдэг гарна. **Хавтасны эх файл (300 dpi)** хамгийн чухал.

## 4. «Wow» түвшинд хүргэх нарийн ширийн зүйлс

Мэргэжлийн CGI-г энгийнээс ялгадаг зүйлс:

1. **Ирмэг бөөрөнхий.** Бодит юм хэзээ ч хурц 90° өнцөггүй. 0.5мм бөөрөнхийлөлт гэрлийг барьж «бодит» мэдрэмж өгнө.
2. **Төгс бус байдал.** Хавтас бага зэрэг муруйсан, хуудасны блок жаахан жигд бус, ламинат дээр бараг харагдахгүй хурууны ул мөр. Хэт төгс = компьютерийн зураг.
3. **Нурууны нугалаа.** Зөөлөн хавтастай номын урд хавтас нурууны ойролцоо нугалагдсан зураастай.
4. **Гүний бүдгэрэл.** Урд хэсэг тод, ард нь бага зэрэг бүдэг — бодит линзний мэдрэмж.
5. **Градиент тусгал, хар хаалт.** Гялгар хавтсан дээр нэг ирмэг нь хурц, нөгөө нь уусдаг гэрлийн тууз.
6. **Ойрын сүүдэр (contact shadow).** Ном шалтай хүрсэн шугамд хамгийн бараан, нарийн сүүдэр.
7. **Өнгөний зөв менежмент.** Filmic / AgX tone mapping — гэрэлтсэн хэсэг цайрахгүй, бараан хэсэг унахгүй.
