# Pi.mn v2 public interface review

Reviewed 2026-10-07. Scope: public landing page and application navigation. Original checkout is not a write target. No external photos, fabricated results, extra packages, deployment or production data writes.

## Evidence and decisions

- [Next.js Link](https://nextjs.org/docs/app/api-reference/components/link) and the installed Next 16.2.9 `dist/docs` recommend Link for route navigation. Public links and shell return links use Link. The existing public `/` route has no authentication redirect; its navigation offers the existing role-specific dashboard via `homeForRole` without clearing authentication.
- [Next.js useRouter](https://nextjs.org/docs/app/api-reference/functions/use-router) documents that back uses browser history. The new contextual navigation instead links to a known parent page from existing role navigation, so opening a deep link directly still has a useful destination.
- [W3C target size guidance](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html) establishes a 24 CSS pixel AA minimum with exceptions. This project retains its stricter 44px interaction target contract. Mobile navigation uses the existing Vaul drawer for focus management, Escape and closing controls.
- [Reduced-motion preference](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/prefers-reduced-motion) is respected: the CSS math visual animates only under `no-preference`. Public section content remains visible without IntersectionObserver or JavaScript animation. Formulas use MathText; illustration uses inline SVG and CSS with no WebGL or remote assets.
- [Brilliant's official homepage](https://brilliant.org/) presents learning first with a direct primary action. This informed the restrained hero, clear learning choices and progressive subject disclosure. This is an interpretation of content hierarchy, not a claim that Pi.mn matches its outcomes. [Khan Academy's homepage](https://www.khanacademy.org/) returned no readable content to the research tool; no unverified visual conclusions are drawn from it.
