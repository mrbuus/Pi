# Томьёоны энгийн тайлбар (`simple`) — бичих заавар (2026-11-02)

## Эзний үг

«Томьёоны хэсэг хамгийн чухал. Томьёо бүрийн тайлбарыг математикийн ямар ч мэдлэггүй хүн хараад ойлгохоор, маш энгийнээр,
алхам бүрчлэн тайлбарлаж, хэрэглээг нь харуулсан жишээтэй байх. Хүүхдийн тархи гацчихсан байсан ч ойлгогдохоор хялбар.
Интернэт дээр хамгийн хялбар, ойлгомжтой байдлаар хэрхэн тайлбарлаж байгааг харж, өнгөөр ялгаж харуул. Ухаантай хүн харсан ч
эвтэйхэн, энгийн бөгөөд цэвэрхэн.»

## Хаана бичих

`api/prisma/data/formulas/<бүлэг>.json` — томьёо бүрийн объектод `"simple"` талбар нэмнэ. Бусад талбарт (latex, explanation,
examples…) ХҮРЭХГҮЙ. Файлыг `json.dumps(d, ensure_ascii=False, indent=2) + "\n"`-ээр бичнэ (diff цэвэр үлдэнэ).

## Бүтэц

```json
"simple": {
  "say": "Нэг өгүүлбэр: энэ томьёо юу хэлдэг вэ (энгийн үгээр)",
  "formula": "\\colA{a}^2+\\colB{b}^2=\\colC{c}^2",
  "parts": [ { "tex": "\\colA{a}", "mean": "энэ үсэг юуг илэрхийлэх вэ" } ],
  "steps": [ "Алхам 1", "Алхам 2", "Алхам 3" ],
  "example": { "problem": "Жижиг, амьдралын/энгийн тоотой бодлого", "steps": ["…"], "answer": "…" },
  "watch": "Хамгийн түгээмэл алдаа нэг өгүүлбэрээр (заавал биш)"
}
```

- **Өнгө:** `\colA{…}` (хөх), `\colB{…}` (ягаан), `\colC{…}` (ногоон), `\colD{…}` (нил ягаан). Өөр өнгө, `\color`, `\textcolor`
  ХЭРЭГЛЭХГҮЙ. Нэг үсэг/хэмжигдэхүүн томьёо, `parts`, `steps`, `example` бүгдэд ИЖИЛ өнгөтэй (a нь үргэлж хөх гэх мэт) —
  хүүхэд өнгөөр нь холбож ойлгоно. Энгийн томьёонд 2-3 өнгө хангалттай, 4-өөс илүүг бүү хэрэглэ.
- `formula` нь анхны `latex`-тэй математикийн хувьд ижил (хялбаршуулж болно, гол хэлбэрийг хадгал).
- `parts` 1-6 мөр. `steps` 2-6 алхам: «юуг хаанаас олох», «юуг юугаар орлуулах», «юу хийх» — тушаалын хэлбэрээр, богино.
- `example` нь жижиг, гараар бодоход хялбар тоотой (3, 4, 5 гэх мэт), алхам бүр томьёотой, өнгө нь `formula`-тай ижил.
  Хариу нь ЗӨВ байх ёстой — өөрөө гараар хоёр удаа шалга.

## Хэл, хэв маяг (эзний хатуу дүрэм)

1. Зөвхөн монгол хэл. Орос үг, өгүүлбэр ХЭЗЭЭ Ч үгүй. Англи үг үгүй.
2. Математикийн бүх тэмдэгт `$…$` дотор LaTeX (`$x^2$`, `$90^\circ$`, `$\sqrt{2}$`). `π ² · √ ≤` гэх мэт тэмдэгтийг энгийн
   бичвэрт БҮҮ бич. Үржих тэмдэг зөвхөн `\cdot` (`•`, `·` хориотой).
3. Өгүүлбэр, алхам, тайлбарын төгсгөлд цэг (.) ТАВИХГҮЙ. Асуултын тэмдэг болно.
4. Хүнд нэр томьёо («үл доройтсон», «тодорхойлогдох муж», «изоморф»…) хэрэглэхгүй. Заавал хэрэгтэй нэр томьёог хаалтанд
   энгийнээр тайлбарла: «катет (тэгш өнцгийн хажуугийн тал)».
5. Анхаарлыг татах үгийг энгийн бичвэрээр (ТОМ үсгээр биш, emoji биш).
6. Хэт урт биш: `say` ≤ 160 тэмдэгт, алхам бүр 1 өгүүлбэр.

## Жишиг (өөрийн тайлбарыг үүнтэй харьцуулж бич)

`plane-geometry.json` → `plane-pythagoras`, `plane-triangle-inequality`-ийн `simple` талбар.

## Шалгах

```bash
node web/scripts/check-formula-simple.cjs <файлын нэр .json-гүй>
```

«Алдаагүй» болтол засна. Скрипт нь KaTeX-ээр бүх томьёог уншиж, бүтэц, цэг, өнгө, тэмдэгтийг шалгадаг.
