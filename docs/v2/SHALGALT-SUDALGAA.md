## 1. Шалгалтаар юу хийх гэж байна (бизнес)
- ЭЕШ сорилыг **live** (олон хүүхэд зэрэг, улс даяар нээлттэй) болон **хүссэн үедээ** өгөх; данс цэнэглээд шалгалт бүрийг худалдаж авна (CHAT-09-22:360).
- Ялгарал (SYSTEM-DESIGN exam-strategy): **OMR + онлайн → нэг түүх → алдсан сэдэв → багшийн даалгавар**. Өрсөлдөгч: YESH, iMath, Lumina, testly (үнэгүй).
- Загвар: үнэгүй оношлох сорил + төлбөртэй сорил + live pilot. Үнийн санаа ₮15k ганц / ₮120k 10 сорил (батлагдаагүй — U8, U12).
- Франчайз: салбаруудыг «сүлжээ дундын эрэмбэтэй сорил»-оор холбоно (00-ФРАНЧАЙЗ). Гадны төвд програм зарах (B2B) — одоохондоо үгүй.
- Хориг: «ЭЕШ-ийн албан оноо / тэнцэх магадлал / 800 оноо» гэж нэрлэхгүй (F09, LV08).

## 2. Шалгалтын амьдралын мөчлөг (бүх баримтыг нэгтгэсэн)
1. **Бэлтгэх** — бодлогын сангаас эсвэл импортоор (Word/PDF/JSON) 36+4 загвар, A/B хувилбар, бүлэг/сэдвийн тэмдэглэгээ, контент царцаах (version freeze).
2. **Худалдаалах / нээх** — ангид оноох (TestAccess), худалдан авалт/эрх (Pass, Store, prepaid credit — 3 загвар нэгтгэгдээгүй, G40).
3. **Өгөх** — онлайн (серверийн таймер, autosave) эсвэл цаасан (OMR машин / багш гараар).
4. **Дүгнэх** — автомат (1-р хэсэг + 2-р хэсгийн алхмын багц), гараар засах, regrade хувилбар.
5. **Нийтлэх** — PUBLIC / зөвхөн анги / хувийн; нэртэй эсвэл ID-аар; тэнцүү оноонд ижил байр; маргаан.
6. **Задлан шинжлэх** — анги, сурагч, бодлого, сэдэв (Topic% = авсан/боломжит), буруу сонголтын шинжилгээ.
7. **Эргэн харах / давтлага** — бодолт+бичлэг (7 хоногийн дараа), алдааны сан → ижил сэдвийн бодлого.
8. **Эцэг эх** — дүнтэй танилцсанаа баталгаажуулах.

## 5. Санал болгож буй бүтэц — «Шалгалт» нэг хэсэг, 3 давхарга
- **Жагсаалт** — бүлгүүд (сэдвийн, ЭЕШ сорил, 1000 бодлого…) + 4 шүүлтүүр (хайлт, цуврал, анги, төлөв).
- **Мөр дэлгэрэх** — тухайн тестийн бүх зүйл нэг дор: хураангуй тоо, анги харьцуулалт, бодлого бүрийн %, сурагчдын жагсаалт; жижиг товчууд (Сурагчийн харагдац · Засах · Дүн шивэх · Хандалт · Бичлэг).
- **Дүн шивэх** — Excel шиг тор (хоосон = зөв, 0 = буруу, ирээгүй), 2-р хэсгийн алхмын багц (1-1…4-3) тест бүр дээр тохируулна. Дараа нь OMR файл ч энэ торыг дүүргэнэ.

## 6. Хийх дараалал (санал)
1. Суурь өгөгдөл: бодлого бүрийн тэмдэглэгээ (TestItemMark), алхмын багц (scoringGroups) — онлайн, гар, OMR гурвуулаа нэг хэлбэрт.
2. «Шалгалт» нэгтгэх + мөр дэлгэрэх + дүн шивэх тор.
3. Анализ (тест/анги/бодлого/сэдэв).
4. Дүн нийтлэх + эрэмбэ (зөвшөөрлийн урсгалтай).
5. OMR импорт (машины жишээ файл ирсний дараа).
6. Худалдаалах + live сорил (төлбөрийн загвар шийдэгдсэний дараа).
