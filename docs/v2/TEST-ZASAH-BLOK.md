# Тест засах — 40 блок (2026-10-11)

Эзний хүсэлт: «Засах» дарахад тестийн бүх бодлого блок болж харагдана; блок бүрээс LaTeX,
хариу, оноо, зураг, байрлал, дээр/доор нэмэх, хасах — бүгд нэг дор. Буцаах/Урагшлах дээр
байнга харагдана. Бодлого зөвхөн дугаар дээр дарахад идэвхжинэ. Урт зураг дэлгэцэнд багтана.

## Бүтэц (`web/src/components/test-editor/`)
- `model.ts` — цэвэр логик (tests/test-editor-model.test.cjs): агуулга ↔ сервер, шалгалт,
  зөөх/нэмэх/хасах, хадгалах төлөвлөгөө (`planSave`: шинэ бодлого → агуулгын PATCH → тест PATCH).
- `EditorToolbar` — `sticky top-14`: ↶ ↷, Хадгалах (N), Түүх, ⋯, дугаараар үсрэх 1–40.
- `ProblemBlock` (memo) — унших горим; дугаар дарахад засах горим (LaTeX + шууд харагдац,
  сонголт/зөв хариу, нөхөх нүд, зураг нэмэх/солих/хасах, оноо, байрлал, дээр/доор нэмэх, хасах).
- `SettingsCard` — хураасан тохиргоо. 1000 бодлогын тестэд төрөл түгжээтэй, анги илгээхгүй
  (өмнөх хуудас 1000 тестийг хадгалж чаддаггүй байв).
- `BankDialog` — «Сангаас сонгох».

## Дүрэм
- Бүх засвар нэг буцаах стект, нэг «Хадгалах». Агуулгын PATCH `expectedVersion`-той (зэрэг засвар нэгтгэнэ).
- Байгаа бодлогын агуулга — Багш+/Админ; шинэ бодлого — бүх ажилтан. Сурагч өгсөн тест — бүтэц түгжээтэй.
- `MathText`: `**I.**` → тод «I.», од харагдахгүй (бүх дэлгэц).
- `ProblemFigure`: өргөн зураг (≥1.6:1) бүтэн өргөнөөр, өндөр дэлгэцийн хувиар.
