# «Шалгалт» хэсгийн төлөвлөгөө (батлуулах)

Зарчим: нэг хуудас (`/app/tests` → «Шалгалт» таб), шинэ цэс/хуудасгүй.
Мөр дээр дарахад доор нь нээгдэнэ. 1000 бодлогын тусдаа цэс/хуудас устна
(backend логик нь хэвээр ашиглагдана).

## 1. Юу байх вэ

Бүлгүүд (одоогийнх шиг эвхэгддэг): «100V3 Илтгэгч тэгшитгэл» … + **«1000 бодлого»**
(Явцын 1-A…6-A, дараа нь Сорил 7-A…22-A).

Шүүлт — ердөө 4, нэг мөрөнд:
- **Хайлт** (сэдэв, тестийн нэр)
- **Цуврал**: Бүгд / 100 / 200 / 300 / 1000 (номын код — одоо өнгөөр ялгагддаг)
- **Анги**: Бүх анги / 12-1 / 12-2 … (багшид зөвхөн өөрийн анги)
- **Төлөв**: Бүгд / Оноосон / Өгсөн / Дүн шивээгүй

Хичээл (Математик/Нийгэм) болон сэдвийн dropdown одоогийнхоороо үлдэнэ.

## 2. Загвар

Эвхэгдсэн мөр:
```
▸ Тест 1 Хувилбар A · 40 бодлого · 100 мин · 23/28 сурагч · дундаж 61%   [Засах]
```

Нээгдсэн мөр (компьютер):
```
▾ Сорил 8-A · 40 бодлого · 100 мин
 ┌──────────────────────────────────────────────────────────────────────┐
 │ [Бүх анги] [12-1] [12-2] [12-7]                                      │
 │ Өгсөн 23 │ Дундаж 61.4 (61%) │ Медиан 63 │ Max 92 │ Min 18 │ Тэнцсэн 70% │
 │ Анги: 12-1 ███████ 66% (12)   12-2 █████ 54% (11)                   │
 │ Тархалт: ▁▂▅█▆▃▁  (0-10-…-100%)                                      │
 │ Бодлого бүрийн зөв %:                                                │
 │  1 ████████ 87%  2 ██████ 64%  …  36 ██ 18%                          │
 │  1-1 █████ 52%  1-2 ███ 31% … 4-3 █ 9%                               │
 │ Хамгийн хэцүү 5: №36 18% (C 41%) · 4-3 9% · …  ← дарахад бодлого+бодолт │
 │ Сурагчид (эрэмбэлэгдэнэ): Нэр │ Анги │ I хэсэг │ II хэсэг │ Нийт │ %  │
 │ [Дүн шивэх] [Сурагчийн харагдац] [Хандалт] [Засах] [YouTube] [⋯]     │
 └──────────────────────────────────────────────────────────────────────┘
```

Утас: дээрхтэй ижил дараалал, нэг багана. Тоонууд 2×3 хавтан, анги чипс
хөндлөн гүйлгэнэ, бодлогын % 6 баганатай жижиг тор (өнгө = %), сурагчийн
жагсаалт «Нэр — Нийт %» хоёр баганатай, дарахад задарна. Товчнууд доор
хөндлөн гүйлгэх мөр.

## 3. Энэ хэсэгт юу хийж болох вэ

Багш (зөвхөн өөрийн анги):
1. Шүүх, хайх, бүлэг/мөр нээх.
2. Өөрийн ангиудын дүн, статистик харах; анги сонгож шүүх.
3. Бодлого дээр дарж бодлого + бодолтыг харах.
4. Өөрийн ангид тест оноох/цуцлах, эргэн харалт (Үгүй / Зөвхөн бодлого / Бүрэн) + автоматаар нээх огноо.
5. «Дүн шивэх» — өөрийн ангийн сурагчдын буруу нүдийг тэмдэглэх, ирээгүйг тэмдэглэх.
6. «Сурагчийн харагдац» — тестийг сурагч яг яаж харахыг үзэх.
7. Өөрийн үүсгэсэн тестийг засах.

Багш+ / Админ (бүх анги) — дээрхийг бүгд, нэмээд:
8. Бүх ангийн дүн, ангиудын харьцуулалт.
9. Аливаа тестийг засах; II хэсгийн алхмын бүлэг (үсэг, оноо) засах.
10. YouTube холбоос оруулах (мөрөнд шууд) ба Excel-ээр гаргах/оруулах (⋯).
11. Бодлогын код харах («#» дарж).

Сурагч:
12. Өөрт оноогдсон шалгалтуудаа жагсаалтдаа харах (1000 бодлогынх ч мөн).
13. Онлайнаар өгөх / үргэлжлүүлэх.
14. Өөрийн дүн, хэсэг тус бүрийн оноо харах.
15. Багш нээсэн үед эргэн харах (бодлого эсвэл бүрэн бодолт + YouTube). Код, токен хэзээ ч харагдахгүй.

## 4. Дүн шивэх (Excel-тэй адил)

1. Мөрийг нээгээд «Дүн шивэх» → анги сонгоно.
2. Хүснэгт: мөр = ангийн сурагч; багана = 1…36 + II хэсгийн бүлгүүд (1-1, 1-2, 1-3, 2-1 … 4-3). Толгойд оноо (жин) харагдана.
3. **Хоосон = зөв, 0 = буруу.** Нүдэн дээр дарах эсвэл «0» бичих нь солигдоно. Сум/Tab/Enter-ээр шилжинэ; Excel-ээс блок хуулж буулгана.
4. Нийт = бүх жингийн нийлбэр − 0 тавьсан нүдний жин; % шууд тооцогдоно. Мөр бүрд «Ирээгүй» сонголт.
5. «Хадгалах» — сурагч бүрээр хадгална (нүд бүрийн зөв/буруу + нийт дүн, эх сурвалж = гараар).
6. Онлайнаар өгсөн сурагчийн мөр автоматаар бөглөгдсөн, түгжээтэй (засах бол «Гараар засах»).

II хэсгийн бүлэг: Excel-ийн 3-р мөр шиг тест бүрд өөр. «Засах» дотор II хэсгийн
бодлого бүрд жижиг хүснэгт: Бүлэг (2-1) │ Нүдүүд (a b c) │ Оноо. Нийт оноо
бодлогын онооноос зөрвөл хадгалахгүй, улаанаар анхааруулна. Онлайн үнэлгээ:
бүлгийн бүх нүд зөв → бүлгийн бүтэн оноо. 1000 бодлогынх JSON-оос
(`steps`) автоматаар орно; бусад тестэд өгөгдмөл нь бодлого бүр = нэг бүлэг.

## 5. Статистик (хэн харах)

- Өгсөн тоо / нийт сурагч — бүгд (сурагч зөвхөн өөрийнхийг).
- Дундаж оноо ба %, медиан, max/min, тэнцсэн хувь — багш (өөрийн анги), Багш+/Админ (бүгд).
- Ангиудын дундаж % ба тоо — багш (өөрийн ангиуд), Багш+/Админ (бүгд).
- Онооны тархалт (10 баганатай жижиг SVG) — багш, Багш+/Админ.
- Бодлого бүрийн зөв % (36 + II хэсгийн бүлэг) — багш, Багш+/Админ.
- Сонголтын тархалт A–E, хамгийн их сонгосон буруу хариулт тодруулна (зөвхөн онлайн өгсөнд) — багш, Багш+/Админ.
- «Хамгийн хэцүү» эрэмбэ — багш, Багш+/Админ.
- Сурагчийн жагсаалт (I/II хэсэг, нийт, %) — багш, Багш+/Админ.
- Өөрийн дүн, хэсэг тус бүр — сурагч.

График: шинэ сан нэмэхгүй, гараар хийсэн жижиг SVG/CSS баар.

## 6. Үе шат

1. **Нэгтгэх** (DB өөрчлөлтгүй): 1000-ын цэс/хуудсыг хасаж «Шалгалт» табд «1000 бодлого» бүлэг; сурагчид оноогдсоныг жагсаалтдаа; шүүлт (цуврал/анги/төлөв); мөр нээгдэх + үйлдлийн товчнууд (одоо байгаа логик).
2. **II хэсгийн бүлэг**: DB `Problem.scoringGroups Json?` (нэмэлт миграци); импортер `steps`-ийг оруулж дахин ажиллуулна; онлайн дүгнэлт бүлгээр; «Засах» дотор бүлэг засах + шалгалт.
3. **Дүн шивэх**: DB `TestItemMark` (testId, studentId, itemKey, correct) + TestResult (source=гараар, absent); API хадгалах/унших; вэб тор (гар, буулгах, нийт).
4. **Статистик**: API `/tests/:id/analytics?classroomId=` (онлайн + гараар нэгтгэсэн, эрхээр шүүсэн); вэб хураангуй, анги, тархалт, бодлогын %, хэцүү жагсаалт, сурагчид.
5. **Бүх шалгалтад**: CHAPTER_EXAM / EESH_MOCK мөн ижил нээгдэх самбар, дүн шивэх.

Үе шат бүр тусдаа deploy болж болно; тест, build, локал шалгалттай.

## Эзэнд асуух (≤5)

1. «Тэнцсэн» босго хэд вэ — 60%? Тест бүрд өөр үү?
2. Онлайнаар өгсөн сурагчийн дүнг багш гараар дарж засахыг зөвшөөрөх үү?
3. Excel-д зарим бүлгийн оноо 0 байна (ж: 4-1 = 0). Энэ нь «тооцохгүй» гэсэн үг үү, эсвэл алдаа юу?
4. «1000 бодлого» дотор Сорил 11, 13, 14 одоогоор алга (JSON-д байхгүй) — дараа нэмэх үү?
5. Багш өөрийн ангид тест оноох эрхтэй байх уу, эсвэл зөвхөн Багш+/Админ оноох уу?
