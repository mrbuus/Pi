## Гэрлийн / харанхуй горим

- Цэсэнд нэг товч (нар/сар), анх системийн горимоор, сонголт хадгалагдана
- Хуудас ачаалахад анивчихгүй (толгойд жижиг скрипт)
- 3D-ийн өнгө (ирмэг, дэвсгэр) горимоор солигдоно, лого аль хэдийн солигддог
- Эхлээд демо дээр, таалагдвал үндсэн нүүрт шилжүүлнэ

## Гүйцэтгэл (хуучин утас)

- Сул төхөөрөмж (санах ой < 4GB, цөм < 4) → 3D-гүй, зураг
- Зураг бүр lazy, жижиг урьдчилсан хувилбар, WebP
- «Хөдөлгөөн багасгах» тохиргоотой хүнд хөдөлгөөнгүй
- Зорилт: эхний дэлгэц 2.5 секундээс бага (4G)

## Үгийн дүрэм

Апп маягийн: нэг санаа — нэг өгүүлбэр. «Шилдэг», «баталгаатай», «№1» хэрэглэхгүй.
Тоо өөрөө ярина. Гарчигт цэг тавихгүй.

## Амжилтын нүүр (2026-10-17)

`python3 docs/v2/hero/build_amjilt_faces.py` — `amjilt/<он>.json`-ийн бүх картаас нүүрийг macOS Vision-оор (`faces.swift`)
олж `amjilt/faces/` руу бичнэ (атлас + тус бүр + index.json, git-д орохгүй). Шинэ карт нэмэгдвэл
`build_amjilt_cards.py`-ийн дараа энийг ажиллуулаад `port_home.py --demo`. Бүлэг картын 800 / 700-аас доош
оноог скриптийн `TOP`, `LOW`-д картаас нүдээр уншиж бичсэн.
