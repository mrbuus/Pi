# Буцаах (Undo/Redo) ба өөрчлөлтийн түүх — төлөвлөгөө (2026-10-11)

Эзний хүсэлт: вэб дээр бодлого засаж байхад буцаах боломжгүй — Cmd+Z / Ctrl+Z ажилладаг,
буцах/урагшлах товчтой, хэн хамгийн сүүлд өөрчилсөн түүх хадгалагддаг байх.

## Одоогийн байдал (судалгаа)
- Undo/redo огт байхгүй. Засварлагч (ProblemClassifyEditor) хадгалсны дараа шууд хаагдана;
  гадуур дарвал хадгалаагүй өөрчлөлт анхааруулгагүй алга болно.
- Түүх хагас: бодлогын ангилал/сонголт/tag, YouTube, алхмын багцын засвар аудитад бичигддэггүй;
  бичигддэг ч сонголтгүй «өмнөх» хувилбар → сэргээх боломжгүй.
- Хоёр хүн зэрэг засвал сүүлд хадгалсан нь дарна (анхааруулгагүй).

## Хийх зүйл — 3 давхарга

### 1. Засаж байх үеийн буцаах (хадгалахаас өмнө)
- Засварлагчийн толгойд **↶ Буцаах · ↷ Урагшлах** товч.
- Товчлол: **Cmd+Z / Ctrl+Z** — буцаах, **Shift+Cmd+Z / Ctrl+Y** — урагшлах.
  Текст бичиж байх үед (input/textarea дотор) хөтчийн өөрийн текст буцаалт ажиллана;
  бусад үед (сонголт зөв болгох, tag нэмэх/хасах, зураг солих…) манай буцаалт.
- Бичвэрийн өөрчлөлтийг ~0.6 сек зогсолтоор нэг алхам болгоно.
- Хадгалаагүй өөрчлөлттэй цонхыг хаахад «Хадгалаагүй өөрчлөлт байна» гэж асууна.

### 2. Хадгалсны дараах буцаах
- Хадгалмагц 10 сек «Хадгаллаа · **Буцаах**» мэдэгдэл — дарвал өмнөх хувилбар руу буцна.

### 3. Өөрчлөлтийн түүх (хувилбар бүр бүрэн хадгалагдана)
- Шинэ хүснэгт `ContentRevision`: бодлого/тест × хувилбарын дугаар → бүрэн хуулбар
  (текст, сонголт + зөв хариу, хариу, бодолт, зураг, сэдэв, алхмын багц, YouTube; тестэд —
  бодлогууд, оноо, хугацаа), **хэн**, **хэзээ**, **юу өөрчлөгдсөн** (товч), шалтгаан.
- Бүх засварын зам бичнэ: бодлого засах, ангилал/сонголт/tag, алхмын багц, YouTube,
  тест засах, анги оноох, импорт.
- Засварлагчид **«Түүх»** таб: «Б. Баасанжав · өнөөдөр 14:05 · сонголт B-г зөв болгосон»
  гэх мэт жагсаалт, хувилбар бүрийн ялгааг харуулна, **«Энэ хувилбар руу буцаах»** товч.
  Буцаах нь өөрөө шинэ хувилбар болно (түүх устахгүй).
- Тестийн мөрийн «⋯» цэсэнд «Өөрчлөлтийн түүх».
- Хоёр хүн зэрэг засвал: «Таныг засаж байх хооронд Б. Баасанжав өөрчилсөн» → дахин ачаалах
  эсвэл харьцуулах (сүүлд хадгалсан нь чимээгүй дарахгүй).

## Хамгаалалт
- Сурагч өгсөн тестийн бодлогын хариуг хуучин хувилбар руу буцаахад анхааруулга
  («Өмнөх дүн дахин бодогдохгүй»), алхмын багцын түгжээ хэвээр.
- Түүхийг харах: Багш — өөрийн зассан бодлого/тест; Багш+/Админ — бүгд.
- Сурагчид түүх, ID огт харагдахгүй.

## Хэрэгжүүлэх дараалал
1. DB: `ContentRevision` + Problem/Test `version`, `updatedAt`, `updatedById` (нэмэлт миграц).
2. API: бүх засварын замд хувилбар бичих, `expectedVersion` → 409, түүх/ялгаа/сэргээх endpoint.
3. Web: `useUndoable` hook (стек + товчлол), засварлагчид ↶ ↷ товч, хаахын өмнөх асуулт,
   «Буцаах» мэдэгдэл, «Түүх» таб; тестийн «⋯ → Өөрчлөлтийн түүх».
4. Тест: undo стек, 409 зөрчил, сэргээлт, эрх.
