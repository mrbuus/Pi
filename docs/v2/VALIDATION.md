## Үлдсэн ажлыг ямар дарааллаар хийх вэ

1. **Агуулга, бодит урсгалын pilot.** Номын бүх бодлогын дугаар/LaTeX/зураг/зөв түлхүүрийг бүрэн хянах. Одоогоор50 бодлогын seed л баталгаажуулсан дэд багц. Бодит зөвшөөрсөн амжилтын зураг, мэдээллийг кодын тохиргоонд оруулах. Сурагч/багш/эцэг эхтэй турших.
2. **Элсэлт.** Түвшин тогтоох материал, заавал ажлын зураг, багшийн үнэлгээ/холбогдох,1–2 туршилтын хичээл, дараах гэрээ. Бүрэн үйл явц одоогоор баримтжуулсан бөгөөд хэрэгжээгүй. Одоогийн танхимын идэвхжүүлэх огнооны код болон анхны утсаар тохирох нууц үг нь нийтэд гаргахын өмнөх тусдаа хамгаалалтын шийдвэр шаардана.
3. **Бодит цаг ба цалин.** Хуваариас тооцсон цагийг ажилласан цагтай андуурахгүй. Ажилтан цаг илгээх, хянах, батлах/түгжих, цалингийн тарифын хувилбар, бодит тооцоо хэрэгжээгүй. Capability тодорхойлолт нь цалингийн engine биш.
4. **Төлбөр/холболт.** QPay settlement/webhook, Google OAuth, SMTP, SMS, CDN/video origins/гэрээний бодит тохиргоо. Өмнөх банкны хуулга ба policy fixture-ээр тулгах; буцаалтын хугацаа/өмнөх буцаалт/олон ангид хуваарилах allocation-г батлах. Wallet, улсын хэмжээний live болон weekly orchestration бүрэн биш.
5. **Хадгалалт ба үйлдвэрлэлийн орчин.** Файлын URL дотор bearer token явдаг хуучин аргыг богино настай, scoped холбоосоор солих. Үйлчилгээний хадгалалтын гэрээ, object-store/CDN, Docker startup, monitoring/outbox, migration/schema-ийн хуучин зөрүү, rollback, recovery-г staging дээр шалгах.5,000 хэрэглэгчийн ачаалал/алдааны төсөв хэмжигдээгүй.
6. **OCR ба суралцах загвар.** Зураг→Монгол бичвэр/LaTeX→семантик/Q-matrix→solver→багш батлах benchmark; лиценз, төхөөрөмж, хэмжээ, хурд, чанар. Дурын бодлого бодох OCR/универсал model хэрэгжээгүй. Одоогийн зөвлөмж нь ил тод heuristic; difficulty/IRT/BKT болон суралцах үр нөлөөг бодит pilot дээр үнэлнэ.32 шинэ судалгааны ажил нэмсэн ч өмнөх сангийн баталгаатай тоо тодорхойгүй тул2× гэж зарлаагүй.
