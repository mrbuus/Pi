# Шалгалтын модуль — бүрэн төлөвлөгөө (санал, 2026-10-10)

Суурь: SHALGALT-SUDALGAA.md (манай бүх баримт + код), SHALGALT-GADAAD-SUDALGAA.md (ZipGrade, Gradescope,
Socrative, Formative, Quizizz, testly, yesh, eec), эзний Excel «Багшийн анги-3-2.xlsx». Код хөндөөгүй.

---

## 0. Зарчим — «хамгийн хялбар»

1. **Нэг газар.** Шалгалттай холбоотой бүх зүйл «Шалгалт» хэсэгт. Тусдаа цэс, тусдаа том хуудас байхгүй.
2. **3 товшилт.** Ямар ч үйлдэл ≤3 товшилт: олох → мөрийг дэлгэх → үйлдэл.
3. **Нэг хүснэгт.** Онлайн, цаасан (гар шивэлт), OMR — гурвуулаа ижил «бодлого бүрийн зөв/буруу» хүснэгтэд бичигдэнэ → анализ нэг.
4. **Анхдагч утга.** Бүх тохиргоо урьдчилан бөглөгдсөн; багш зөвхөн өөрчлөх шаардлагатайг өөрчилнө.
5. **Энгийн үг.** «p-value, discrimination» биш — «Зөв хувь», «Сайн ялгадаг / Сул ялгадаг» өнгөөр.
6. **Эрхээр нуух.** Сурагч ID, бусдын дүн, зөв хариу (нээгдэхээс өмнө) хэзээ ч харахгүй.

## 1. Бүтэц — «Шалгалт» хуудас

```
Шалгалт                                   [Хайх...] [Цуврал v] [Анги v] [Төлөв v]  [+ Шинэ]
[ Тест 562 ]  [ Шалгалт 198 ]

v 1000 бодлого                                                      19 шалгалт
  Сорил 10-A   40 бодлого · 100 мин   12-1 12-2   ● Дүн дутуу   дундаж 64%   >
  Сорил 12-A   40 бодлого · 100 мин   —           ○ Оноогоогүй                >
> Сэдвийн шалгалт (36+4)                                            52 шалгалт
> ЭЕШ сорил                                                          11 шалгалт
```

**Шүүлтүүр (зөвхөн 3):** Цуврал (Сэдвийн / ЭЕШ сорил / 1000 бодлого / Өдөр тутмын) · Анги · Төлөв
(Оноогоогүй / Өгч байна / Дүн дутуу / Дууссан). Хайлт нэр, сэдвээр.

**Мөр дарахад дотроо дэлгэрнэ — 4 жижиг таб:**

```
v Сорил 10-A                                  [Сурагчийн харагдац] [Засах] [⋯]
  ( Тойм )  ( Дүн )  ( Бодлого )  ( Тохиргоо )
  ------------------------------------------------------------------
  Анги: [Бүгд] [12-1] [12-2]
  Өгсөн 52/60 · Дундаж 64% · Медиан 66% · Хамгийн их 96% · Хамгийн бага 18%
  Тархалт  ▁▂▅▇▆▃▁   (0-20-40-60-80-100)
  Анги харьцуулалт  12-1 ███████ 68%   12-2 █████ 59%
  Анхаарах 5 бодлого:
    #28  22% зөв — ихэнх нь B-г сонгосон (шилжилт ба зайг хольсон)   >
    #33  31% зөв ...
```

| Таб | Агуулга | Хэн |
|---|---|---|
| **Тойм** | Дээрх тоо, тархалт, анги харьцуулалт, «Анхаарах 5 бодлого», сэдвийн эзэмшил (Алгебр 72%, Геометр 48%…) | Багш (өөрийн анги), Багш+/Админ (бүгд) |
| **Дүн** | Сурагчдын жагсаалт (оноо, %, 1-р/2-р хэсэг, эрэмбэ) — эрэмбэлэх, хайх. **[Дүн шивэх]** горим, **[Excel оруулах]**, **[Excel татах]** | Багш, Багш+, Админ |
| **Бодлого** | 40 бодлого: зөв %-ийн мөр, A–E сонголтын тархалт, 2-р хэсгийн алхмын багц бүрийн %; дармагц бодлого+бодолт+бичлэг; Багш+ эндээсээ засна (өөрчлөлтийн түүхтэй) | Багш (харах), Багш+/Админ (засах) |
| **Тохиргоо** | Анги оноох + огноо · Хугацаа · Бодолт нээх (Хаалттай / Зөвхөн бодлого / Бүгд, автоматаар N хоногийн дараа) · 2-р хэсгийн оноожуулалт · Дүн нийтлэх хэлбэр · Худалдаа (үнэ, нийтэд) | Багш (өөрийн анги оноох), Багш+, Админ (үнэ) |

`⋯` цэс: Хуулах · A/B хувилбар үүсгэх · YouTube Excel · Устгах (Багш+).

## 2. Дүн шивэх (эзний Excel-ийн дагуу)

```
Сорил 10-A · 12-1                       [Excel оруулах] [Excel татах] [Хадгалах]
 №  Нэр             Оноо   %    1 2 3 4 ... 36 | 1-1 1-2 2-1 2-2 2-3 3-1 ... 4-3 | Ирээгүй
    Оноо (жин) →          100   1 1 1 1     3 |  2   5   3   2   2   7       3 |
 1  Амарболд Б.      87   87%   . . 0 . ...  . |  .   .   0   .   .   .       . |  [ ]
 2  Амгаланзаяа С.   —     —    ...                                               |  [x]
```

1. Ангийг сонгоно → тухайн ангийн сурагчид мөрөөр гарна.
2. **Зөвхөн алдсан нүдэнд 0** (хоосон = зөв). Нүд дээр дарах эсвэл `0`/`Space` товч, сум/Tab-аар шилжинэ.
3. Excel-ээс хуулж буулгах (paste) — бүхэл блокоор.
4. Ирээгүй сурагчийг тэмдэглэнэ (дүнд, дундажид тооцогдохгүй).
5. Оноо, % тэр даруй бодогдоно; хадгалахад сурагч бүр тусдаа хадгалагдана.
6. Онлайнаар өгсөн сурагчийн мөр түгжээтэй («онлайн»); засахдаа Багш+ шалтгаан бичнэ → аудит.

**2-р хэсгийн оноожуулалт (Тохиргоо табд):** бодлого бүрт алхмын багц — нэр (2-1), аль үсгүүд ([a][b][c]), оноо (3).
Нийлбэр нь бодлогын оноотой тэнцэх ёстой (тэнцэхгүй бол улаанаар). 1000 бодлогын 19 тестэд бэлэн (JSON `steps`).
Онлайнаар: багцын бүх нүд зөв → бүтэн оноо, нэг нь буруу → 0 (ЭЕШ-ийн жишиг).

**Excel оруулах:** эзний одоогийн хуудасны хэлбэрийг шууд уншина (№/Овог/Нэр/Бүлэг + 36 + 1-1…4-3).
**OMR:** машины экспорт (Scored_Data.xls + key.ini) мөн энэ хүснэгт рүү буух — урьдчилан харах → батлах.

## 3. Анализ — юу харуулах (бүгд «Тойм», «Бодлого» табд)

| Үзүүлэлт | Тайлбар (дэлгэцэн дээр) |
|---|---|
| Өгсөн / нийт, дундаж, медиан, их/бага | энгийн тоо |
| Тархалт | 5 баганатай гистограм |
| Анги харьцуулалт | анги бүрийн дундаж % мөр |
| Бодлого бүрийн **зөв хувь** | ногоон ≥70%, шар 40–70%, улаан <40% |
| **Ялгах чадвар** (дээд 27% − доод 27%) | «Сайн ялгадаг / Сул / Асуудалтай» тэмдэг — асуудалтай бол «бодлогыг шалга» |
| **Буруу сонголт** | «Ихэнх нь B-г сонгосон» — хамгийн их сонгогдсон буруу хариу |
| 2-р хэсгийн алхам бүрийн % | аль алхам дээр унадаг |
| **Сэдвийн эзэмшил** | сэдэв бүрийн авсан/боломжит % (Topic% = Σавсан/Σmax) |
| Найдвартай байдал (KR-20) | зөвхөн Багш+/Админ, ногоон/шар/улаан цэг |
| Сурагчийн явц | олон шалгалтын дүнгийн шугам (сурагчийн мөр дээр дарахад) |

Хориг: «ЭЕШ-ийн оноо / тэнцэх магадлал / 800 оноо» гэж хэзээ ч нэрлэхгүй (F09, LV08).

## 4. Сурагч, эцэг эх

**Сурагч — «Шалгалт»:** «Өгөх» (оноогдсон/худалдаж авсан, эхлэх хугацаатай) · «Өгсөн» (оноо).
**Дүнгийн дэлгэц (1 хуудас):** Оноо, % · хэсэг тус бүр · сэдвийн эзэмшил · буруу бодлогууд →
бодолт нээгдсэний дараа бодолт + бичлэг · **[Ижил сэдвийн бодлого бодох]**. Анги доторх байр (зөвшөөрсөн бол).
**Эцэг эх:** хүүхдийн дүнгийн карт (оноо, сул сэдэв 2–3) → **[Танилцлаа]**.

---

## 5. Худалдаа (дараагийн шат)

- Аль ч шалгалт дээр **Тохиргоо → «Нийтэд зарах»** + үнэ (Админ). Тусдаа каталог хуудас байхгүй — нийтийн «Шалгалт» жагсаалтад «Худалдаж авах» товч.
- Хоёр хэлбэр: **Хүссэн үедээ** (худалдаж авмагц) · **Live сорил** (тогтсон цаг, бүгд зэрэг эхэлнэ, дүн цонх хаагдсаны дараа).
- Төлбөр: QPay. Эрх / дэлгүүр / данс гурвыг **нэг «эрх» загварт** нэгтгэх (G40).
- Эрэмбэ: анхдагчаар **зөвхөн ID**-аар, нэрээ харуулахыг сурагч өөрөө зөвшөөрнө.
- Сертификат (PDF) — дараа.

## 6. Өгөгдлийн суурь (хэрэгжүүлэх үед)

- `TestItemMark` — сурагч × шалгалт × нүд (бодлого эсвэл алхмын багц): зөв/буруу/хоосон, эх (ONLINE/MANUAL/OMR/EXCEL), хэн, хэзээ.
- `Problem.scoringGroups` — 2-р хэсгийн алхмын багц.
- `TestResult.source` зөв төрлөөр (CHAPTER_EXAM гэж бүгдийг бичихгүй), regrade хувилбар.
- Шалгалтын контентыг оноосны дараа царцаах (засвар нь шинэ хувилбар).

## 8. Миний сонгосон анхдагч шийдвэрүүд (өөрчлөхийг хүсвэл хэлээрэй)

1. **Тэнцэх босго:** анхдагчаар байхгүй; тест бүр дээр сонголтоор (жишээ 60%).
2. **Онлайн дүнг засах:** зөвхөн Багш+/Админ, шалтгаантай, аудитад бичигдэнэ.
3. **0 оноотой алхам:** «тоолохгүй» гэж үзнэ (саарал).
4. **Багш:** өөрийн ангиа оноож, дүн шивнэ; **Багш+/Админ:** бүх анги.
5. **Шалгалтаас гарах:** анхны шийдвэр (3 дахь удаад автоматаар илгээх) рүү буцаана.
6. **Дүн нийтлэх:** анхдагчаар зөвхөн анги дотор; live сорилд ID-аар нийтэд.
7. **Сорил 11, 13, 14:** олдвол нэмнэ (эх файл алга).
