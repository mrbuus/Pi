# Хэрэглэгдэхүүн — төлөвлөгөө (2026-10-22)

Математикийн багшийн бүх төрлийн хэрэгсэл нэг дор: график, хавтгайн дүрс, огторгуйн
биет (огтлол, дэлгээс), томьёо, бодогч, хэвлэх тор цаас. Сурагч ч ашиглана.

## Эзний шийдвэр (2026-10-22)

| Асуулт | Шийдвэр |
|---|---|
| Хэн ашиглах | Бүх хүн, нэвтрэлтгүй. Хуудасны доор «Нэвтрэх» үлдэнэ |
| Бодогч | Өөрсдийн тооцоолуур (AI биш, үнэгүй, интернэтгүй ажиллана) |
| Хүрээ | 6 хэсэг бүгд |
| Нүүрний hero | Дараа нь нэг товчоор холбоно (одоохондоо зөвхөн таб) |

## Миний шийдвэр (эзэн шалгана)

- Маршрут: нийтийн `/tools` (өөрийн толгой, доор нь Нэвтрэх) + аппын дотор `/app/tools`
  (зүүн цэсэнд «Хэрэглэгдэхүүн», бүх role). Хоёулаа нэг `ToolsHub` компонент.
- Таб нь хаягт: `/tools?t=graph|plane|solid|formula|solve|paper` — линкээр хуваалцана.
- 3D = **SVG** (WebGL биш): сурах бичгийн хэв маяг, тестэд цэвэрхэн хэвлэгдэнэ,
  удаан интернэттэй үед ажиллана (STATUS §3.8). Шинэ npm сан нэмэхгүй.
- Томьёо: API нэвтрэлт шаарддаг тул `web/scripts/build-formula-sheet.cjs` нь
  `api/prisma/data/formulas/*.json`-оос хөнгөн JSON үүсгэнэ (зөвхөн таб нээхэд ачаална).
  Нэвтэрсэн хүнд «Дэлгэрэнгүй» → `/app/formulas/[slug]`. 28 хөдөлгөөнт томьёо нийтэд.
- Хэсэг бүрт: дүүрэн дэлгэц (проектор), SVG/PNG татах (цагаан дэвсгэр, хар зураас).
- Төлөв localStorage-д (try/catch), графикийн функцүүд хаягт.

## Хэсгүүд

1. **График** — олон функц `y=f(x)`, `x=c`, далд тэгшитгэл `x^2+y^2=25`,
   тэнцэтгэл бишийн муж будах, цэг `(2;3)`. Чөлөөт үсэг (a, b, k…) автоматаар гулсуур.
   Чирж/чимхэж томруулах, π масштаб. Тэг, оргил, огтлолцол цэг (дарвал координат).
   Утгын хүснэгт.
2. **Хавтгайн дүрс** — бэлэн загвар (гурвалжин SSS/SAS/ASA, тэгш өнцөгт, адил хажуут,
   квадрат, тэгш өнцөгт, параллелограмм, ромб, трапец, зөв n-өнцөгт, тойрог) хэмжээг
   тоогоор өгнө. Гурвалжинд өндөр, медиан, биссектрис, багтсан/багтаасан тойрог.
   Чөлөөт горим: цэг, хэрчим, шулуун, тойрог, олон өнцөгт, чирэх. Оройн нэр, урт,
   өнцгийн нум, тэгш өнцгийн тэмдэг, тэнцүү хэрчмийн зураас. Талбай, периметр.
3. **Биет** — куб, параллелепипед, n-призм, n-пирамид, тетраэдр, тайрсан пирамид,
   цилиндр, конус, тайрсан конус, бөмбөрцөг. Хэмжээ, эргүүлэх, нуугдсан ирмэг тасархай,
   оройн нэр, диагональ/өндөр/апофем. Огтлол (өндөр + налуу, эсвэл 3 цэгээр) — хэлбэр,
   талбай. Дэлгээс. V, S томьёо тоогоо орлуулсан.
4. **Томьёо** — 387 томьёо 9 бүлгээр, хайлт, анги/түвшин шүүлт, хэвлэх. 28 хөдөлгөөнт.
5. **Бодогч** — тооцоолох (бутархай, язгуур), тэгшитгэл (шугаман, квадрат алхамтай,
   олон гишүүнт, бусад тоон), тэнцэтгэл бишийн завсар `(-\infty;1)\cup(2;+\infty)`,
   шугаман систем 2x2/3x3, уламжлал, интеграл (тодорхой тоон, тодорхой бус энгийн),
   задлах/үржигдэхүүнд задлах, ХИЕХ/ХБЕХ, анхны тоонд задлах, n!, C, A. «Графикт харах».
6. **Тор цаас** — дөрвөлжин тор, координатын хавтгай (1/2/4/6 нэг хуудсанд),
   изометр цэгэн тор, туйлын тор, тооны шулуун, миллиметр. A4, хэвлэх.
