# Хэрэглэгдэхүүн — сайжруулалт, 1-р шат (2026-10-24)

Өмнөх бриф `docs/v2/HEREGLEGDEHUUN-AGENT-BRIEF.md`-ийн бүх дүрэм ХҮЧИНТЭЙ (эхлээд түүнийг унш). Энэ файл нь эзний шинэ шаардлага.

## Эзний үг (2026-10-24), товч

- «Детал бүрчлэн сайжруулж, яг хэрэглээнд нийцэхэд бэлэн болго». Утаснаас ороход эвтэйхэн. Алдаа гарахгүй.
- «Тоонууд дээр доор байгаад байгаа асуудлыг зас» — шошго, тоо, томьёо нэг нэгнийхээ дээр/доор давхцаж, овоорч байна. ДАВХЦАЛ ҮЛДЭЭХГҮЙ.
- «Тоонуудыг хэт бутархайгаар харуулах асуудалтай» — `53.13`, `3.6055`, `2.4` гэх мэт хэт олон оронтой аравтын тоо БҮҮ харуул. Эхлээд яг/цэвэр хэлбэр (`\frac{1}{3}`, `\sqrt{13}`, `\frac{12}{5}`, `60^\circ`), ойролцоо утга хэрэгтэй бол дор нь жижиг саарал `\approx 3.61` (2 орон). Өнцгийн цэвэр утгыг (30°, 45°, 60°, 90°…) таниад бүхэл бичнэ.
- «Хамгийн хялбар». Photomath-ыг жишээ болгосон: нэг оруулга → шууд цэвэр хариу, «Дэлгэрэнгүй» дарвал алхам. Хэт дэлгэрэнгүй, «тэнэг юм шиг» урт бичвэр биш. Хүсвэл дэлгэрэнгүйг харна.
- Өнгө, дүрс маш энгийн. Гар (keyboard) маш хялбар.
- Хэрэгсэл бүрт хамгийн хэрэгтэй (useful) зүйлсийг нэмэх.
- Тор цаас хэсэг ХАСАГДСАН (хэрэггүй).

## Утасны дүрэм (375-430px, хамгийн чухал)

1. Хуудас хэвтээ тийш гүйхгүй. Удирдлагын табын мөр таслагдаж «нуугдмал» харагдвал → хэвтээ гүйлгэх бол заавал сүүдэр/сум дохио эсвэл 2 мөр.
2. Зураг утсан дээр ӨРГӨН, хангалттай өндөр (ойролцоогоор 55-65vh), дүрс зургийн талбайг дүүргэнэ (жижиг дүрс + их хоосон зай болохгүй).
3. Зургийн доторх шошгоны үсэг утсан дээр ≥13px (бодит дэлгэцийн пикселээр). Шошго бие биетэйгээ болон шугамтай давхцахгүй (давхцал зайлуулах: шошгыг дүрсийн гадна тал руу, хэрэгтэй бол тусгаарлах).
4. Томьёо/үр дүн урт бол МӨРӨӨР ТАСАРЧ давхцахгүй: тэнцүүгийн тэмдгээр хуваах, эсвэл карт тус бүрд нэг утга, эсвэл хэвтээ гүйлгэлттэй блок (`overflow-x:auto`) — гэхдээ хоёр гүйлгэгч хоорондоо давхцахгүй.
5. Хүрэх талбай ≥44px. Хуруугаар чирэх, чимхэж томруулах ажиллана.
6. Чухал үр дүн эхэнд, тохиргоо доор/«Тохиргоо» хураагдмал хэсэгт.

## Шалгалт (энэ удаад ХӨТӨЧ ЗӨВШӨӨРӨГДӨНӨ)

- dev server аль хэдийн http://localhost:3381 дээр ажиллаж байна (эзний терминал). ШИНЭЭР БҮҮ АСАА, `npm run build` БҮҮ ажиллуул, `.next`-д хүрэхгүй.
- Хөтчийн хэрэгсэл (Claude_Browser, Playwright г.м.) байвал `http://localhost:3381/tools?t=<хэрэгсэл>`-ийг 390x844 ба 1280x800 хэмжээнд нээж, ӨӨРИЙН нүдээр шалга (давхцал, жижиг дүрс, таслагдсан текст). Шалгасныхаа дараа localStorage-ийн `pi-tools:*` түлхүүрийг цэвэрлэ.
- `npx tsc --noEmit` цэвэр, `node --test src/components/tools/<хэрэгсэл>/*.test.mjs` ногоон (хавтсаар биш, glob-оор).
- Өөрийн хавтаснаас гадуур БҮҮ зас (`core/`-ийг зөвхөн зааварт зөвшөөрсөн бол).
