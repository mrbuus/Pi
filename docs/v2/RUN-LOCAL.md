# Pi.mn v2 — тусгаарласан локал хувилбар

Энэ checkout нь `../Pi.mn`-ийг өөрчлөхгүй. Branch: `codex/pi-mnv2`. Дараа PR үүсгэвэл base нь `claude/100-dollar-credit-usage-ksqjev`; `main` руу push хийхгүй. Одоогийн хувилбарыг cloud дээр байршуулсан гэж үзэхгүй.

## Асаах

Node.js22.12+ эсвэл24+, PostgreSQL16 хэрэгтэй. macOS Homebrew-ийн PostgreSQL хэрэгслийг ашиглана; өөр замтай бол `PI_V2_PG_BIN` тохируулна. Docker engine энэ компьютер дээр байхгүй тул container startup баталгаажуулаагүй. Хуучин `docker-compose.yml`-ийн5432 порт/нууц үгтэй setup-ийг энэ хувилбарын launcher ашиглахгүй.

```sh
cd /Users/mr.buus/Intern/pi.mnv2/api
npm ci
cd ../web
npm ci
cd ..
node tools/v2/local.cjs setup
node tools/v2/local.cjs seed
cd api
npm run build
cd ..
./start.sh
```

Вэб: `http://localhost:3381`. API: `http://localhost:3380/api`. PostgreSQL: `127.0.0.1:5544/pimn_v2`. Launcher зөвхөн энэ local database-д ажиллаж, өөр тохиргоог дарж бичихээс татгалзана. Ажиллаж буй өөр процессыг албадан зогсоохгүй. `Ctrl+C` зөвхөн launcher-ийн эхлүүлсэн API/вэбийг зогсооно; локал PostgreSQL cluster үлдэнэ.

Зохиомол зургаан эрхийн нэвтрэх мэдээлэл `.runtime/accounts.json` файлд байна; тэр файл Git-д орохгүй. Seed зөвхөн локал сан дээр ажиллана. Нууц үг дахин seed хийхэд өөрчлөгдөхгүй.50 номын жишээний эх нь өмнөх хараат бус математик шалгалтын SHA-256 fingerprint-тэй таарсан үед л орно. Хариуны түлхүүр шалгагдсан боловч тайлбарын статус `AUTO_DRAFT`; багш батлаагүй тайлбарыг зөв гэж сурагчид үзүүлэхгүй.

Ажиллаж буй портууд:

```sh
node tools/v2/local.cjs status
```

Production-mode локал шалгалтад эхлээд `web` дотор `npm run build`, дараа `./start.sh --production`. Нэг `.next` directory дээр `next dev` ба `next build`-ийг зэрэг ажиллуулахгүй.

`docs/v2/REVIEW.html` нь интернетгүй ажиллах тусдаа хяналтын хуудас. Checkbox/comment хөгжүүлэлтийн тэмдэглэл бөгөөд бүтээгдэхүүний баталгаатай тестийг орлохгүй. JSON export хийн хадгалж болно.

Амжилтын галерейг `web/src/components/landing/achievements-config.ts` дотор баталсан зураг, тайлбар, эх, зөвшөөрлөөр шинэчилнэ. Тусдаа зураг оруулах удирдлагын дэлгэц нэмээгүй. Одоогийн жинхэнэ амжилтын жагсаалт хоосон.

Төвийн шинэ онлайн ангийн элсэлт анхдагчаар хаалттай. Одоо байгаа ONLINE сурагчийн нэвтрэлт, түүх болон BUYER-ийн бие даасан ном/тестийн эрх хэвээр. Ирээдүйд бодитоор нээхээр шийдвэрлэсэн үед API-ийн `CENTRE_ONLINE_CLASS_ENABLED=true` ба вэбийн `NEXT_PUBLIC_CENTRE_ONLINE_CLASS_ENABLED=true` тохиргоог хоёуланг нь тавьж, вэбийг дахин build хийнэ; хичээлийн элсэлтийн цонхны availability мөн тохирсон байх ёстой. Зөвхөн frontend эсвэл хүсэлтийн payload өөрчилж серверийн хаалтыг тойрох боломжгүй. Энэ тохиргоо өөрөө шинэ анги нээх бизнес шийдвэр биш.

## Баталгаажуулалт ба нөөц

API: `npm test -- --runInBand`, `npm run build`. Вэб: `./node_modules/.bin/tsc --noEmit`, `npm run build`. Шинэ сангуудын production audit: API/вэб дотор `npm audit --omit=dev`. Dev tooling advisories-ийг тусад нь хянаж, framework-ийг дур мэдэн хуучин major хувилбар руу буулгахгүй.

`GET /api/health/live` процессын төлөв; `GET /api/health/ready` нь бодит DB query амжилттай эсэхийг шалгана. Readiness алдаа нь DB connection/credential/хэрэглэгчийн мэдээлэл задлахгүй. API startup өөрөө DB холболт шаарддаг; энэ нь DB унасан үед бүх хувийн функц хэвийн байна гэсэн амлалт биш.

```sh
node tools/v2/restore-check.cjs
node tools/v2/migration-check.cjs
```

Энэ скрипт54 миграцитай зохиомол локал санг custom dump-аас шинээр үүсгэсэн disposable DB руу сэргээж, гол хүснэгтүүдийн тоо болон хадгалсан файлын байтын hash-уудыг харьцуулна. Зөвхөн өөрөө үүсгэсэн disposable DB-г устгана. Fixtures өөрчилж буй туршилтуудтай зэрэг ажиллуулахгүй. Cloud snapshot/PITR/object-store сэргээх баталгаа тусдаа шаардлагатай.

`migration-check.cjs` бүх миграцийг хоосон disposable локал сан дээр эхнээс нь ажиллуулж, тоо болон Prisma schema-г шалгана. Хуучин migration ба Prisma schema хооронд байсан нэмэлт index/FK/default-ийн зөрүүг автоматаар DROP хийдэггүй; production migration review дээр тусдаа шийдвэрлэнэ.

## Нийтэд гаргахын өмнөх бодит хязгаар

QPay, Google OAuth, SMTP, SMS, CDN болон зөвшөөрсөн video origins энэ локал орчинд credential-гүй. Үйлчилгээ байхгүй үед төлбөр/эрх нээсэн гэж мэдээлэхгүй. Нийтийн амжилтын бодит зураг, багшийн баталсан мэдээлэл тусдаа хэрэгтэй.5000 сурагчийн cloud ачаалал, Redis/queue availability, WAL/PITR, object store, хууль/гэрээний баталгаа, төлбөрийн буцаалтын allocation, элсэлтийн байршуулалт/туршилтын хичээл, бодит timesheet/цалин болон өргөн OCR/solver-ийн ажиллагааг энэ local acceptance-аар баталсан гэж үзэхгүй. Шалгалттай математик generator нь зургаан тодорхой template family; дурын бодлого боддог universal model биш.
