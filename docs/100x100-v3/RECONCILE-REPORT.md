## 3. 🔴 МИГРАЦИЙН ЭРСДЭЛ — token-оор зөөж БОЛОХГҮЙ

DB-ийн token нь хуудсаас хамаардаггүй нь тогтоогдов:

```
100V2-TOO-02-B-01
  │     │   │  │  └ бодлогын дугаар
  │     │   │  └─── хувилбар A/B
  │     │   └────── тестийн дугаар
  │     └────────── сэдвийн код
  └──────────────── ном+хэвлэл
```

Энэ нь сайн мэдээ мэт харагдана — гэхдээ **дугаар нь байрлалаас хамаардаг.**
Нэг бодлого хасагдвал түүнээс хойшхи БҮХ дугаар шилжинэ.

Батлагдсан жишээ (`Модультай тэгшитгэл, Тест 1-A`): хуучин №05 `|x+4|+2=1`
шинэ хэвлэлээс **хасагдсан** тул 06→05, 07→06 болж шилжсэн. Token-оор зөөвөл
`ABSEQ-01-A-05`-ийн задлан огт өөр бодлогод очно.

**Агуулгаар тулгасан үр дүн:**

| | Тоо | Тайлбар |
|---|---:|---|
| ✅ Таарсан | **1,074** | DB-ийн 54.4% |

**900 / 815 тоог болгоомжтой ойлгоно уу.** Задлалт монгол текст дээр алдаа
гаргасан (жишээ: ном «тэгшитгэлийг бод» гэж бичсэн атал задлалт «тэнцэтгэлийн
бод» гэж уншсан — х.141-ээс баталсан). Ийм алдаа тулгалтыг бүтэлгүйтүүлдэг тул
жинхэнэ хасагдсан/нэмэгдсэн тоо **үүнээс бага**. Найдвартай нь **686 яг таарц**.

### Санал болгох арга

1. **Token-оор БҮҮ зөө.** `MIGRATION-MAP.json`-ийн агуулгын тулгалтыг ашигла.
2. **686 яг таарцыг** автоматаар зөө — `ProblemAnalysis` шууд шилжинэ.
3. **186 шилжсэнийг** гараар баталгаажуулаад зөө.

5. **Одоогийн DB-ийн монгол текстийг БҮҮ дарж бич** — тэр нь энэ задлалтаас
