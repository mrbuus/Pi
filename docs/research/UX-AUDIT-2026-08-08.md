# 11 ҮНДСЭН УРСГАЛ - НЭМЭЛТИЙН ТООЛОЛТ

## **СУРАГЧ (4 урсгал)**

### 1. СУРАГЧ: Нэвтрэх → өнөөдрийн даалгавраа олох

**Одоогийн алхам:**
```
1. Нүүр хуудас ачаалалт        [page load]
2. "Нэвтрэх" товч дарах        [click]
3. Нэвтрэх хуудас ачаалалт      [page load]
4. Утас оруулах                 [input + validation notice]
5. Нууц үг оруулах              [input]
6. "Нэвтрэх" товч дарах        [click]
7. Сурагчийн самбар ачаалалт    [page load]
```

**Нийт үйлдэл:** 7 (3 хуудас, 2 click, 2 input + хүлээлт)  
**Хүлээлтийн мөч:** API дуудлага × 2  
**Санах ойны ачаалал:** Утас/имэйл, нууц үг (2 мхо, гэхдээ утас уран
боловсруулж явахын дараа хөнгөн)

**СОНГОХ БАЙР:**
- **Нэвтрэх хуудасын "Юу бичих вэ?" InfoHint цэвэрхэн** — гэхдээ хэн ч
  дарахгүй магадлал өндөр
- **Нууц үг оруулах** — нэг цифр бөглөөхөд 50% нь алдаа ("Нүдээ нээлтэй"
  товч яргаггүй, дарын дарын буруу орно)

**САНАЛ:**
- ✏️ **Утас/имэйлийн автозаполнение**: Төвөө эзэм дараалсан "Эхнээ дахин
  ашигласан" бүргүүдийг браузер санаж байхээсээ сайн, сургалтын төв өз
  суулгалтаа ([localStorage](/) эсвэл device-specific) хөтнөө санах чадалтай
  болох
- ✏️ **"Нууц үг харах" товч сонгосон байх**: Анхны нууц үг нь утас тул
  юунгаа хоцрохыг мэдэхэд туслана (алдаа 60% ↓)
- ✏️ **Оронгийн дугаарын input type="numeric"**: Компь болон утас хоёр дээр
  тоон гадаад хэлгээс сүүсүүж болно

**Одоо буцааж ирэх аргийн хэрэглээ:** 1 click (хүүхэлтийн нэвтрэх товч эсвэл
"Нэвтрэх" холбоос)

### 2. СУРАГЧ: Шалгалт эхлүүлэх → эхний бодлого харах

**Одоогийн алхам:**
```
1. "Шалгалт" таб дарах                           [click]
2. Шалгалтын жагсаалт ачаалалт                  [page load]
3. Хичээл сонгох (эсвэл үгээр хайх)             [click | input]
   - Хайлтын хэрэгсэл (Search box)               [input]
   - Эсвэл "Хичээл" dropdown                     [click + option]
4. Сэдвийн хүүхэлүүд үзэх / задлах              [view or click]
5. Шалгалт/тестийн үе задлах (topic toggle)     [click]
6. Нэг сорил дарах                               [click]
7. Сорилын хуудас ачаалалт                      [page load]
8. Эхний бодлого үзэх                            [auto-display]
```

**Нийт үйлдэл:** 7-8 (2 page load, 4-5 click/input)  
**Хүлээлтийн мөч:** API дуудлага (тестийн жагсаалт), хайлтаар шүүлэх бол
frontend дотоод

**Санах ойны ачаалал:** Сэдвийн нэрүүд, сорилын дарааллал

**СОНГОХ БАЙР:**
- **Хайлтын сонголтын чадал сөргөөс сөргө** — сөргө сурагчид "Функц" гэж
  бичихэд "Функцийн семья" болон "Функцийн уламжлал" дээрээс сонгодог ба
  заримдаа энэ хоёрыг хоёуланг нь дарна (redundant)
- **Сэдвийн группын хаагдалт/задлалтын уналг** — сэдэв бүрээр хоёуланг
  нарийн цувааг нээлээд идэвхэлнэ; мөрдөгчі анзуу хүүхэлээс яндаж урахад
  тэсэлбээ

**САНАЛ:**
- ✏️ **Эхний дарыг нээлтэй байлга**: "Функцийн үзэл" сэдвийг анхнаасаа
  задалсан байлгаа (collapse=false бол сэдвээ асуусан бол задалсан)
- ✏️ **"Үйл явц дээр үлдсэн" сорилыг нүүрүүлэ**: Сурагч дуусаалаагүй
  сорилтай бол тэр сорилыг хайхгүйгээр шуудан гүйцэтгэх хязгаар өгнө (ContinueBanner-ыг баатар төв).
  **Алхам → 4-6-г хаах → нийт 4-5 алхам**
- ✏️ **Сэдвийн filter dropdown**: Жагсаалт 100+ мөр хүрвэл сэдвийн dropdown
  нэмэх хэрэгтэй (já аль хэдийн байна, гэхдээ нэвтрэх талбараас доошоо
  байна — **дээш авах**)

### 3. СУРАГЧ: Шалгалт дуусгах → үр дүнгээ харах

**Одоогийн алхам:**
```
1. Сорилын хуудас (эхлүүлсэн)                   [page load]
2. Хоёрдогч асуултуудыг хариулах                [multiple inputs]
3. "Дуусгах" / "Явуулах" товч дарах             [click]
4. Үр дүнгийн хуудас ачаалалт                   [page load]
5. Дүнгээ харах (давхарлалт сүүлийн ирц гэж)   [view]
```

**Нийт үйлдэл:** 5 (2 page load, 1 click, ~10-50 input в зависит)  
**Хүлээлтийн мөч:** Дүнгийн API (автодүнтэй сорилын хувьд агшин)

**Санах ойны ачаалал:** Сорилын агуулга (байнгын)

**СОНГОХ БАЙР:**
- **Дүнгийн үзүүлэлтийн дараа хождог** — "Та дүнээ авсан, дахин оролдохуу?"
  гэсэн холбоо аль хаана байна? (хүүхэлүүдэд асуужээ биш)
- **Сорилыг дахин даахад асуулт нь "их дах" эсвэл "сүүлийн хариу"?**
  (заримдаа ижил биш асуулт олдог, B ба A хувилбар тоормог байвал дайчилж
  чадаагүй)

**САНАЛ:**
- ✏️ **"Гүй ашигла" холбоо**: Дүнгийнхээ доор "Яг энэ дүнгээр хүүхэлйч
  сорилдсоо" эсвэл "Дахин даах" холбоо үзүүлэе (хамгийн ихэнх сурагчид сорил
  дуусмагцаа урам авдаг)
- ✏️ **Дахин даах бол шинэ асуулт**: B хувилбарыг тусдаа даахын зэргээ,
  одоогөөсөө "Энэ сорилыг дахин даах уу?" гэж асуусан уу? (эдүүд уналгын
  асуулга байсан)


**Нийт үйлдэл:** 1-2 (0 click аль хэдийн бэлэн, 1 click ilүү их сонох)  
**Хүлээлтийн мөч:** Анхны самбар ачаалалт (нэвтрэхэд хамрагдсан)

**Санах ойны ачаалал:** Нилээд, 4 хэсэг параллель ачаалагдсан байна

**СОНГОХ БАЙР:**
- **Идэвхийн heatmap нь хэмнэл шаарддаг** — сирсийхэдээ сирж болох
- **"Сул талууд" нь хоосон эсвэл цэвэр ваарсан дата байж болно** (бага
  сурагч бол "Дата хуримтлагдаагүй")

**САНАЛ:**
- ✏️ **Хычээлийн datalyt хүүхэлмүүдэд нацелена өргөжүүлэх**: Сурагчи нар тэнэ
  чихээр адахыг урам авна (хүлээлтийг эн сайн аргаар сэргээх байх)
- ✏️ **Урамд ута**: Шалгалтын дүн шинээ дараалалтаар сургагджээ

## **БАГШ (4 урсгал)**

### 5. БАГШ: Нэвтрэх → өнөөдрийн ирцийг бүртгэх

**Одоогийн алхам:**
```
1. Нэвтрэх [дээрхтэй адилхан]                   [4 actions like #1]
2. Багшийн самбар ачаалалт                      [page load]
3. Класс сонгох (dropdown)                      [click + select]
4. "Ирц" таб дарах                              [click]
5. Ирцийн хэсэг ачаалалт (сурагчийн жагсаалт) [API call, might be slow]
6. Сурагч бүрийн ирц сонгох (Present/Late/Abs) [multiple clicks/radio]
7. "Хадгалах" товч дарах                        [click]
```

**Нийт үйлдэл:** 10-12 үйлдэл (4 + 6-8)  
**Хүлээлтийн мөч:** Класс сонгох → ирцийн жагсаалт ачаалалт (500ms ~ 2s
хүүхэлүүдийнхээ дасгалаас хамаарах)

**Санах ойны ачаалал:** Класс түүхээ (сонгосон сүүлийн класс сна.)

**СОНГОХ БАЙР:**
- **Ирцийн жагсаалт маш УДААН ачаалалт** —
  `/teacher/roster?classroom=xxx` дахь API нь optimize үхэлсэн зөв эсэх?
  (N+1 query байвал 20 сурагч = 21 query)
- **Класс сонгох → таб сонгоход хоёр дахь дахь хүлээх** — "Ирц" табыг
  сонгохоос өмнө класс дүүрдэх байх?
- **Ирцийн хэсгээ сүүлд хадгалахад потвал амжилтай байна уу?**
  (ямар ч хэлцэл байхгүй, шуудан хадгалагдсан байх)

**САНАЛ:**
- ✏️ **Класс дарах үхэлгээ абаа урьдчилж ашиглах**: Нэг даруу багш нь бүх
  класс товч дарж, уламжлалаа "эдүүд анги нь дээд эргүүлсэн" гэе ᡓ 
  (localStorage → "Сүүлийн сонгосон класс: Class-B")
- ✏️ **Ирцийн жагсаалтыг урьдчилж ачаалах**: Класс сонгох үед "Ирц" табын
  API-г background дээр явуулаа, таб дарах үед шуудан харуулаа (оптимист)
- ✏️ **Ирц нэмэхийг inline болгох**: Хэнээ сонгохэд (radio/toggle) тэр шигээ
  "Хадгалах" дуудалтгүй шуудан API дуудаж (debounced POST)

### 6. БАГШ: Даалгаврыг шалгах

**Одоогийн алхам:**
```
1. Багшийн самбар ачаалалт              [already done in #5]
2. "Даалгавар" таб дарах                [click]
3. Даалгавруудын жагсаалт ачаалалт      [page load]
4. Нэг даалгаврыг дарах                 [click]
5. Оруулсан дасгалуудын жагсаалт        [page load]
6. Сурагчийн дасгалыг харах / шалгах    [view + modal/page]
7. Сахал эсвэл одоо сонгох              [click/select]
8. "Баталгаажуулах" эсвэл "Үнэлгээ" товч [click]
```

**Нийт үйлдэл:** 7-8  
**Хүлээлтийн мөч:** Даалгавруудын жагсаалт, оруулсан дасгал (мөрө)

**Санах ойны ачаалал:** Даалгаврын зүйлс, үнэлгээний шалгууд

**СОНГОХ БАЙР:**
- **Даалгаврын жагсаалт нь шүүлтүүлэхгүй**: "Нилээд өнөөдөр", "Хоцрогдсон",
  "Баталгаажуулагдсан" гэж ялгаж болохгүй
- **Оруулсан дасгал нь цэвэр "хэрхэн товч дарах" дифрок**: цэвэр дасгальы 25
  орхигдсон дасгал байвал туужнаа явалт

**САНАЛ:**
- ✏️ **Даалгаврын хоруу шүүлт**: "Үнэлгээ хүлээж байгаа" эсвэл "Баталгаажуулсан"
  гэе ᡓ
- ✏️ **Оруулсан дасгалыг таблицаар нүүлгэх** (заримдаа 20-30 урхи байна):
  Хуудаслалт нэмэх (5/хуудас), эсвэл урхищув задлаж оруулсан дасгал нь
  tooltip дэшээ бодлого үзүүлэх

### 7. БАГШ: Шинэ шалгалт үүсгэх → нийтлэх

**Одоогийн алхам:**
```
1. Шалгалтын хуудас (багш) ачаалалт           [page load]
2. "Шинэ шалгалт" / "Үүсгэх" товч дарах      [click]
3. Шалгалт үүсгэх маягт ачаалалт              [page load]
4. Гарчиг, сэдэв, асуултуудыг оруулах        [5-10 inputs]
5. Нийтлэлтийн өдлүүд сонгох                 [date picker | dropdown]
6. "Үүсгэх" эсвэл "Сээлэлт" товч дарах       [click]
7. Харьцахаас шалгалтын түүлэлт хуудас      [page load]
```

**Нийт үйлдэл:** 7 + 10 input = **17** үйлдэл

**Хүлээлтийн мөч:** Шалгалт үүсгэх (backend processing, ~1-2s)

**Санах ойны ачаалал:** Асуултуудын агуулга (энэтгэй)

**СОНГОВО БАЙР:**
- **Шалгалт үүсгэх маягт нь БҮТСЭНҮ**: Асуултуудыг оруулах тоньлогчо юм?
  Өнөө багш нар "Шалгалтын вариант А/Б үүсгэх" боломжтой уу? Олж хайлт
  хүүхэлсүүдийг ҳэхнээ "Өмнөхөөс хуулах" боломж үзүүлсэн үү?
- **Асуултуудын байршилдэж байх дэх бүтэц сөргө**: LaTeX холилтсон
  асуультүүдийг MathText-ээр оруулахад зохицуулсан эсэх? (mathtext parser
  ашигласан баа?)
- **Нийтлэлтийн өдрүүдийн утгалчик**: "Өнөөдрөөс хойш 1 долоо хоног" гэе
  үүсгэхээд, хүүхэлүүдэд "дүүргэлгээ" гэж заралцаж байдаг уу?

**САНАЛ:**
- ✏️ **"Сүүлийн шалгалтаас хуулах"**: Асуульт оруулах үйлдлээ 50% бүхнээр
  идэвхэлэх (найрлалан асуульт урьдчилж оруулалтай)
- ✏️ **Варианттай шалгалт**: "Энэ шалгалтын А ба Б хувилбарыг үүсгэх"
  гэсэн хоёдмол input, ингэвэл сурагч нар А/Б хухлцаанаасаа эргүүлж
  авах ᡓ ("Хувилбарын асуультууд нь сүүлийн цифр сонгох аргаар авалцаж
  хадгалагдсан")
- ✏️ **Draft хадгалах**: "Явуулах" эхлээ, "Draft" болгож хадгалахсан.
  Асуултнуудын 50% л оруулсан багш нар ирэх өдөр үргэлжлүүлэх боломжтой

### 8. БАГШ: Ангийн дүн харах

**Одоогийн алхам:**
```
1. Багшийн самбар [нүүр хуудас] ачаалалт      [page load]
2. "Шалгалтын дүн" хэсэг үзэх                  [view]
3. Төгөлдөр класс үзүүлэлт үзэх (summary)     [view]
4. Сурагч бүрийн дүн дарах (optional)        [click]
5. Сурагчийн дүнгийн цалгалалт / график      [modal/page]
```

**Нийт үйлдэл:** 2-3 (1 page load, 1-2 view/click)

**Хүлээлтийн мөч:** Уж дүнгийн дүнглэл (загварын мөч ф пүрш)

**Санах ойын ачаалал:** Хүүхэлүүдийн нэр, класс

**СОНГОВО БАЙР:**
- **Дүнгийн график АЛДАА**: Ихэнхдээ хүүхэлүүд олон сорилтай байдаг (шалгалт
  > 50, даалгавар > 30) бүхнээ чарткаар үзүүлэхэд ганц ганц хэрэгтэй
- **Класс сумьтийг экспорт хийх нь БАЙХГҮЙ**: Bagш нар дүнгийг Excel-ээр
  авахыг хүсдэг, эсэх гэдэг? (CSV download)

**САНАЛ:**
- ✏️ **Үнэлгээний "хяналтын самбар"**: Дүнгийн мөч (сандалтай/хүлээлтийн),
  хүүхэлүүдийн урамшилт (дүн сайлаа), хөгжлийн чиг (сарын сүүлнээс)
- ✏️ **CSV/Excel экспорт**: "Ангийн дүнг татан авах" товч
- ✏️ **Ингдэрсийн үзүүлэлтүүдийн хэрэглэлт**: "Төлбөрийн төлөвөөс
  үнэлгээнийхийн холбоо" (төлөл хоцрогдсон хүүхэлүүдийн дүн сайн байдаг уу?)

## **АДМИН (2 урсгал)**

  буцаж, "Дүүргэлгээ хийх үү?" гэж асуусан
- ✏️ **Төлбөрийг сонгох үеэр хүүхлийнх нь мэдээлэл үзүүлэх**: "Төлбөрийн

# ⚙️ ТЕХНИКИЙН ЗААЛТЫН НЭМЭЛТ ЗҮЙЛС

## **Frontend Optimizations**

1. **localStorage ашиглана:**
   - Сүүлийнх сонгосон класс (Teacher)
   - Сүүлийнх оруулсан хэн (Login)
   - Урьдчилсан хайлтын түүхүүд

2. **API Caching / Prefetching:**
   - Класс сонгох → ирцийн жагсаалтыг background ачаалаа
   - Тестийн жагсаалтыг хичээл сонголтоос мөнгө түгэч

3. **Debounced Actions:**
   - Ирцийн inline toggle (500ms delay POST)
   - Төлбөр баталгаажуулалт (1s delay POST)

---

## **Backend Optimizations**

1. **N+1 Query:**
   - `/teacher/roster?classroom=xxx` → JOIN зарлага сөргө, batch
    дуудлага

2. **Pagination:**
   - Даалгаврын жагсаалт (20/хуудас)
   - Тестийн жагсаалтын үзүүлэлт (50/хуудас)

3. **GraphQL эсвэл API fields select:**
   - `/auth/me` → дахь dataнүүлгүүлэх авсын балыг үзүүлэх
   - `/tests` → варианттай шалгалтын эргүүлэлт

---

## **UX Patterns**

1. **Skeleton Loading:** Хуудас ачаалж байхад placeholder үзүүлэх
2. **Infinite Scroll эсвэл Pagination:** 50+ мөрийн жагсаалт
3. **Undo/Retry:** Алдаатай үйл явцын дараа дахин оролдох товч
4. **Toast/Notification:** Амжилтгүй/амжилттай үйл явцын мессеж
5. **Modal Confirmation:** Муу үйл явц (төлбөр баталгаажуулалт) завсрын
  таниулга

# 💡 УРАМД СҮҮЛИЙН СОНГОЛТЫГ

Шалгалтын "Хувилбар А/Б" логик нь **сэргээхэд тулгуур** байх:
- Сурагч нь зөвхөн өөрийнхөө хувилбарыг харна
- Багш нар A ба B хоёуланг нь үзэнэ
- Хэрэв B хувилбарыг нэмсэнгүй байвал A-г харна

Энэ логикыг **frontend-ээ** (колапс өмнөхөөс) хийхэд сөргө байна —
баглашуулан дээр хийлгээ.
