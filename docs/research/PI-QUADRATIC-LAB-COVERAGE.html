Хүүхдийн таван зам

  1. Танхим: утасгүй номын ажил → гэрт анхны тэмдэглэл → засвар → B даалгавар → материал → багш.
  2. Нөхөлт: ирцийн шалтгаан → тухайн өдрийн онол → оноосон A хүрээ → B → тусдаа нөхөлтийн материал. Ирцийг өөрчлөхгүй.
  3. Вебээр бие даалт: онол → A-ийн шууд оролдлого → алдаа, эргэлзээ → B-ийн шинэ нөхцөл → давтлага.
  4. Өөрийн давтлага: 10/30/60 минут эсвэл тоо → шинэ/алдаа/хуучин багц → үр дүн.
  5. Долоо хоногийн шалгалтын загвар: нээгдээгүй/идэвхтэй/хаагдсан → хугацаат оролдлого → зөвхөн дууссаны дараа үр дүн. Жинхэнэ live сервер биш.

Багш/эцэг эхийн цонх, эрх, фото, төлбөр, network болон виртуал дараах өдөр нь загвар. Бодит интеграц, 5000 хэрэглэгчийн ачаалал, ангийн хүүхдийн туршилт одоогоор хийгдээгүй.

Wilson et al.2019: Eighty Five Percent Rule

Тодорхой хоёр ангилалтай, градиентаар суралцах загваруудын хувьд ойролцоогоор 85% сургалтын зөвийн хувь оновчтой гарсан.

Хязгаар: Монголын математикт бүх хүүхэд, бүх бодлогод 85% байлгах хүний хээрийн туршилт биш. Зохиогчид: Wilson, Shenhav, Straccia, Cohen.

Сонголтын дүрэм нь дээрх судалгаанаас шууд батлагдсан хувьчилсан алгоритм биш. Багшийн хяналттай турших дүрэм. 85% зөвийг бүх хүүхдийн зорилт болгохгүй; 1/3/7 хоногийг нийтлэг зөв хуваарь гэж үзэхгүй.
