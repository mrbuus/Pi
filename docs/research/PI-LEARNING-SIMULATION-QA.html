Юуг ажиллуулж үзэв?

  • Шугаман тэгшитгэл, өгүүлбэртэй бодлого, огторгуйн вектор × зургаан сурагчийн дүр: 18 бүтэн урсгал. Дараах өдрийн виртуал шалгалт хүртэл дуусгасан.
  • 528 генераторын гаралтын хариуг эх тэгшитгэлд орлуулах, өгүүлбэрийн тоон холбоо, векторын дүрмээр тусдаа тооцож шалгасан. Ижил бүтэцтэй хувилбарууд орсон; 528 өөр чадварын бодлого гэсэн үг биш.
  • Таасан, тусламжтай, дутуу, санахгүй болон хоосон хариуг ялгаж бүртгэх. Бүх хариу хоосон үед чадварын 0% гэж дүгнээгүй.
  • Анхны хариуг бодолт харсан дараах засвар болон шивэлтийн засвараар солихгүй. Өмнөх/дараах утга, шалтгаан, тусламж түүхтэй үлдэх.
  • Давхар даралт нэг анхны оролдлого үүсгэх. Шинэ давтлагад оролдлогын шинэ ID ашиглаж, хуучин түүхийг хадгалах.
  • Сан хүрэлцэхгүй, сэдэв сонгоогүй, тохирох хүндрэлгүй үед ил тод жижиг багц эсвэл «олдсонгүй» гэсэн үр дүн гаргах.
  • Reload, локал тасарсан төлөв, JSON экспорт, тэмдэглэл дотор HTML-г текстээр харуулах, 320px/390px дэлгэцийн халилт, keyboard focus, sticky цэсийн доорх гарчиг.
  • Шинэ шалгах бодлогын дүн/бодолтыг багц дуусахаас өмнө интерфейст харуулахгүй.
