## 3. 🔴 SMS АЮУЛГҮЙ БАЙДАЛ — CRITICA АСУУДАЛ

### Нөхцөл
- **~359 сурагч, ~~30,000 боломжтой**
- SMS нь **МӨНГӨ ТӨЛӨХ, БУЦААХ БОЛОМЖГҮЙ**
- Админ & TEACHER_PLUS хоёр л хандалт (nav-data.ts мөр 75, 93)

### АЮУЛГҮЙСАН БАЙДАЛ ҮНЭЛГЭЭ

#### ✅ **Төгсдөг:**
1. **Баталгаажуулалтын диалог:** SmsSend.tsx мөр 147-182 → хүлээн авагчдын тоо, мессежийн хэсэг, өртөг харуулж баталгаажуулна
2. **Мөнгөний сэрэмж:** Үнэлгээ endpoint (`/sms/bulk/estimate`) эхлүүлэхийн өмнө дуудагдаж, админ УРЬДЧИЛЖ мэдэнэ
3. **Draft→Start хоёр алхам:** Бөөн илгээлтийг DRAFT-д үүсгээд, эхлүүлэхээр дэр ОРУУЛНА (идэвхгүй нийслэлээр устаж болно)

#### ❌ **НҮХҮҮД:**
1. **Recipient Filter ЯХ ШИД:** 
   - SmsSend.tsx мөр 93-103: textarea-д утасны дугаарыг таслал/мөрөөр оруулна
   - **АСУУДАЛ:** Аль дугаар хүчинтэй, аль давхардсан болохыг оруулахын ӨМНӨ харуулахгүй
   - Гэхдээ баталгаажуулалтын диалог нь deduplicated count харуулна (мөр 156)
   - **Үр дүн:** Админ 500 утасны дугаар oруулсан, баталгаажуулав, гэхдээ 50 нь хүчингүй бол 450-д илгээнэ — сэтгэлгүй хулгайлал энд байхгүй ч ҮЗҮҮЛЭЛТ дутуу

2. **DRY-RUN / PREVIEW ДҮҮ БАЙХГҮЙ:**
   - Баталгаажуулалт → идэвхжүүлэлт нь АДИЛХАН мөр
   - Админ "Баталгаажуулж явуулах" даралтаар **шууд явах ёстой**
   - Дахь алхам байхгүй: "эхнээс урьдчилан харах" гэх зүйл ДҮҮ БЭ

3. **Админ UI-д role-gating ДҮҮ:**
   - `web/src/components/sms/SmsSend.tsx` нь **ЯМАР Ч ROLE ШАЛГА ДҮҮ БЭ**
   - Мөнгийн эрх: `/app/sms` маршрут өөрөө (nav-data.ts) ADMIN дээрхрүү дэмжигддэг, гэхдээ
   - **⚠️ Хэрэв TEACHER_PLUS адрес хүүхэлхэлэлээр /app/sms руу орвол → компонент асарч ЭХЛҮҮЛЭХ хүсэлтийг явуулж болдог, сервер л шалгана**
   - Дутаа: UI дээр `useEffect` → me() → роль шалгаж, нэвтрэлцүүлэх

4. **Idempotency АСУУДАЛ:**
   - `api/src/notifications/sms-management.service.ts` мөр 202-206:
   ```typescript
   if (batch.status !== 'DRAFT') {
     throw new BadRequestException(`Batch нь DRAFT байх ёстой, одоо ${batch.status} байна`);
   }
   ```
   - **АСУУДАЛ:** `/sms/bulk/:id/start` endpoint нь ИДЭВХЖҮҮЛЭЛТ СЭРГЭЭ ОРУУЛДАГГҮЙ. 
   - Сценарий: админ "Явуулах" даралтаас сүлжээ таслан → response ирэхгүй → админ дахин даралтаж болно → дарахайхсна "Batch үхнээ DRAFT байхгүй" гэнэ
   - **Үр дүн:** SMS АЛЬ ХЭДИЙН явсан (эхний хүсэлт амжилттай байсан), админ буцаа алдаа авч "найцдаагүй" гэж боддог
   - **Засал:** `idempotencyKey` эсвэл `status = 'SENDING' → SENDING_CONFIRM` хорин-бараж доголдол (бодлого: бусад хэлтсээр 2 дахь start авсан)

### SMS-ийн Аюулгүй Байдлын Үнэлгээ: **ДУУТАЙ АЮУЛГҮЙ (2 АСУУДАЛ ЗАСАХ ХЭРЭГТЭЙ)**

// Эм залруулж сеттэ DRY-RUN endpoint
