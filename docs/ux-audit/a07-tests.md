## ⚠️ АЧААЛАЛ: 10,000 Нэгэн Сурагч

### Үзэгдэл
STATUS.md §9.2: k6 load 2,000 зэрэг бара **БАТАЛГААЖУУЛААГҮЙ**. Нь 30,000 сурагчийн 10,000 зэрэг нэгэн суралцаа.

### Асуудал № 1: Нэгэн Суралцаа Spiking

**Үр дүн:** Шалгалт эхэлхэд / дуусахад 10,000 сурагч НЭГЖЭЭР хүсэлт явдаг.

| Үйл явдал | API | Дараалал | @10k | Сэрэгдүүлэлт |
|---|---|---|---|---|
| Шалгалт эхэл | GET /tests/{id}/session/start | 1 дахь | **10,000 заалт** | ✅ Хүнгэн холбоо |
| Хүрүүлэх | POST /tests/{id}/submit | Тогтсон цаг ± 30с | **~333/сек** | ⚠️ Spike 1,000+ / load |

**Утга:** Прод базан 15 сек-д 10,000 INSERT / UPDATE / SELECT-ийг сүүлүүлэх ёстой. Дуусгахад 30с, 30-50 с өмнөх spike.

### Асуудал № 2: Зэрэгцүүлэн Хөгжүүлэлтийн Дараалал

Энд хамт ажиллан хүсэлтүүдийн урсгалын хөндлөнө — **дөрвөлжин нөлөө**:

```
hearbeat (20s) → autosave on answer
    │
    └──→ 10,000 зэрэг
         @secondsLeft=3600±1: 
         heartbeat_1, heartbeat_2, … heartbeat_10000
         → сервер дараалал

autosave (1.2s debounce per answer)
    │
    └──→ Сурагч өмнөхтэй 3 хариул/мин (шалгалтын дээлий)
         @10k:  300 save/sec × 10,000 = 3,000,000 хүсэлт 
         (энэ нь АЙМШИГТАЙ)
```

### Хүсэлтийн Үндсэн Эх Дээрээ

| Эх | Давтамж | @10,000 | Тайлбар |
|---|---|---|---|
| **Heartbeat** (20с ±20% jitter) | 1/20s | 500/s | `setInterval` бүрд шинэ jitter |
| **Autosave** (1.2s debounce) | ~3/мин/сурагч | 500/s | Хариулт өөрчлөгдөхөд 1.2с дотор |
| **Initial load** | 1×/сурагч | 10,000 зэрэг | GET /session/start |
| **Submit** | 1×/сурагч | ~333/s | Цаг дуусхад / USER click |
| **Review load** | 1×/сурагч | ~167/s | POST дараа GET /review |

**Нийт:** Spike үед 500 + 500 + 333 = **~1,333 жинхэнэ API дуудлага/сек**, нэмж retry + jitter.

### Үндсэн Идэвхлэлүүд

**1. Heartbeat-д Jitter БА**: ✅ Байна  
   - `const jitteredDelay = () => HEARTBEAT_MS * (1 - JITTER + Math.random() * 2*JITTER)`
   - Тик бүрд **ШИНЭ** jitter (нэг удаа биш, сайн)
   - **Score: САЙН** — thunder herd үүсэхгүй

**2. Autosave-д Jitter**: ❌ БАЙХГҮЙ  
   - `const SAVE_DEBOUNCE_MS = 1200` (үл өөрчлөгдөх)
   - **Асуудал:** 10,000 сурагч нэг адилхан timing-д 1.2с ухвал хичээллүүлнэ
   - **Score: МУУ**

**3. Submit-д Jitter**: ❌ БАЙХГҮЙ  
   - Таймер дуусхад: `setTimeout(() => void finish("TIME"), 0)` — үнэмлэхүүлж явдаг
   - **Score: МУУ** — Spike 100% өмнөхтэй таатсан

**Нийтлэг Сэрэгдүүлэлт:**
- Retry backoff: ✅ `exponential: 2000→30,000ms + jitter` — сайн
- Keepalive: ✅ `90s бүрт` (хүн үгүйлүүлэхэд) — сайн

### Сүүлэгдэл Холбоо (Оруулга байхгүй)

```javascript
// Үл сайн: 1.2s дөрвөлжин autosave спайк
SAVE_DEBOUNCE_MS = 1200  // ← бас jitter үүсгээрэй

// Үнэмлэлтэй сайн: heartbeat jitter
HEARTBEAT_JITTER = 0.2   // ← энэ нь зөв хэмжээ

// Үл сайн: submit natively synced
finish("TIME") → setTimeout(..., 0)  // ← +jitter нэмнэ
```

## Багш Үзүүлэлт: 30 Сурагчийн Шалгалтыг Авуулжээ

### Үүлгэ

30 сурагч нэг байлдан сургууль эхэлж, 90 минутыг авж яв.

1. **Харуулт (3 мин):** Шалгалт интро, нэвтрэл гэх мэтэй 30 НЭГЭН GET /tests/{id}
   - Шинэ орон: 30 шалгалт идэвхтэй эхэлэнэ, үэх дараа алгалиагаа үзэх заалт
   - Шалгалт: Шалгалт идэвхтэйгээр байна

2. **Авалт (87 мин):**
   - Heartbeat 20s бүрт × 87м ≈ 260 дуудлага/сурагч = 7,800 дуудлага нийтлэг
   - Autosave: ~3 хариул/мин × 87м = 260 хадгалах/сурагч = 7,800 дуудлага нийтлэг
   - Нийтлэг: **15,600 API дуудлага, 87 мин = 3 дуудлага/сек** ✓ сүүлтэй
   - Мөрт: өмнөхөө дараалал ямар нэгээ сүрлүүлхэнтүэг явзалн, гадаад рэ үл сайн
   - **Тайлбар:** Одоо 30 сурагч, гэхдээ 10,000 дуудлага 10 мин дахь үх дуудлага (initial) байвал муу. Үл мөрс.

3. **Дуусгалт (2 мин):** 30 НЭГЭН POST /tests/{id}/submit
   - 30 хүсэлт 2 мин-д = 15/сек ✓ сүүлтэй
   - Гэхдээ 30 нь дарамт биш. 10,000 нь дарамт.

4. **Үзэх (5 мин):** GET /tests/{id}/review × 30
   - 30 дуудлага 5 мин-д = 6/сек ✓ сүүлтэй

### Сүүлэгдэл

30 сурагч авах нь **сүлтэй**. 10,000 нь **үл сүлтэй**.

Анхааруулга:
- ⚠️ Spike эхэл: 10,000 × GET /session/start в өмнөхтөөг гашуугараа **үл байна**
- ⚠️ Spike дуусгалт: 10,000 × POST /submit-д **үл байна**
- ⚠️ "Саадаас гаралт" (leave) механизм 30 сурагчийн хялбар үл байлал
