## III. MathText.tsx-ийн засварын үнэлгээ — Ирээдүйн эсхүл дат эвдэх

### Регексүүдийн үнэлгээ

#### 1. **POWER_RE** (41-р мөр)

```typescript
/([a-zA-Z\u{1D400}-\u{1D7FF}])(?:\^\{?([+-]?\d+)\}?|\s?(\d))/gu
```

**Байршил:** Доод индекс (subscript) дэмжиж чадахгүй тул "x2" → "$x^{2}$" → "$x_2$" зэрэг алдаа болж магадгүй.

**Ирээдүйн эрсдэл:** 
- "f(x23)" ба "f(x^{23})" холилдохдоо тэмдэгтэ алдаа  
- "мар2" (англи код) ба "март 2" холилдох

**Үнэлгээ:** ✅ **Сол давхарга дээр ажиллахад зөв.** Дэлгэцийн засвар болхоос илүүтэйгээр ОС-д хадгалагдсан дата эвдэлгүйгээр үлдсэн байна. Docx импортын эпизодик алдаа (x2 → x^2) л засдаг тул **нэвтрүүлэх утга хяналтагүй**.

**Мэдэгдэж буй хязгаарлалт (заалтад зөв):**
- Хоёр оронтой зэрэг (x23) зөвхөн эхний цифр авна  
- Доод индекс огт дэмжигдэхгүй  
- Кирилл үсэг + цифр ихэвчлэн аюултай

#### 2. **DIMENSION_RE** (55-р мөр)

```typescript
/\d+\s*[xх]\s*\d+/gi
```

**Байршил:** Номын цуврал нэр ("100x100", "200 x 200") хосолсон давтамжийг сүүлүүдээ хэзээ л эвдэхгүй.

**Үнэлгээ:** ✅ **Авч сахина.** Private Use Area тэмдэг (U+E000) POWER_RE-д гулсалгалгүй байна.

## IV. Онолын контент — Хэцүүлэлтийн судалга

### 4.1 Хэцүүлэлтийн бүдүүргүүлэлт

| Сурсан хэлбэр | Байршил | Хэцүүлэлт |
|---|---|---|
| **Markdown** (теория) | `/app/learn/[chapterId]/page.tsx` → `SafeMarkdown` | $...$, $$...$$ LaTeX ҮЛ дэмжинэ (тэхалхалд нэмэгдсэн) |
| **LaTeX эхлээд** (бодлого) | `/app/library/page.tsx` → `MathText` | $...$, $$...$$ дэмжинэ |
| **Онолын редактор** | `/app/admin/theory/page.tsx` → `TheoryEditorClient` | Markdown ввод → ӨС дээр JSON хадгалагдана |

**СУМБУР:** Багш "Онолыг засах"-т Markdown бичдэг. Дараа нь тэр Markdown текстэнд **ямар ч $…$-г шууд оруулч болохгүй** (фронтенд `SafeMarkdown`-д дэмжигдээгүй). LaTeX томьёо хүсвэл шинэ `Markdown` тохиргоо хэрэгтэй.

### 4.2 Сурагчийн утга

Сурагчийн орон: `/app/learn/[chapterId]/page.tsx` → `SafeMarkdown({content})`.  
Markdown МӨРӨЖ байхдаа `MathText` **хариулалтын нэг мөрөөр** дуудагдана (inline/bold/italic дотор).

**Загварчилсан дараалал:**
1. `SafeMarkdown` → MarkdownBlock[] задлана
2. Inline `renderInline` → MathText($...$ хүүхэлтэй)
3. KaTeX → HTML

**АЮУЛГҮЙ ТЕХ:**
- `dangerouslySetInnerHTML` **зөвхөн KaTeX гаралт** дээр
- Холбоос ЗӨВХӨН http(s):// эхлэнэ
- Зураг өвдөлцүүлсэн ImageKeys → `fileUrl()` токены хамт
