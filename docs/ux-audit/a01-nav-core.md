## 5. Роль гэйтинг — сервер ба клиентт

### ✅ Сервер (шилдэг)
- API endpoint бүр `@Roles` decorator-оор хамгаалагдалтай
- NestJS `RolesGuard` ашигладаг
- 401/403 буцаадаг эрхгүй хүнд

### ⚠️  Клиент (хамгалта, гэхдээ эргүүлсэн)
- `RequireRole` компонент цэсээр холбоосгүй маршрутыг үл үзүүлэх
- Гэхдээ URL шууд бичиж `/app/admin/students` очиж болохгүй (RequireRole нь "Хандах эрхгүй" харуулна)
- **Сайн:** Жинхэнэ хамгалалт СЕРВЕР дээр байдаг; клиентт зөвхөн UX gate юм
