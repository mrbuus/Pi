## II. Сонинчилгээний зөрүү: `/app/insights` vs `/app/admin/analytics`

### Зорилго ба төрөл

| Үзүүлэлт | InsightsDashboard | AnalyticsDashboard |

| **Фокус** | Нэг шалгалтын хэвлэл үнэлгээ | Үйлчлүүлэгч, анги, сэдвийн тренд |

| Үзүүлэлт | InsightsDashboard | AnalyticsDashboard |

## III. Эзний тусгай асуулга: Ангийн түүх ("өмнө нь тэр өдрөөс тэр өдрийн хооронд энэ ангид ингэж сууж байсан")

### Зорилго
Эзэн татан авахыг хүсэж байсан: **сурагч X 2026-08-01 ~ 2026-08-15 хооронд 11-А ангид сууж байсан, дараа нь 11-Б-д шилжсэн—хэн шилжүүлсэн, яагаад**

### Өгөгдөл эх сурвалж

**ӨС схем:**
```prisma
model Enrollment {
  studentId    String
  classroomId  String
  enrolledAt   DateTime    // Нэвтрэлтийн цэг
  leftAt       DateTime?   // Орхисон цэг (null = одоо сууж байгаа)
  movedById    String?     // Хэн шилжүүлсэн ADMIN ID
  @@index([studentId, leftAt])
}

model AuditLog {
  id        String
  entity    String      // "Enrollment"
  entityId  String
  action    String      // "CREATE", "UPDATE", "DELETE"
  before    Json?       // Өмнөх утга
  after     Json        // Шинэ утга
  reason    String?     // Админ "яагаа" гэсэн бичлэг
  actorId   String      // Хэн хийсэн
  actorRole String      // ADMIN, TEACHER_PLUS
  at        DateTime    // Үйлдлэлийн цаг
}
```

### Одоогийн дэлгэцийн боломж

**AuditClient.tsx (мөрүүд 110–231):**

1. ✅ **Шүүлтүүр** — entity, actorId, action, from/to огнооны эргүүлэлт
2. ✅ **Бичлэгийн дүрслэл** — `row.action`, `row.entity`, `actorName(row.actorId)`, `row.at`
3. ✅ **Сэлгэгч** — `row.reason` (админ бичсэн шалтгаан)
4. ✅ **Диф үзэгч** — `<AuditDiff before={row.before} after={row.after} />` ашигла

### Ашигласан замын төлөвлөгөө

**Өнөө өдрийн адил, зүйлийн нэр "Enrollment" дээр шүүлтүүр:**

```
1. AuditClient → Шүүлтүүрийн entity = "Enrollment"
2. Optional: entityId = сурагчийн ID / ангийн ID
3. Optional: from/to = 2026-08-01 ~ 2026-08-15
4. Дараа дохиолдуулэхэд:
   - Action="CREATE" → Орно гүйлгээ (ангид орох)
   - before/after диф-д classroomId солигдлыг харна
   - movedById ба actorName()-ээр "хэн шилжүүлсэн" бэлэг
   - reason-нээс "яагаа" сонирхогч
```

**Хэрэглэгчийн харуулалт:**

```
[Enrollment] · CREATE · Батаа · Админ Эмүжин · 2026-08-01 09:15
  Шалтгаан: Түр сайн сурч эхэллээ → 11-Б-д шилжүүлэв
  
  До:      (없음)
  Дараа:   classroomId: "11a" → "11b"
           enrolledAt: 2026-08-01
           leftAt: null
           movedById: (null)
```

### ӨНЦӨГ ХҮНДРЭЛ: Сэлгэгчийн үр дүн

**AuditDiff компонент хэлбэр:** 
- `before` болон `after` JSON объект буцаана
- Байхгүй байсан мөрүүд эс эхний JSON 
- **Жүжиг:** JSON `null` ≠ SQL NULL → `movedById` дээрх "байгаа" болон "байхгүй" эргүүлнэ

**Мөнгөн сүүлийн алдаа (STATUS.md §8.5):**
```sql
WHERE choices::text='null'  -- Prisma JSON null дээр дүрслэл
```

Гүйцэтгэлээ юу: `AuditDiff.tsx` нь бэлэглэлтийн JSON утгуудыг цэвэрлэдэг уу, эсвэл оруулс ганц **дараа** сонголтоор оруулны байхгүйсэн үр дүн үрийл.

### Үр дүн: Ангийн түүх тулгасан идэвхжүүлэхээр БАЙНА

✅ **Ансаатуул:** Аудит лог бүтэлгүй ошигланхайг сүүлүүлс дүрслэл муу заасны дотор.

⚠️ **Хөшиг:** 
1. Шүүлтүүрийн UI-д "Enrollment" сонголтын дүлийцдүүлэхгүй бү (одоо dropdown нь entity бүхний жагсаалт)
2. `classroomId` өмнө/дараа-ыг цэвэр ишээсдүүлнэ — `before/after` JSON дотор эвддэл

**Дээд түвшний үнэлгээ:**
- 80% дүрслэлдүүлэхээр байн → 3–4 мөргөн добан хүүхдэл (JSON цэвэрлэл, dropdown)

## IV. Мэдээлэл ба үзүүлэлтийн цоорхойн шалгалт

### Эзэн сонголтоо шаардсан утгалуу

"Ангидаа ямар түстэйн идэвхтэй · сурагчийн эрсдэл · сэдвийн амжилт · багшийн ангийн үндэслүүлэлтүүдийг харна"

### Одоо эмхэтгэлгүй

1. **Ангийн үндэслүүлэлтүүдийн шалгалт** — AnalyticsDashboard нь ангийг "оролцоо %"-аар ангилдаг, гэхдээ:
   - ❌ Даалгавар биш: ангийн **цуртуулалт** хэвлэлүүлэнгүй
   - ❌ Сэдвийн **амжилт** нь чацын ангидах заводчлүүлэнгүй

2. **Багшийн үндэслүүлэлтүүдийн биртүүлэлт** — TEACHER ээс:
   - Нэг ангийн идэвхийн үзүүлэлтүүдийг `ActivityService` дотор уруу зөвхөн `/app/teacher` дээр (sidebar алда)
   - Admin-ийн "ангийн ҮНДЭСЛҮҮЛЭЛТҮҮДИЙН жагсаалт"-д эд гүйцэтгэгч

3. **Сурагчийн эрсдэлгүй логикэл дүрслэл**:
   - ✅ AnalyticsDashboard `at-risk` сурагчид (`/analytics/at-risk?days=7`)
   - ❌ Энэ үзэгч: утга мэдээлэл яагаа хоцроо, хэд хоног, хэн тэндээ идэвх хайх

### Цоорхойсог мөрүүдийн дүрслэл

| Юу | Одоо | Хэрэгтэй |
|---|---|---|
| **Ангийн үр дүн трэнд** | Эсгүүлэн нэг өдөр | Аль анги уруу сахирлаж эхэлсэн, хэзээ |
| **Сэдвийн амжилтын ангийн дүрслэл** | Глобал ("сулшерхий" гэсэн шалтгаан) | Ангидаа сэдвийн үнэ судалгаа—нэгжийн хүрээ |
| **Bagsh-ийн цоог бага эцсэх** | Байгаа (11-А: 8/12 сурагч) | «11-А-н И. Сонгол: 8/12 сурагч идэвхтэй» |
| **Энгийн эрсдэлтүй логицлүүлэлт** | 7/14/30 хоногийн товчлол | "XX сурагч 21 хоног идэвх сулхайрсан — X хичээлгүй" |
| **Сэдвийн урвалжилгээ** | Шалгалтын дараа InsightsDashboard | Оператив Analytics дээр дүрслэлүүлэнгүй |

## VIII. Үр дүн ба санал

### A. Insights vs Analytics: Сонголт

| Сонголт | Нэрлэлэл | Гашилтүүлэлт |
|---|---|---|
| **1. Сунгах** | InsightsDashboard → API (+endpoint) | +2 сар ажил, дүхүүлэн даалгаварты |
| **2. Салгах** | Одоо байн InsightsDashboard; орон дотор холбоос | Цэсүүл хэвлэл (хоосон хүүхэлтүүдийн дүн шинжилгээ) |
| **3. Нэгдэх** | Insights→Analytics-д буулгах (шалгалтаар шүүлтүүр) | +1 цэс, яргалал компонент |
| **4. Устгах** | InsightsDashboard алгасах | Хүүхэлтийн дүн шинжилгээ алга |

**Сүүлийн шалт:** **#2 (Салгах)** эсвэл **#1 (Сунгах)**. Insights нь ялгагдсан зорилго юм. Хэвлэлгүй байвал байхгүй байн.

### Б. Аудит лог: Ангийн түүх хүрэхээр **гашилтүүлэлтүүдэл**

✅ **Болно:** Enrollment өөрчлөлтүүл AuditLog-д үлддэг. AuditClient нь шүүлтүүр, диф-г харуулдаг.

⚠️ **Асуудал:**
1. Мөрөн сонголт дүрслэлүүлэлтэй (JSON before/after)
2. UI нь "Enrollment-ийг сонгоно" dropout-г сайхан зааладаггүй

**Шиг залруулалт:**
- `AuditFilters.tsx`: entity dropdown дээр "Enrollment — Ангидаа орох/гарах"
- `AuditDiff.tsx`: JSON-г цэвэрлэхэд classroomId-ийн "11-А → 11-Б" гэсэн сайхан гашилтүүлэлт

## IX. Хүнд ба хөнгөн сонголтүүдийн хүл

## 12-МӨРГӨН ХУРААМЖ

1. **Insights vs Analytics:** Ялгагдсан зорилго (хүүхэлтийн дүн ба оператив тренд). Insights сунгалт дээрх **сонголт**, эс нэгдэх. API дутуу, мокап л.

2. **Ангийн түүх:** Аудит лог-д байн (Enrollment, classroomId солигдол, movedById-ээр "хэн"). UI gashiltuuleltüüdel (dropdown сонголт, JSON цэвэрлэлт). 2–3 цагийн сунгалт.

3. **Хамгийн үзэгдэх цоорхой:** Ангийн үр дүн **тренд** ("10-Б анги огноо дараа 45% → 38%"). Сэдвийн амжилт **анги бүр** (одоо глобал). Эрсдэлтэй сурагч **шалтгаан** ("21 хоног идэвх сулхайрсан").

4. **Цэсийн сонголтүүдийн хүл:** ADMIN/TEACHER_PLUS-д 2 сонголт идэвхтэй (Аудит, Аналитик). Insights сунгалтын дараа **3 сонголт** байх. Орон дотор холбоос (шалгалтын дараа Insights-д орох) байж болох ч sidebar сонголт юунээс сайхан.
