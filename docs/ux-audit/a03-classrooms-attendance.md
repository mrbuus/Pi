## 1. Ирцийн урсгал эцэсээр дагалдуулсан

**Анхны түлхүүр:** Хуанли сонгох нь цөөхөн зүйл биш — хичээлийн хуваарийн дүгнэлтээс ирцийн хуудас хүртэл 5 алхам. Нэр дээр "Ирц" гэж бичэгдээгүй л дээ.

### Өнөөдрөө ирцийг бүртгэх — 5 алхам (сонголт холимог)

**Эхлэл:** Bagшийн самбар (`/app/teacher`) → "Ирц" таб

1. **Санхүүгийн цэс дээр ирцийн хэсгийг олох** — `TeacherDashboard`-д "Ирц" таб бүхэлдээ байна; сахилгын дарга тэнийг олвол:
   ```
   web/src/components/TeacherDashboard/AttendanceSection.tsx
   ```

2. **Бүх сурагчийн жагсаалт авахыг хүлээх** — Компонент нь `/classrooms/{id}/attendance?date=YYYY-MM-DD` дуудаж API-аас ЦОХИЛТОО сурагчдын энэ өдрийн статусыг авна.
   - Жагсаалт эхлээд **өнөөдрийн** төлөвтэй ирнэ (эзний шийдвэр: сонгосон өдрийг нүүр таб дээр АВАХГҮЙ).

3. **Сурагч тус бүрийг "Ирсэн" / "Хоцорсон" / "Тасалсан" / "Чөлөөтэй" сонгох** — 4 товчноор баттай зөвхөн нэг статус сонгогдоно.
   - **Зүлхүүн зүй:** Хуцорсон сонгоход `LateRangePicker` (5–10 минут гэх мэт) гарна.
   - **Тайлбар** (жишээ нь "гэрээсээ хожуу гарсан"): `NoteAutocomplete` дээр бичнэ.

4. **Бүх 30-50 сурагчийн статус баталгаажуулах** — Эзний үг: "Хэрэглэгч сурагч тус бүрийн мөр рүү НЭМЭЛТ товч дарах ёстой байх үед л сайнаа. Энэ нь нэг хадгалалтад 5 сурагч = 5 дараалал".
   - **Одоогийн холимог:** Барилгын товч (`StatusPills`) нь сурагчийн мөрийн ДООР байгаа; эсвэл баруун талд модульт байхыг өргөмжлүүлсэн.

5. **"Хадгалах" товч дарах** — Нэг `POST /classrooms/{id}/attendance` дуудалт бүх 30 сурагчийн статус + тайлбарыг нэг дахиад илгээнэ.
   - Хадгалалт амжилттай болвол `Attendance` хүснэгтэд `INSERT/UPDATE`, **мөн** `DailyClassSummary` автоматаар нарийвчлагддаг.

```
┌─────────────────┐
│ Самбарын "Ирц" │
└────────┬────────┘
         │
    1 дарах
         │ (Шалгалт: өнөөдрийн жагсаалт)
         ▼
┌──────────────────────┐
│ Сурагчдын жагсаалт  │
│ (30 сурагч эргүүлэх)│
└────────┬─────────────┘
         │ 
    30 дараалал
    (тус бүрт товч дарах)
         │
         ▼
┌──────────────────────────┐
│ Бүх статус баталгаажаа  │
└────────┬─────────────────┘
         │
    1 дарах ("Хадгалах")
         │
         ▼
  API амжилттай
  (Attendance INSERT)
```

**Эрхэм:** 5 алхамын 3 нь "сурагч тус бүрд товш".

## 2. Хүссэн хялбарлалт — 3 алхам

Эзний шаардлага (STATUS.md §7.1): "Элементүүд нь объектын хажууд байх ёстой" = мөр дээр шууд дэргүүлэх.

```
┌──────────────────────────────────────────────┐
│ Сурагчдын жагсаалт (30 мөр)                │
├────────────────────────────────────────────┤
│ 1. Гантөмөр Анар  [Ирсэн] [Хоцор] [Тасалсан] │
│ 2. Эмүүжин Уж     [Ирсэн] [Хоцор] [Тасалсан] │

2. Бүгдийг баталгаажуулах (нүдээр дуу сонго)
```

## 4. Багтаамжийн цоорхой

**Эзний Excel-д:** "Багтаамж" (42 хэн, жишээ) · "Үлдсэн суудал" (8 үлдсэн)

**Prisma schema `Classroom`:**

```prisma
model Classroom {
  id                String        @id @default(cuid())
  name              String
  type              ClassroomType
  grade             Int?
  teacherId         String?
  teacher           User?
  archived          Boolean
  createdAt         DateTime
  progressChapterId String?
  
  // ❌ BАГ ТАЛБАРУУД (capacity, maxSeats, freeSeat зэрэг БҮҮ)
  enrollments       Enrollment[]
  attendances       Attendance[]
  ...
}
```

**Схема нэмэх хэрэгтэй:**

```prisma
model Classroom {
  // Хамгийн оршин суудлын эвхэлт
  capacity          Int?          // null = хязгаараа; 42 гэх мэт
  
  // Үлдсэн суудлыг тоолох — энэ мөнжид `SELECT COUNT(*) FROM Enrollment WHERE classroomId = X` —
  // галь хүндрүүл. Компонент дээр `_count: { enrollments }` авч `capacity - count` тооцоно.
}
```

**Хаана хэрэглэх:**
- Ирцийн жагсаалтын толгойд "35/42 суудал бүтэлтэй" гэж харуулах
- Элсэлтийн админ UI дээр: "Энэ анги 5 суудал сул"
- `/admin/classrooms` дээр (дээр дараа) оруулав
