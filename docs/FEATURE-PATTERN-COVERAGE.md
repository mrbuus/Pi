# v0.7 · Feature бүрийн жишиг ба судалгааны хамралт

2026-09-24. 82 зураглал бүгд бүртгэлтэй. Энэ нь зураглалын түвшний coverage; бүх товч, хувьсагч, платфомыг туршиж дууссан гэсэн үг биш. Нэг source олон workflow-д UI зарчим өгч болно; тэр source манай бизнес дүрмийг шийддэггүй.

## 3. Дараагийн user test

Туршилтын зорилго, хугацаа нь санал: 3 багш + 3 сурагч + 2 эцэг эхтэй даалгавар шалгах, төлбөрийн статус ойлгох, маргаашийн хуваарь засах, алдсан сэдвээ олох ажлыг өгнө. Ажлыг дуусгасан эсэх, будилсан үг, илүү товшилт, алдаанаас буцсан алхмыг тэмдэглэнэ. Sample нь статистик нотолгоо биш. Эхний прототипийн үр дүн гараагүй тул «best UX» гэж батлаагүй.

Судалгаанд дутуу үлдсэн тодорхой ажил: provider-ийн эцсийн шимтгэл/гэрээ, бүх app-ийн бодит paid flow, calendar-ийн Safari touch/export pilot, full archive Facebook, palette export, simulation чанар/latency, OCR accuracy. Эдгээрийн decision нь implementation-оос өмнө байна.
