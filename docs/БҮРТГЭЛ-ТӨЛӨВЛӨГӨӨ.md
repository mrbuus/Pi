# Сурагчийн бүртгэлийг вэб рүү оруулах — төлөвлөгөө

**Огноо:** 2026-09-09 · **Эх сурвалж:** `ЗҮҮН-4-09.07.xlsx`, `БҮРТГЭЛ-2027-1 (1).xlsx`

---

## 1. Шийдвэр: **вэб дээр хийнэ, Google Sheets-тэй хоёр талын холболт ХИЙХГҮЙ**

Шийдвэрлэсэн шалгуур нь таны өөрийн шаардлага:

> «хүүхдүүд анги өдөр нь солигдоод асуудал гарахад … өмнө нь тэр өдрөөс тэр
> өдрийн хооронд энэ ангид ингэж сууж байсан гэх мэт бүх мэдээлэл нь харагддаг
> байвал их зүгээр»

**Google Sheets үүнийг зарчмын хувьд хийж чадахгүй.** Хүснэгтийн нүд нэг л утга
хадгална. Сурагчийг 12-2-оос 12-4 болгоход хуучин утга **устана**. Sheets-ийн
хувилбарын түүх байдаг ч тэр нь:

- файлын хэмжээнд, бичлэг тус бүрээр биш
- «2026-10-15-нд 12-2-т хэн байсан бэ?» гэж **асууж болдоггүй**
- тайланд оруулах боломжгүй

**Танай өгөгдлийн сан үүнийг АЛЬ ХЭДИЙН хийдэг** —
[`classrooms.service.ts:127`](../api/src/classrooms/classrooms.service.ts):

```ts
// Өмнөх ангийн бичилт хаагдаж шинэ бичилт үүснэ — түүх хадгалагдана
$transaction:
  1. хуучин Enrollment → leftAt = одоо, movedById = хэн зөөсөн
  2. ШИНЭ Enrollment мөр үүснэ
```

Энэ бол **temporal (цаг хугацааны) загвар**. Сурагч бүрийн бүх шилжилт мөр
болж үлддэг тул хүссэн өдрийн байдлыг сэргээж болно.

## 2. Серверийн ачаалал ба аюулгүй байдал

Та «аль нь ачаалал бага, аюулгүй вэ» гэж асуусан. Хариулт нь зөн совингийн
эсрэг: **Sheets холболт нь ИЛҮҮ ачаалалтай**, бага биш.

| | Вэб (өөрийн DB) | Google Sheets хоёр талын |
|---|---|---|
| Нэг дэлгэц харах | 1 индексжүүлсэн query | Sheets API дуудлага + квот |
| Квот | Өөрийн DB, хязгааргүй | Sheets API **минутанд хязгаартай** |
| 30,000 сурагч | Хуудаслалт, асуудалгүй | Квотыг давна |
| Хоёр талын синк | — | Poll эсвэл webhook + **зөрчил шийдэх** логик |
| Хэн зөв бэ (conflict) | Асуудал үүсэхгүй | Хэцүү, чимээгүй алдагдал үүснэ |

Аюулгүй байдлын хувьд:

| | Вэб | Sheets |
|---|---|---|
| Эрх | `Role` (ADMIN/TEACHER_PLUS), `canManageStudents` | Линктэй хүн бүр |
| Талбарын хяналт | Төрөл, шалгалт | Утасны дугаар шинжлэх ухааны тэмдэглэгээ болно |
| Санамсаргүй буулгалт | Батлагдана | **500 мөр чимээгүй эвдэрнэ** |
| Хэн юу өөрчилсөн | `AuditLog` + `movedById` | Файлын түүх, бичлэгээр биш |

## 3. Гэхдээ Sheets-ийн санаанд ҮНЭН зүйл бий

Таны хүсэж байгаа жинхэнэ зүйл нь Google Sheets биш — **Excel шиг хурдан
ажиллах мэдрэмж**. Ажилтнууд Excel мэднэ, сумаар алхаж, хуулж буулгадаг.
Үүнийг вэб дээр өгөх ёстой:

- **Хүснэгт маягийн засварлагч**: сумаар нүүх, Tab, Enter, шууд нүдэнд засах
- **Excel-ээс буулгах** (paste): олон мөрийг нэг дор
- **Excel/Sheets рүү ГАРГАХ** — тайлан, офлайн харах

Гэхдээ **нэг чиглэлд**: `DB → Excel`. Буцаж синк хийхгүй. Тэгвэл Excel-ийн
хурд, DB-ийн бүрэн бүтэн байдал хоёулаа үлдэнэ.

## 5. ХИЙХ АЖЛУУД

### 🔴 A — Схемийн цоорхой (жижиг, эхлээд)

| # | Ажил | Хэмжээ |
|---|---|---|
| A1 | `Classroom.capacity Int?` нэмэх — Excel-д «Багтаамж» гэж хөтөлж байгаа | Бага |
| A2 | Сурагч «Хуучин/Шинэ» эсэхийг тэмдэглэх талбар | Бага |
| A3 | `leftAt` (DateTime) ба `leftOn` (Date) хоёр зэрэг байгааг цэгцлэх — аль нь эрх мэдэлтэй болохыг тодорхойл | Бага, гэхдээ **төөрөгдөл үүсгэж байна** |

### 🟠 B — Импорт (нэг удаагийн)

| # | Ажил |
|---|---|
| B1 | Excel уншиж `User` + `StudentProfile` + `ParentLink` үүсгэх скрипт |
| B2 | «ГАРСАН» хуудсыг `leftAt`-тай импортлох — **түүхийг хадгална** |
| B3 | Давхардал илрүүлэх (утсаар) — нэг сурагч 2 хуудсанд байж болно |
| B4 | Зөв бичгийн шалгалт нэрс дээр (`spellcheck-mn.cjs` + цагаан жагсаалт) |

⚠️ Импортын өмнө: `ЗҮҮН-4` файлд 591 мөр, `БҮРТГЭЛ-2027-1`-д 440+218+220+234
мөр. Салбар бүр тусдаа файлтай тул **нэгтгэхэд давхардал гарна**.

### 🟡 C — Бүртгэлийн дэлгэц (гол ажил)

| # | Ажил |
|---|---|
| C1 | Excel маягийн хүснэгт: сумаар нүүх, шууд засах, Tab/Enter |
| C2 | Шүүлт: анги, салбар, сургууль, төлөв (идэвхтэй/гарсан) |

### 🟢 D — ТҮҮХ (таны гол хүсэл)

| # | Ажил |
|---|---|
| D1 | Сурагчийн хуудсанд **цагийн хэлхээ**: аль ангид, хэзээнээс хэзээ, хэн зөөсөн |
| D2 | «Тухайн өдрийн байдал» — огноо сонгоод тэр үеийн ангийн бүрэлдэхүүн |

байгаа, зөвхөн харуулах хэрэгтэй.

### ⬜ E — Google Sheets (сонголттой, хамгийн сүүл)

| # | Ажил |
|---|---|
| E1 | **Нэг чиглэлд** гаргах: DB → Google Sheet (тайлан) |
| E2 | Товчоор эсвэл шөнө бүр автоматаар шинэчлэх |

**Хоёр талын синк ХИЙХГҮЙ.** Хэрэгцээ гарвал дахин ярина, гэхдээ түүх
алдагдах эрсдэлийг мэдэж байж шийднэ.

## 6. Дараалал

```
A (схем засах)  →  B (импорт)  →  C (дэлгэц)  →  D (түүх)  →  E (гаргах)
   жижиг            нэг удаа        гол ажил      үнэ цэн       сонголт
```

A нь жижиг ч эхэнд байх ёстой — багтаамжгүйгээр C6 хийгдэхгүй, импортын
дараа схем өөрчлөх нь илүү зовлонтой.
