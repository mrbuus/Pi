# Төлбөрийн шийт: бүтэц, дүрэм, логик

2026-11-08. Онлайн «2027 оны төлбөрийн мэдээлэл» шийтийг нүд бүрээр нь зөвхөн уншиж задалсан. Мөн «2027 оны орлого зарлагын мэдээлэл» болон банкны хуулгатай харьцуулсан.

Тоонууд бодит өгөгдлөөс гарсан. Хүүхдийн нэр энд бичигдээгүй.

## 0. Локал хуулбар

- Файл: `api/prisma/reports/tolbor-sheet-local-20261108.xlsx`. Энэ хавтас git-д ордоггүй.
- Хуулсан зүйл: утга, томьёо, тоон формат, бичгийн өнгө, дэвсгэрийн өнгө, нэгтгэсэн нүд.
- Онлайн шийттэй 7 хуудасны **23,526 нүдийг тулгахад зөрүү 0**.
- Туршилт бүр энэ хуулбар дээр явагдана. Жинхэнэ шийтэд юу ч бичигдэхгүй.

Бүлэг бүр гурван баганатай:
- **Төлсөн дүн:** тоо. Заримдаа текст бичигдсэн: «ярьсан», «хэлсэн», «багш», «БҮТЭН», «09/01с өмнө» (12 нүд).
- **Хугацаа:**
   - Ихэвчлэн «MM/DD-MM/DD», төлбөр хамарсан хугацаа.
   - Бүтэн жил бол «бүтэн» гэж бичдэг (318).
   - Хагас жил бол «хагас».
   - Цөөн тохиолдолд «12/20 өмнө» гэх мэт.
- **Баримт:** төлсөн огноо MM/DD. Нэг сард хоёр удаа төлсөн бол **дүнг нэг нүдэнд нэмж**, огноог «09/01, 09/30» гэж залгадаг (278 нүд).

### Бодит өгөгдлөөс батлагдсан дүрэм

- **Бүлгийн сар:** «Хугацаа»-ны эхний сар = бүлгийн сар (757/763).
- **Хугацааны өдөр:** «Хугацаа»-ны эхний өдөр = сууж эхэлсэн өдөр (K) (594/763). Үлдсэн 169-д нь 09/01-ээс шинэ жил эхэлсэн, эсвэл амралтаар сунгагдсан («08/04-09/14»).
- **Төлбөрийг банкны сараар биш, хүүхдийн дараагийн төлөгдөөгүй сараар бичдэг:**
   - 9-р сард орсон 330 төлбөрийн 293 нь «9-10» нүдэнд, 11 нь урьдчилж «10-11» нүдэнд, 10 нь хоцорч зуны нүдэнд бичигдсэн.
   - 10-р сард орсон 280 төлбөрийн 195 нь «10-11» нүдэнд, 52 нь хоцорч «9-10» нүдэнд, 19 нь урьдчилж «11-12» нүдэнд бичигдсэн.
- **Бөглөгдсөн бүлгүүд:** хамгийн түгээмэл нь «9-10, 10-11» (231), «9-10» (197), зөвхөн зун (6-7, 7-8: 88).
- **Бичгийн өнгө:**
   - Ногоон (#34a853) бол хэвийн бичилт.
   - **Улаан (#ff0000) ~40 нүдэнд байна. Утгыг тодруулах хэрэгтэй.**
- **Дэвсгэрийн өнгө:**
   - Саарал (#f6f7f9) нь «Хугацаа» баганын өнгө.
   - **Цэнхэр (#9fc5e7) ~40 нүдэнд байна. Утгыг тодруулах хэрэгтэй.**
- **Нэгтгэсэн нүд:** O:Q, R:T, U:W-г 600 гаруй мөрөнд нэгтгэсэн. Ихэнх нь хоосон, зун суугаагүй сарыг хаасан хэлбэр бололтой.

## 3. Бусад хуудас

- **Сар бүр:** багана нь үндсэн хуудастай ижил. L «Нийт төлсөн» = sum томьёо. Үндсэн жагсаалтын хуучин хуулбар. Синк хоёр хуудсыг нэг сар гэж тоолдог (`cellSlot`).
- **Бүтэн жил:**
   - J:K = Урьдчилгаа (дүн, баримт).
   - L:M = Үлдэгдэл (дүн, баримт).
   - N = Нийт.
- **Нийгэм:**
   - L-ээс эхлэн 3 баганат сарын бүлгүүдтэй.
   - Бүлгийн гарчиг дараалал нь эвдэрсэн: 9-10, 10-11, 8-9, 9-10…
   - J = sum томьёо.
- **гарсан, Илүү төлөлт:** буцаалтын бүртгэл. Сайтын «Буцаалт» хэсэгтэй (`tuition/withdrawal`) холбоотой.

## 4. «Орлого» хуудас (банкны хуулга → ажилтан)

Баганууд:
- B = Огноо (бүтэн огноо);
- C = Төрөл: Суудал, Бүтэн, Сар бүр, Хагас, ЗУН, Нийгэм, Сонгох;
- D = Тайлбар (банкны утга);
- E/F/G = Овог/Нэр/Анги;
- H = Дүн;
- I = Баримтын дугаар;
- J = Данс (Баасанжав).

Бусад:
- Зөвхөн сургалтын орлого орсон: ном, торгууль, зарлагыг ажилтан хассан.
- Нэг банкны гүйлгээг хэд хэдэн мөр болгон хуваасан тохиолдол 40 бий (ах дүү, сургалт + Нийгэм).

## 5. Үнэ ба бизнесийн дүрэм

- **Сургалтын үнэ** (суудаг анги 7 хоногт хэдэн өдөр ордгоор):
   - 4 өдөр: сар 350,000, бүтэн жил 2,500,000, хуваан төлөх 3,000,000.
   - 3 өдөр: сар 300,000, бүтэн жил 2,000,000.
- **Суудал:** эхний сарын төлбөр 300/350 мянга. Бүтэн жил гэвэл үлдэгдэл нь 1,700,000 эсвэл 2,150,000.
- **Хагас:** жишээ нь 1,500,000 + 1,500,000.
- **Хөнгөлөлт:** багшийн гэр бүл гэх мэт. Систем дээр Багш+ «Бүрэн» гэж тэмдэглэнэ.
- **Ном:** E1 30,000, E2 40,000, Хавтгайн геометр 25,000 (бөөнөөр 23,000).
- **Хариултын хуудас:** 1,000/ш.
- **Заалны торгууль** (ажилтан): 15,000, одоо 30,000.

## 6. Шийтэд бичих санал болгож буй алгоритм

Энэ алгоритмыг доорх давтан тулгах туршилтаар батлана:

1. **Мөр олох:** хүүхдийн мөрийг нэр, утсаар олно. Бичихээс өмнө тэр мөрийн овог, нэрийг дахин уншиж таарч байгааг шалгана.
2. **Сургалтын төлбөр:**
   - Хуваан төлж байгаа сар байвал түүнд нэмнэ. Үгүй бол хамгийн эртний хоосон сарын бүлэгт бичнэ.
   - Хугацааг сууж эхэлсэн өдрөөр тоолно.
   - Баримт = банкны огноо.
3. **Бүтэн жил:** «9-10» бүлэгт дүнг бичээд, «Хугацаа» = «бүтэн».
4. **Нүд бөглөгдсөн байвал:** ажилтны адил дүнг нэмж, огноог «, MM/DD» гэж залгана.
5. **Томьёо (L):** хөндөхгүй. Шинэ нүд нь нийлбэрт автоматаар орно.
6. **Хуулгын холбоос:** бичсэн нүд бүрийг хуулгын гүйлгээтэй холбож хадгална. Ингэснээр давхардахгүй, буцааж болно.

## 7. Давтан тулгах туршилт

1. Локал хуулбараас 09/01–11/05-ны хооронд ажилтны бичсэн төлбөрийн бичилтийг арилгана.
2. Систем банкны хуулгаас 6-р хэсгийн алгоритмаар дахин бичнэ.
3. Үр дүнг жинхэнэ шийттэй нүд бүрээр нь харьцуулна: дүн, хугацаа, баримт.
4. Зөрүү бүрийн шалтгааныг ангилж, дүрмийг засаад дахин ажиллуулна.
