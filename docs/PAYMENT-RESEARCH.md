# Pi.mn — төлбөрийн сувгийн судалгаа

2026-09-22 · Диаграмм v0.3-ийн шийдвэрийн материал. Гэрээ байгуулаагүй, API холболт идэвхжүүлээгүй. Нийтийн албан тариф нь Pi-д өгсөн үнийн санал биш.

## Санал болгож буй бүтэц

**Танхимын сарын/жилийн төлбөр:** эхлээд Хаан банкны хуулга импортлох → сурагч/нэхэмжлэхтэй тулгах → Багш+ батлах. Дараа нь банкны зөвхөн мэдээлэл унших API-г ижил тулгалтын урсгалд залгана. Одоо ашигладаг дансанд API олгох эсэх, үнэ, гүйлгээний утгын бүрэн мэдээллийг банкнаас баталгаажуулна.

**Нийтийн онлайн ном, сорил:** төлбөрийн gateway хэвээр. Сурагчийн төлбөр ба худалдан авалтын бүх суваг нэг Payment + Allocation бүртгэлд орно. Үйлчилгээ бүр өөр банкны логиктой болохгүй. Энэ нь судалгаанаас гарсан архитектурын санал; банк сонгосон шийдвэр биш.

**Сарын нэхэмжлэлийн нэмэлт хувилбар:** Голомтын И-Биллингийн тохирох эсэхийг шалгах. “SocialPay үнэгүй” гэж бүх үйлчилгээ, бүх мерчант төлбөрт ерөнхийлөхгүй.

## Тооцоо: 1 тэрбум₮ орлого ба өөр өөр шимтгэл

Өөрийн тооцоо: хувьт суваг `жилийн төлбөрийн дүн × хувь`; нэгж шимтгэл `амжилттай гүйлгээний тоо × нэгж үнэ`; API `ашиглах сарын тоо × сарын үнэ`. Орлого, цэнэглэлт, зарцуулалтыг давхар тоолохгүй.

| Хувилбар | 12 сарын суурь зардал | Тайлбар |
|---|---:|---|
| Бүх 1 тэрбум₮-д 1% | 10,000,000₮ | Хэрэглэгчийн жишээ, арифметик тооцоо |
| Бүх 1 тэрбум₮-д 0.5% | 5,000,000₮ | Зөвхөн хэлэлцээний хувилбар; баталсан тариф биш |
| ХХБ 5 минутын хуулга | 360,000₮ | API хуулгын тариф л багтсан |
| ХХБ 1 минутын хуулга | 1,800,000₮ | API хуулгын тариф л багтсан |

| И-Биллинг SocialPay, 1000 хүн × 12 удаа | 600,000₮ | 12,000 гүйлгээ ×50₮; хичээлийн сар цөөн бол тэр тоогоор үржүүлнэ |

Нэг 350,000₮ төлбөрийн 1% нь 3,500₮; 50₮ тогтмол шимтгэлтэй бүтээгдэхүүнд үнэхээр холбогдож чадвал нэг гүйлгээний ялгаа 3,450₮. Энэ нь шинэ гэрээний сарын үнийг 350,000₮ гэж баталсан хэрэг биш.

Нийт зардалд API + account/setup + дэмжлэг + засвар үйлчилгээ + багшийн review минут + reconciliation алдаа + refund + шилжүүлэгчийн зардал орно. “0₮ хуулга” бол нийт систем үнэгүй гэсэн үг биш. Credit цэнэглээд олон сорил авах нь 1%-ийг арилгахгүй: 100,000₮ цэнэглэлт1% байвал 1,000₮ хэвээр.

## Холболтын гэрээ авахаас өмнөх тодорхой асуултууд

1. Pi-ийн одоогийн дансны эзэмшил, байгууллагын бүртгэлээр read-only API/И-Биллинг нээх боломжтой юу?
2. Setup, сарын суурь, per transaction, минимум, татвар, settlement, refund, chargeback, volume discount тус бүр хэд вэ?
3. Гүйлгээний тогтвортой ID, бүрэн утга, credit/debit, booking/value date, reversal мэдээлэл өгдөг үү?
4. Rate limit, хуулгын pagination, хэдэн сарын түүх, polling/webhook, давтан татах боломж, тасалдлын мэдээлэл?
5. Sandbox ба банкны бодит гүйлгээтэй тулгах туршилт; callback давхардал/хоцролт, support, SLA?
6. Хуулга унших эрхийг мөнгө шилжүүлэх эрхээс салгаж болох уу? Credential rotation/IP restriction ямар вэ?

Эдгээрийг банк/үйлчилгээ рүү илгээгээгүй. Дараагийн ажлын асуултын жагсаалт.

## Diagram холбоос ба нэвтрүүлэх дараалал

- **BR01–BR12:** хуулга → нормчлол → давхардал → candidate → зөрүү → батлах → allocation → эрх сэргээх → өдрийн тулгалт → API.
- **TP01–TP12:** гэрээний хувилбар батлахаас өмнө автоматаар үнэ/эрхийн хаалт нэвтрүүлэхгүй.
- **WL01–WL10:** prepaid credit-ийн ledger, үлдэгдэл, debit/entitlement нэг transaction, refund, санхүүгийн тулгалт. Хүрээний шийдвэрийг launch-аас өмнө гаргана. [Монголбанкны зөвшөөрлийн суваг](https://license.mongolbank.mn/) нь шалгах эх сурвалж; хаалттай credit автоматаар зөвшөөрөлгүй гэсэн дүгнэлт хийгээгүй.
- **ST01–ST07:** private pilot → төлбөрийн амжилт/гар review/алдаа/шимтгэл хэмжих → сонгосон сувгаа өргөжүүлэх.

Өмнөх `market-research/m10-pricing-payments.md`-ийн банк/SocialPay-ийн үнэгүй гэх ерөнхий таамгийг энэ шийдвэрт ашиглахгүй. Түүхэн судалгааг устгаагүй; дээрх үйлчилгээ тус бүрийн баталсан нөхцөлөөр дахин үнэлсэн.
