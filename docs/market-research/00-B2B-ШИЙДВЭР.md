# «Сургалтын төвийн систем» зам — шийдвэрийн баримт

**Огноо:** 2026-09-15 · **Судалгаа:** b01–b05 (5 салбар)
**Асуулт:** Pi.mn-ийн платформыг бусад сургалтын төвд зарах уу?

---

## Дүгнэлт: НОТОЛГОО ЭНЭ ЗАМЫГ ДЭМЖИХГҮЙ

Та надаас энэ чиглэлийг судлахыг хүссэн. Судалсан. **Хариу нь үгүй** —
бөгөөд шалтгаан нь таны бүтээгдэхүүний чанарт биш, **арифметикт** байна.

Доорх тоонууд бүгд эх сурвалжтай (b01–b05, дэлгэрэнгүй нь тэдгээр файлд).

---

## 1. Арифметик

### Худалдан авагчийн тоо (b03)

| Сегмент | Тоо | Тайлбар |
|---|---:|---|
| Ерөнхий боловсролын сургууль | 885 | 314 УБ, 571 орон нутаг |
| ├ **улсын, ESIS-д албан журмаар** | **705** | ❌ хаагдсан — төрийн үнэгүй систем |
| └ хувийн сургууль | 180 | 20–40 нь бодитой |
| Сургалтын төв | 50–300 (таамаг) | **албан регистр байхгүй** |
| **Бодитой худалдан авагч** | **30–50** | b03-ын тооцоо |

### Ангиллын үнэ (b01, 19 платформ)

| | Үнэ |
|---|---|
| Сурагч тутам | $3–15/сар |
| Хавтгай тариф | $39–249/сар |
| Оролтын үнэ | **$15–75/сар** |

### Дэмжлэгийн зардал (b05)

| | Зардал |
|---|---|
| Нэг хэрэглэгчийн сарын дэмжлэг | **$1,200–1,400** |
| Эхний суулгалт | 40–80 цаг |
| Сар тутмын дэмжлэг | 5–10 цаг |
| Шалгалтын үед | **24/7 бэлэн байх** |

### Нийлүүлбэл

```
Орлого:   40 худалдан авагч × $50/сар  =  $2,000/сар  =  $24,000/жил
Зардал:   40 × $1,200/сар              = $48,000/сар

Нэг хэрэглэгч тутам сар бүр:  −$1,150
```

b05-ын дэмжлэгийн тооцоо 3 дахин хэтрүүлсэн байсан ч ($400/сар),
$50 орлого vs $400 зардал = **8 дахин доогуур**.

**Дээр нь:** multi-tenancy 3–6 долоо хоног (b04, миний зассан тооцоо —
агент 1–2 хоног гэсэн).

## 2. Гурван бүтцийн хориг

### 2.1 Өрсөлдөгчдөө зарах — нотлогдоогүй модель

b05: **«Ажиллагааны софтвэрийг шууд өрсөлдөгчдөө зарж амжилтад хүрсэн
компанийн баримтжуулсан тохиолдол байхгүй.»**

Та өрсөлдөгч төвөөс сурагчийн нэрс, орлогын датаг **өөрийн системд** тавихыг
хүсэж байна. Гэрээгээр хамгаалсан ч тэд хийхгүй. Энэ нь бүтээгдэхүүний
асуудал биш, **зах зээлийн бүтцийн татгалзал**.

### 2.2 Classplus-ийн түүх — таны замын хэтийн зураг

| Classplus (b02) | |
|---|---|
| Хэрэглэгч | **100,000 багш/төв** |
| Зах зээл | Монголоос **50 дахин том** |
| Үнэ | $20–25/сар + төлбөрийн 15% |
| FY22 орлого | ₹26 кроре |
| **FY22 гарз** | **₹164 кроре** |
| Хэрхэн аврагдсан | **Testbook (тест бэлтгэл) худалдаж авсан** |

100,000 хэрэглэгч хүрэлцээгүй бол **30–50 хүрэлцэхгүй.**

Бас анхаарууштай: Classplus **тест бэлтгэл рүү зугтаж** аврагдсан — яг та
одоо байгаа байрлал руу.

### 2.3 Churn 22%/жил (b05)

Боловсролын SaaS-д churn 2024–2025-д хоёр дахин өссөн. 40 хэрэглэгчээс жилд
9 гарна. Худалдан авагч 50 байхад энэ нь нөхөж баршгүй.

## 3. Агуулга vs админ — зөрчилдсөн нотолгоо, шийдсэн

| Агент | Юу гэсэн |
|---|---|
| **b01** | «19 платформын зөвхөн Classplus агуулга хамтруулдаг → **цоорхой, боломж**» |
| **b02** | «төвүүд **админ**-д төлсөн, агуулгад биш — агуулгыг өөрсдөө хийдэг» |

b01 үүнийг «хэн ч хийгээгүй тул боломж» гэж уншсан. Өөр уншлага:
**18 платформ хийдэггүй нь зарагддаггүйн шинж.** Цорын ганц хийсэн нь
Classplus — тэр нь гарздсан.

**Шийдэх нотолгоо (b02):**

| Компани | Модель | FY25 орлого |
|---|---|---|
| **Physics Wallah** | **агуулга (B2C)** | **₹2,886 кроре** |
| Unacademy | агуулга (B2C) | ₹826 кроре |
| **Classplus** | **админ софтвэр (B2B)** | **₹26 кроре** |

**110 дахин зөрүү.** Энэ ангиллын мөнгө агуулгад байна, софтвэрт биш.

## 4. Өмнөх саналаа залруулж байна

Өчигдөр би «агуулга лицензлэх нь хямд зам» гэж хэлсэн. **b02 үүнийг
үгүйсгэв** — төвүүд агуулга худалддаггүй, өөрсдөө хийдэг.

Тиймээс **B2B агуулгын лиценз ч мөн сул.** Ажилладаг нь **B2C агуулга**.

---

## 5. Нотолгоотой хоёр өөр зам

### 5.1 Сургалтын аргаа франчайз болгох (b05-ын зөвлөмж)

| | |
|---|---|
| Нотолгоо | **Kumon, Sylvan — 40+ жил** |
| Модель | $100k–200k урьдчилгаа + 5–6% royalty |
| Churn | **<5%** (франчайзи хөрөнгө оруулсан) |
| Дэмжлэгийн ачаа | Ажиллагааны сургалт, **24/7 uptime БИШ** |

Танд франчайз болгох зүйл бий: **батлагдсан сургалтын арга** (самбарын
жишээ бодлого, туслах багш, оройн өөрийн үнэлгээ, цоорхой үлдээхгүй зарчим),
6,100 бодлого, 1,974 задлан.

Гол ялгаа: франчайзи өөрийн серверийг өөрөө хариуцна. Та шалгалтын өдөр
24/7 бэлэн байхгүй.

### 5.2 B2C-д үлдэж өсөх

- Онлайн сургалтын зах зээл **15.3% CAGR** (b05)
- ЭЕШ математик өгдөг **23,002 сурагч/жил** (m06)
- Танайх 359 — когортын **1.6%**

3% болох нь 690 сурагч — одоогийн 350,000₮ үнээр сарын орлого хоёр дахин.
Multi-tenancy, шинэ борлуулалтын сувag, 40 хэрэглэгчийн дэмжлэг **шаардахгүй**.

## 7. Итгэлцлийн тэмдэглэгээ

| | Юу |
|---|---|
| ✅ Өөрөө шалгасан | 70 модельд тенант байхгүй; integral.mn-ийн LaTeX |
| 🔶 Эх сурвалжтай агентын мэдэгдэл | 885 сургууль, 705 ESIS, Classplus-ийн тоо, ангиллын үнэ |
| ⚠️ Агентын таамаг | «TAM 30–50», «дэмжлэг $1,200/сар», «churn 22%» |
| ❌ Батлагдаагүй | Монголын сургалтын төвийн бодит тоо (регистр байхгүй) |

**Гол эргэлзээ:** сургалтын төвийн тоо 50 эсвэл 300 эсэхийг хэн ч мэдэхгүй.
Гэхдээ 300 байсан ч $50/сар × 300 = $180,000/жил, дэмжлэгийн зардал нь
түүнээс их.

## 8. Хийхийг зөвлөж байгаа зүйл

1. **Multi-tenancy-г БҮҮ бүтээ** — 3–6 долоо хоног, 30–50 боломжит худалдан
   авагчийн төлөө
2. **Өчигдрийн IA цэгцлэлтийг дуусга** — 17 цэс → 7, «⋯» мөрийн ажиллагаа.
   Энэ нь өөрийн 13 багшид шууд тус болно
3. **§7-ийн мөнгө/SMS эрсдэлийг зас** — идемпотент байдал, баталгаажуулалт
4. **Дараа нь хоёроос сонго:** франчайз (Kumon модель) эсвэл B2C өсөлт
5. **Хэрэв B2B-г шалгах гэвэл хямд туршилт:** нэг танил төвд одоогийн
   системээ ҮНЭГҮЙ туршуулж үз. Тэд хэрэглэх эсэх, дата тавих эсэхийг
   3–6 долоо хоног код бичихээсээ ӨМНӨ мэднэ.

Тавдугаар зүйл хамгийн үнэ цэнэтэй: **нэг харилцан ярианд** энэ бүх
судалгаанаас илүү зүйл мэдэж болно.
