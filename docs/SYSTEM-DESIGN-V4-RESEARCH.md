# Pi.mn · v0.4 шаардлага ба судалгааны шийдвэр

2026-09-22. **Зөвхөн зураглал, дараа хэрэгжүүлэх гэрээ.** Бүтээгдэхүүний V1 нь зураглалын v0.4 гэсэн дугаартай адил биш. Өмнөх эх материалын шинжилгээ, төлбөрийн судалгааг хадгалсан; энэ баримтад зөрсөн дүрэм шинэ хүсэлтийн дагуу давуу үйлчилнэ. Бүх persona нь ерөнхий хэрэглэгчийн төрөл, хүний нэрсийн жагсаалт биш.

## 3. V1 тайлан — DG01–08 / LH01–07

`topicPercent = 100 × sum(earnedPoints) / sum(maxPoints)`; зөвхөн тухайн шалгалтын primary topic-д хамаарах даалгавар. Жишээ: 6/20=30%. Зөв/буруу/хоосон бодлогын тоо ба нийт шалгасан N-ийг хамт харуулна. Огт асуугаагүй бүлэг “Шалгаагүй”, 0% биш. Нэг даалгаврын үр дүн бол “Цөөн даалгаварт үндэслэв”. Бага хувиас нь эрэмбэлж “Энэ шалгалтад энэ сэдвээ давтах шаардлагатай байна” гэж гаргана. Ижил хувь ижил эрэмбийн ач холбогдолтой.

Skill олон холбоостой бол skill chart нь давхцсан шинжилгээ; бүлгийн нийт оноонд нэг даалгаврыг давхар тоолохгүй. Rubric байхгүй бол олон сэдэвт оноог таамгаар хуваахгүй. Оролдлого, анхны хариу, засвар, solutionSeen, retry, багшийн completion нь тусдаа. Бодолт харж зассан 100% нь анхны тестийн оноог солихгүй. Хичээлийн “хийсэн хувь” нь тестийн correctness биш.

StudentId, QuestionId, AssetId тогтвортой; StudentCode нь өөрчлөгдөж болох alias. Элсэлтээс гарах/эрх дуусах нь attempt history устгах trigger биш. Түүхэн дүн/version immutable revision-тэй; хамгаалалт, нэвтрэх хүрээ, зөвшөөрөл, retention нь өгөгдлийн төрлөөр. Хувийн утас/гэрээ/медиа-г математик оролдлоготой адил хязгааргүй хадгалах ганц дүрэм болгож болохгүй. V1 event schema хадгална, ML pipeline/export build хийхгүй. AI чадвар оношлох/прогноз/дасгал сонгох нь тусдаа V2 судалгаа, хэмжилт, багшийн баталгаажуулалттай.

## 5. Эцэг эх ба бүлэг — DP01–08 / SG01–07

Багш эсвэл Багш+ тухайн өдрийн ихэнх сурагч тарсан ойролцоо цаг, хамгийн сүүлийн сурагч гарсан цагийг тэмдэглэж болно. “Ангийн мэдээлэл; хүүхдийн яг гарсан цаг биш” гэж харуулна. Хүүхэд бүрийн actualDepartureAt-г ирээдүйд тусад нь баталж бүртгэвэл source/actor/time-тай. Дутуу утга “Бүртгээгүй”; ангийн цагийг хүүхдийн мөр рүү автоматаар хуулж болохгүй.
