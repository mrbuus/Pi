## 6. Урхи (цаг иддэг, дахин бүү унаарай)

- **SSL:** pg 8.x нь `sslmode=require`-ийг verify-full гэж ойлгодог. `&uselibpqcompat=true` байхгүй бол runtime хүсэлт бүр 500 өгнө, гэхдээ `prisma migrate` амжилттай ажилладаг.
- **tsc цэвэр байх нь хангалтгүй.** `"use client"` дутуу, NestJS модулийн экспорт дутуу, давхар `api/` префикс зэрэг алдаа зөвхөн build хийх эсвэл апп асаах үед илэрнэ.
- **Vercel автоматаар deploy хийгддэггүй.** main руу merge хийсэн ч вэб хуучин хэвээр байна.
- **Render free** 15 мин идэвхгүй бол унтана. Эхний хүсэлт ~60 сек (`lib/api.ts` retry хийдэг).
- **DTO decorator байхгүй** бол талбар чимээгүй хасагдана.
- **Supabase 7 хоног** идэвхгүй бол зогсоно (§4.8).
- **Гарагийн дугаарлалт** эзэн болон JS-ийн хооронд ялгаатай.
- **Хувийн мэдээлэл:** Excel, dump файлыг хэзээ ч репод commit хийхгүй.
