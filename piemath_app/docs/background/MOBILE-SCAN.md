# Photomath шиг «зураг дарж бодох» — Flutter дээр боломжтой юу?

Огноо: 2026-11-01 · Холбоотой: [MOBILE-APP-DETAIL.md](MOBILE-APP-DETAIL.md)

**Товч хариу: Тийм, боломжтой.** Flutter нь камер, утасны өөрийн процессор дээрх ML
загвар (on-device AI), томьёо харуулах бүгдийг хийж чадна. Хэцүү нь Flutter биш:
**зургаас томьёо таних загвар** болон **алхам алхмаар бодох хөдөлгүүр**. Эдгээр нь ямар
технологиор хийсэн ч хамгийн их ажил шаарддаг хэсэг.

---

## 1. Өмнө хэлсэн гурван эрсдэлийн тайлбар

### 1.1 `flutter_math_fork` — томьёо харуулах
- Энэ бол KaTeX-ийг Dart руу хөрвүүлсэн сан. Томьёог натив байдлаар зурдаг тул хурдан,
  гөлгөр. Photomath шиг аппад таньсан томьёог харуулахад яг энэ хэрэгтэй.
- Эрсдэл: KaTeX-ийн **бүх** командыг дэмждэггүй, мөн KaTeX-ээс удаан шинэчлэгддэг.
  Манай бодлогуудад `\text{...}` дотор кирилл бичвэр, хүснэгт, онцгой орчин бий. Тэдгээрийн
  хэдэн хувь нь зөв харагдахыг таамаглах биш, **хэмжиж** мэдэх хэрэгтэй.
- Шийдэл: 12,800 бодлогыг бүгдийг автомат тестээр зурж үзнэ. Бүтэлгүйтсэнийг нь
  сервер дээр SVG болгож харуулна. Энэ нь «ажиллахгүй» гэсэн үг биш, «шалгаж, нөхөх
  ажил бий» гэсэн үг.

### 1.2 MathLive — томьёо бичих талбар
- MathLive бол веб-ийн томьёо засагч: бутархай, зэрэг, язгуурыг товчоор оруулж, LaTeX
  гаргаж өгдөг. Манайд `web/src/components/tools/core/MathInput.tsx`-д ашиглагддаг.
- **Залруулга:** өмнө «Flutter-т дүйцэх зүйл алга» гэж бичсэн нь хэт хатуу байсан.
  Flutter-т **`math_keyboard`** сан бий (томьёо бичих талбар + математик гар, TeX гаргана).
  Гэхдээ MathLive-аас хязгаартай: энгийн илэрхийлэлд сайн, нарийн бүтэц (матриц, систем
  тэгшитгэл) сул.
- Шийдэл: `math_keyboard`-оор эхэлж, дутууг нь өөрсдөө нэмж хөгжүүлнэ. Photomath-д ч
  гараар засах талбар бий (таньсан томьёо буруу бол сурагч засна) — яг энэ хэрэгтэй.

### 1.3 «Хоёр газар бичих»
- Багш, админ веб-д, сурагч Flutter аппад байна. Сурагчид зориулсан шинэ функц бүрийг
  React (веб) болон Dart (апп) хоёуланд нь бичих болно.
- Зардлыг багасгах арга: бизнесийн дүрэм бүгд API-д (оноо, эрх, 7 хоногийн нээлт), апп ба
  веб зөвхөн харуулна. Цаашдаа сурагч бүгд апп руу шилжвэл веб-ийн сурагчийн хэсгийг
  хөлдөөж болно.
- Энэ нь техникийн хориг биш, зөвхөн арчлалтын ажил.

## 2. Photomath яаж ажилладаг вэ

```
[1] Камер    →  [2] Таних (OCR)   →  [3] Ойлгох       →  [4] Бодох            →  [5] Харуулах
 зураг авах      зураг → LaTeX        LaTeX → бүтэц       алхам алхмаар шийд      томьёо + тайлбар
 тайрах          (ML загвар)          (парсер)            (бодох хөдөлгүүр)       (flutter_math_fork)
```

| Алхам | Flutter-т | Хэцүү байдал |
|---|---|---|
| 1. Камер, тайрах | `camera`, `image_cropper` | Амархан |
| 2. Зураг → LaTeX | `tflite_flutter` (Android/iOS-д утсан дээр ML ажиллуулна) | **Хэцүү** — загвар хэрэгтэй |
| 3. LaTeX → бүтэц | Dart парсер (`math_expressions` сан эсвэл өөрийн) | Дунд |
| 4. Алхам алхмаар бодох | Өөрсдөө бичнэ | **Хамгийн хэцүү** |
| 5. Харуулах, засах | `flutter_math_fork`, `math_keyboard` | Дунд |

Таны хүсэж буй «утасны процессороор тооцоолох» санаа яг 2-р алхамд хамаарна: таних
загварыг утсан дээр ажиллуулбал зураг сервер рүү явахгүй, интернэтгүй ажиллана, серверт
ачаалал өгөхгүй. Flutter үүнийг `tflite_flutter`-аар (iOS-д мөн Core ML-ээр) хийж чадна.

## 3. Таних загвар (алхам 2) — гурван сонголт

| | Утсан дээр (on-device) | Өөрийн сервер дээр | Гадны API (жишээ нь Mathpix) |
|---|---|---|---|
| Хурд | Хурдан, интернэтгүй | Сүлжээнээс хамаарна | Сүлжээнээс хамаарна |
| Нарийвчлал | Дунд (сургах хэрэгтэй) | Дунд–сайн | Хамгийн сайн |
| Зардал | Хүсэлт бүрт үнэгүй | GPU сервер (сар бүр) | Хүсэлт бүрт төлбөр |
| Нууцлал | Зураг утаснаас гарахгүй | Манай серверт | **Хүүхдийн зураг гуравдагч этгээдэд очно** |
| Ажил | Загвар хөрвүүлж, жижгэрүүлэх | Сервер тохируулах | Хамгийн бага |

- Нээлттэй эхийн «зураг → LaTeX» загварууд бий, гэхдээ ихэнх нь том (утсанд суулгахад
  жижгэрүүлэх, квантчлах шаардлагатай) бөгөөд **кирилл бичвэр холилдсон бодлогод
  сургагдаагүй**. Манай номын бодлогуудаар нэмж сургах (fine-tune) хэрэгтэй.
- Сургах өгөгдөл бидэнд бий: 12,800 бодлогын LaTeX + номын хуудасны зураг (PDF). Энэ бол
  том давуу тал.
- Зөвлөмж: прототипийг серверт хийж нарийвчлалыг хэмжих → хангалттай болмогц утсан
  дээр шилжүүлэх.

## 4. Хамгийн хурдан, хамгийн үнэ цэнтэй зам: **манай сантай тулгах**

Photomath дурын бодлогыг шинээр боддог. Харин манай сурагчид ихэвчлэн **манай номын**
(100x100, 200x200, Хавтгай, 1000 бодлого) бодлогыг бодож байгаа. Эдгээрийн бодолт,
YouTube тайлбар **санд аль хэдийн бэлэн байна.**

```
Зураг → таних → манай 12,800 бодлогоос хамгийн төстэйг хайх → бэлэн бодолтыг харуулах
```

- Бүрэн таних шаардлагагүй: бүдүүвч танилт ч гэсэн төстэй бодлогыг олоход хангалттай
  (Postgres `pg_trgm` хайлт эсвэл тоо, томьёоны хээгээр)
- Бодолт нь багш нарын бичсэн, зөв, Монгол хэлээр — Photomath-аас илүү
- **«AI runtime-гүй» дүрэмтэй нийцнэ:** вэб Claude API дуудахгүй, бодолтыг урьдчилан
  санд хийсэн
- **QR код:** дахин хэвлэгдэх номд (жишээ нь 300x300) бодлого, тест бүрт жижиг QR
  хэвлэвэл зураг таних ч хэрэггүй — 100% зөв, шууд нээгдэнэ

**Анхаар — бодолт нээгдэх дүрэм:** 1000 бодлогын тестийн бодолт 7 хоногийн дараа
нээгдэнэ. Зураг дарах функц энэ дүрмийг тойрч болохгүй. Шалгалт ба гэрийн даалгаврын үед
сурагч зураг дарж хариу авбал хуулах хэрэгсэл болно. Хариуг сервер үргэлж эрх, хугацаагаар
шалгаж өгнө — апп дотор хариу хадгалахгүй.

## 5. Дурын бодлогыг алхам алхмаар бодох (алхам 4)

- Dart-ийн `math_expressions` сан илэрхийлэл задлах, утга бодох, энгийн уламжлал авч
  чадна, гэхдээ **алхам алхмын тайлбар өгдөггүй.**
- Photomath-ийн түвшний бодох хөдөлгүүр бол олон жил, том багийн ажил. Ямар ч хэлээр
  (Dart, Swift, Python) энэ нь адилхан хэцүү.
- Бодит зам: **сэдэв сэдвээр** дүрэмд суурилсан бодогч бичих:
  1. Шугаман тэгшитгэл, бутархай, хувь
  2. Квадрат тэгшитгэл (дискриминант)
  3. Систем тэгшитгэл
  4. Тригонометр, логарифм...
  Сэдэв бүр «алхам → Монгол тайлбар» загвартай. Үүнийг Dart-аар бичвэл **утсан дээр,
  интернэтгүй** ажиллана — таны санаатай яг таарна.

## 6. Санал болгох дараалал

| Үе | Агуулга | Утсан дээрх тооцоолол |
|---|---|---|
| S1 | Номын бодлогыг QR + зураг тулгалтаар олох, бэлэн бодолт (нээгдэх дүрэмтэй). **QR хэсэг хийгдсэн** (2026-11-01, branch `mobile/scan-s1`, commit үгүй); зураг тулгалт нь S2-ийн таних загвараас хамаарна | Зураг шахах, тайрах |
| S2 | Таних загварын прототип (сервер), нарийвчлал хэмжих | — |
| S3 | Загварыг жижгэрүүлж утсан дээр ажиллуулах (TFLite / Core ML) | **Таних бүрэн утсан дээр** |
| S4 | Шугаман, квадрат тэгшитгэлийн алхам алхмын бодогч (Dart) | **Бодолт утсан дээр** |
| S5 | Бусад сэдвүүд, `math_keyboard`-оор гараар засах | — |

S1 нь Flutter аппын F2–F3 үетэй хамт хийгдэх боломжтой бөгөөд сурагчдад шууд үнэ цэнтэй.
