# Аюулгүй байдал ба хүүхдийн нууцлал

Хэрэглэгчид хүүхэд тул энгийн апп-аас илүү болгоомжтой. **Репо PUBLIC** — эх кодыг хэн ч уншина гэж тооц.

## 1. Нууц

- Апп-д нууц түлхүүр БАЙХГҮЙ (API key, service account, secret). Апп-ын бүх зүйлийг задалж уншиж болно.
- `google-services.json`, `GoogleService-Info.plist`, keystore, `.env` — `.gitignore`-д, commit хийхгүй.
  Жишээ файл (`*.example`) л репод.
- JWT зөвхөн `flutter_secure_storage`-д. SharedPreferences, log, crash report, URL query-д токен бүү тавь.

## 2. Сүлжээ

- Зөвхөн HTTPS (`android:usesCleartextTraffic="false"`, iOS ATS өгөгдмөл). Хөгжүүлэлтийн localhost-д зөвхөн debug flavor.
- Certificate pinning **хийхгүй** (Let's Encrypt 90 хоног тутам солигддог — апп эвдэрнэ). Хэрэгтэй бол эзэнтэй зөвшилцөж root-оор.
- Сервер бүх хүсэлтийг өөрөө шалгадаг — апп-ын шалгалт зөвхөн UX.

## 3. Өгөгдөл

- Утсанд хадгалах кэш: бодлого, онол, хуваарь — хувийн мэдээлэлгүй. Гарахад (logout) бүх кэш, токен устгана.
- Хариуны түлхүүр, `Problem.token`, бусад сурагчийн мэдээлэл хэзээ ч кэшлэхгүй (сервер ч илгээдэггүй).
- Гэрийн даалгаврын зураг: илгээсний дараа түр файлыг устга.
- Log-д нэр, утас, токен бичихгүй. Release build-д `debugPrint` унтраах.

## 4. Хүүхдийн нууцлал

- Зар сурталчилгааны SDK, гуравдагч analytics/трекинг ХОРИОТОЙ (эзний зөвшөөрөлгүй).
- Crash report хэрэгтэй бол эзэнтэй зөвшилцөж, хувийн мэдээлэлгүй (user id-г hash).
- Камер, зургийн зөвшөөрлийг хэрэгтэй үед л асууна, яагаад хэрэгтэйг монголоор тайлбарлана.
- Апп дотроос бүртгэл устгах **хүсэлт** (Apple заавал), нууцлалын бодлогын холбоос.

## 5. Код

- `flutter analyze` цэвэр, `dart fix`. Platform channel-ийн оролтыг шалга.
- WebView хэрэглэвэл (YouTube) — JavaScript зөвхөн nocookie embed домэйнд, навигацыг хязгаарла.
- Deep link (`/q/:code`, `/app/...`): параметрийг шалгаж (regex), зөвхөн дотоод замд шилжүүл.
- Release: `--obfuscate --split-debug-info`, Android `minifyEnabled`.
