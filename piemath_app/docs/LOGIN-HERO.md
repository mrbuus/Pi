# Нэвтрэх хуудасны hero (LoginHero)

Нэвтрэх дэлгэцийн дээд хэсэг. Одоо зөвхөн брэндийн лого харагдана. Эзний анимаци / видеог
`assets/login_hero/` хавтсанд файл хийхэд код өөрчлөхгүйгээр тоглоно.

## Эзэн файлыг яаж нэмэх вэ

1. Видеогоо доорх нэрээр `piemath_app/assets/login_hero/` хавтсанд хуулна.
2. `flutter pub get` (шаардлагагүй, хавтас бүхэлдээ бүртгэлтэй) → апп дахин build хийнэ.
3. Өөр юу ч өөрчлөхгүй. Файл устгавал лого руу буцна.

| Файл | Заавал эсэх | Тайлбар |
|---|---|---|
| `hero.mp4` | видео тоглуулахад заавал | H.264 (AVC), дуугүй |
| `poster.webp` (эсвэл `.png`, `.jpg`) | зөвлөж байна | Видеоны эхний frame; видео ачаалах хүртэл, мөн хөдөлгөөн хасах горимд харагдана |
| `hero_dark.mp4` | заавал биш | Харанхуй горимын видео. Байхгүй бол `hero.mp4` |
| `poster_dark.webp` (эсвэл `.png`, `.jpg`) | заавал биш | Харанхуй горимын poster |

Нэрийг яг ингэж бич (жижиг үсэг). Өөр өргөтгөл, `.webm`, Lottie / Rive дэмжигдэхгүй.

## Үндсэн формат: MP4 (H.264) — яагаад

Нэг формат: `video_player` сан iOS, Android хоёрт нэг файлаар ажиллана. Lottie / Rive нэмбэл
сан + runtime ихэснэ, тиймээс нэмээгүй.

Хэмжээний төсөв:

- Файл **≤ 1.5 MB** (poster ≤ 150 KB)
- Урт **≤ 6 секунд**, шулуун давтагдах (эхлэл = төгсгөл)
- Нягтрал **720p** (1280x720, эсвэл 16:9 харьцаа), 24-30 fps
- Дуу байхгүй (дууны дор нь хасна), bitrate ойролцоогоор 1.5-2 Mbps
- Харьцаа 16:9; апп дотор 176 px өндөртэй мужид `cover`-оор таслагдана, тиймээс чухал зүйлийг голд нь тавь

Жишээ (ffmpeg):

```bash
ffmpeg -i source.mov -t 6 -vf "scale=1280:-2,fps=30" -an -c:v libx264 -profile:v main \
  -crf 28 -preset slow -movflags +faststart hero.mp4
ffmpeg -i hero.mp4 -frames:v 1 -vf "scale=1280:-2" poster.webp
```

## Хэрхэн ажилладаг

- Талбарууд шууд ашиглагдана; видеог эхний frame зурагдсаны ДАРАА ачаална. Алдаа гарвал poster / лого үлдэнэ.
- Дуугүй, хяналтгүй, давтагдана. Апп арын горимд орох, дэлгэц нуугдах, гар нээгдэх үед зогсоно.
- **Хөдөлгөөн хасах** горим (iOS Reduce Motion, Android animations off → `MediaQuery.disableAnimations`):
  видео ачаалахгүй, poster (байхгүй бол лого) харуулна.
- **Гар нээгдэхэд** hero бүдэгэрч (opacity) өндрөө 0 болтол нугарна (260 ms), талбарууд дээш гарна;
  гараа хаавал буцна. Нугарсан үед видео зогсоно.
- Харанхуй горимд `*_dark` файл, байхгүй бол ердийн файл. Лого нь өнгөний токеноор (цагаан хайрцаггүй).
- Видео байхгүй, poster байхгүй бол яг өмнөх лого (`BrandMark`) харагдана.

## Алсын override (өгөгдмөлөөр УНТРААЛТТАЙ)

Bundle-д видео ОГТ байхгүй үед л хэрэглэгдэнэ. Зөвхөн `https://` ба Wi-Fi / ethernet үед
(мобайл датаар татахгүй). Алдаа гарвал лого.

```bash
flutter run --dart-define=LOGIN_HERO_URL=https://cdn.example.mn/hero.mp4
```

Тохируулаагүй (хоосон) бол ямар ч сүлжээний хүсэлт гарахгүй.

## Хэрхэн шалгах вэ

```bash
export PATH=~/Development/flutter-3.47/bin:$PATH
cd piemath_app
flutter analyze
flutter test test/features/auth/login_hero_test.dart
```

Гараар: `flutter run` → нэвтрэх дэлгэц.

1. Файлгүй: лого өмнөх шигээ.
2. `hero.mp4` + `poster.webp` хийгээд build хийх: poster → видео зөөлөн гарна.
3. Утасны Settings дотор Reduce Motion асаа (Android: Remove animations): poster л харагдана.
4. Нэвтрэх нэрийн талбарыг дар: hero нугарна, бүх талбар харагдана (жижиг утсан дээр ч).
5. Харанхуй горим: `hero_dark.mp4` / `poster_dark.*` нэмбэл тэр, үгүй бол ердийнх.

Код: `lib/features/auth/ui/hero/` (`login_hero.dart` дэлгэцийн хэсэг, `login_hero_media.dart` файл
илрүүлэлт, алсын URL). Тест: `test/features/auth/login_hero_test.dart`.

Анимацын слот: hero нь `AnimSlot.loginHero` (`assets/anim/manifest.yaml`, `assets/anim/README.md`).
Видео тоглож байх үед `AnimLoopGate`-ийг эзэмшинэ (нэг удаад нэг давталттай анимац). Файлын нэр, үйлдэл өөрчлөгдөөгүй.
