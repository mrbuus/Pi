# Cloud session-д өгөх НЭМЭЛТ заавар — UX судалгаа

Ажиллаж буй cloud session-д доорх бичвэрийг мессеж болгон өгнө.

---

Эзний шинэ шаардлага: апп нь Голомт банкны шинэ апп шиг гөлгөр, сонирхолтой, хэрэглэхэд эвтэйхэн байх ёстой. Нүд
ядраахгүй, хэт өнгөлөг биш, гэхдээ энгийн хар-цагаан ч биш. **Хамгийн чухал нь AI-аар хийсэн мэт харагдах зүйл НЭГ Ч
байж болохгүй.** Үүнд зориулж 5 судалгааны agent шилдэг апп-уудыг судалсан.

## 1. Эхлээд судалгааг өөрийн branch-д ав

```bash
git fetch origin piemath-ux
git merge --no-edit origin/piemath-ux   # зөвхөн 2 шинэ файл: piemath_app/docs/UX-RESEARCH.md, UX-PROMPT.md
```

`piemath_app/docs/UX-RESEARCH.md`-ийг бүтнээр нь унш. §0 (AI-маягийн шинж) бол RULES.md-тэй ижил хүчтэй хатуу дүрэм.

## 2. M0.5 — UX суурийг засах (M1-ээс өмнө, тусдаа commit-ууд)

1. **RULES.md-д нэм:** «AI-маягийн биш» хэсэг (UX-RESEARCH §0-ийн хориотой ба зорилтот шинжүүд), «Unbounded =
   зөвхөн тоо ба латин», «хүрэх талбай 48dp».
2. **Фонт:** Unbounded-д Ү ү Ө ө байхгүй (шалгасан). `fontFamilyFallback` нь нэг үгэнд хоёр хэлбэрийн үсэг гаргадаг тул
   бүх монгол гарчгийг Onest 600–700 болго; Unbounded-ыг зөвхөн оноо, хувь, цаг гэх мэт тоонд (`tnum`). Гарчгийн
   `TextStyle` бүр Ү Ө-тэй фонт ашиглаж байгааг шалгах тест нэм.
3. **Токен (`lib/core/ui/tokens.dart`):** UX-RESEARCH §2-ын хүснэгтээр саарлыг брэндийн өнгө рүү бага зэрэг хазайлга
   (bg `#F5F7FB`, карт `#FFFFFF` + 1px `#D7DBE3`, хар горимын карт `#1A1E26` …). `#76B6F7`/`#AFC4EF`-ийг цагаан дээр
   текст, дүрсэнд хэрэглэхгүй гэдгийг контрастын тест баталгаажуулдаг байх. Төлөвийн өнгө хэлбэртэй хамт.
4. **`AppSizes.minTap` 44 → 48.**
5. **Хөдөлгөөн:** UX-RESEARCH §4-ийн хүснэгтээр `AppMotion`-д spring-ууд (`SpringDescription.withDampingRatio`);
   reduced motion = `MediaQuery.disableAnimationsOf` **ба** `accessibilityFeatures.reduceMotion` (iOS).
6. **Гүйцэтгэлийн түвшин** `PerfTier` (`device_info_plus`: `sdkInt < 29`, RAM ≤ 3GB, `isLowRamDevice` → low):
   low-д шатлалгүй жагсаалт, гулсах шилжилт, `themeAnimationDuration: Duration.zero`.
7. **Widget-ууд:** `PressableScale`, «уруултай» үндсэн товч (`#273F74` дээр `#142E62` 2–4px уруул, дарахад 2dp доошилно —
   сүүдэр, blur-гүй «сурах бичгийн 3D»), `AppPageTransition`, `SkeletonBox` (shader-гүй, 300ms хойш), `staggerIn`
   (эхний 8 мөр), `SuccessCheck`. Одоогийн `SkeletonPulse` shader/`Opacity` ашигладаг бол соль.
8. **LaTeX кэш:** parse модыг LRU (~300) кэшлэ, `RepaintBoundary`, `ParseException` fallback.
9. Golden зургуудыг шинэчил, `PROGRESS.md`-д M0.5 бичлэг.

## 3. Цаашид ДЭЛГЭЦ БҮРИЙН «Дууссан» гэх шалгуурт нэм

- [ ] UX-RESEARCH §0-ийн AI-маягийн жагсаалтын нэг ч шинж байхгүй (golden зургийг хараад шалга)
- [ ] Ачаалж буй / хоосон / алдаа / өгөгдөлтэй / офлайн төлөв; кэш эхлээд, 1 сек-ээс бага бол skeleton харуулахгүй
- [ ] Дарахад 100ms дотор хариу; хөдөлгөөн зөвхөн transform/opacity, хөдөлгөөн багасгах горимд унтарна
- [ ] Хүрэх талбай ≥ 48dp, контраст ≥ 4.5:1, 200% фонтод таслагдахгүй, `meetsGuideline` тест
- [ ] Бичвэр тодорхой, бодит (хоосон магтаал, ерөнхий уриа үгүй), монгол, орос үггүй

## 4. Урсгалуудад (M3–M7) хэрэгжүүлэх загварууд

UX-RESEARCH §6–§7: вэбтэй ижил доод таб (Нүүр, Хичээл, Шалгалт, Хуваарь, Бусад); «Дараагийн алхам» картай нүүр,
ихдээ 4 шуурхай үйлдэл; гэрийн даалгаврын камер (A4 хүрээ, бүдэг зураг шалгах, «2/6», илгээхээс өмнө байршуулах,
офлайн дараалал); шалгалт (эхлэхийн өмнөх тайлбар, нууж болох таймер 5 мин-д буцна, асуултын тор + «Дараа харах»,
илгээхийн өмнөх тойм, офлайн хадгалалт); дүн (сэдвийн задаргаа, нээгдэх огноо тодорхой, ангийн жагсаалт өгөгдмөлөөр
үгүй); төлбөр (мөр бүрт хуулах + «Бүгдийг хуулах», haptic); эцэг эх (Ирц, Даалгавар, Төлбөр дээр).

## 5. Эзний шийдвэр

UX-RESEARCH §11-ийн A–F саналыг `PROGRESS.md`-ийн «Эзний шийдвэр» хүснэгтэд нэм. **Батлахаас өмнө бүү хий**
(долоо хоногийн дараалал, эзэмшлийн түвшин, дахин оролдох, эцэг эхийн тойм, UX үйл явдал, үнэлгээний хүсэлт).
Хүүхдийн ёс зүйн хориг (§10) — streak бооцоо, нийтийн жагсаалт, гэм буруутгах мэдэгдэл — хэзээ ч үгүй.
