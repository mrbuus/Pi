# Дэлгүүрт гаргах бэлтгэл (M10)

Төлөв: 2026-11-03. Дэлгүүрийн бодлогын хяналт (privacy manifest, target API, 16 KB, Data safety, review тэмдэглэл): **COMPLIANCE.md**. `[Э] = эзний данс, шийдвэр, гарын үсэг хэрэгтэй алхам. Брэнд: `Piemath` / `Шинэ ирээдүйн эзэд` (RULES.md §1).

## 1. Брэнд зураг

Эх: вэбийн `web/public/logo-circle.png` (шинэ лого зохиоогүй). `assets/branding/make_branding.py` (Pillow) тэндээс цагаан тэмдгийг салгаж эх зургуудыг гаргана.

| Зорилго | Файл | Тохиргоо |
|---|---|---|
| Android adaptive | `icon-foreground.png`, дэвсгэр `#273F74`, `icon-monochrome.png` (Android 13 өнгөт дүрс) | `flutter_launcher_icons.yaml` |
| iOS | `icon-ios.png` (альфагүй, хөх дэвсгэр) | мөн адил |
| Splash (2 горим) | `bg` дэвсгэр + хар хөх дугуй дангаараа (`splash-disc.png`, Android 12: `splash-disc-android12.png`) = логоны анимацын эхний кадр | `flutter_native_splash.yaml`, `make_branding.py intro` |

Логоны ард цагаан хайрцаггүй, харанхуй горимд хар хувилбар (RULES.md).

Дахин үүсгэх:

```bash
export PATH=~/Development/flutter-3.47/bin:$PATH
cd piemath_app
python3 assets/branding/make_branding.py
dart run flutter_launcher_icons
dart run flutter_native_splash:create
git checkout ios/Runner.xcodeproj/project.pbxproj ios/Runner/Info.plist   # генераторууд эдгээрийг буруу өөрчилдөг
```

`flutter_launcher_icons` нь `project.pbxproj`-д `ASSETCATALOG_COMPILER_GENERATE_SWIFT_ASSET_SYMBOL_EXTENSIONS = AppIcon` гэж буруу утга бичдэг, `flutter_native_splash` нь `Info.plist`-ийн догол мөрийг бүхэлд нь шилжүүлдэг. Тиймээс заавал буцаана (Info.plist-д зөвхөн нэр, зөвшөөрлийн бичвэр засна).

## 2. Release build

```bash
flutter build appbundle --release --obfuscate --split-debug-info=build/symbols   # Play (ABI-г Play өөрөө хуваана)
flutter build apk --release --split-per-abi --obfuscate --split-debug-info=build/symbols   # шууд түгээх, хэмжих
flutter build ipa --release --obfuscate --split-debug-info=build/symbols          # [Э] Apple данс, гарын үсэг
```

- R8 minify + shrinkResources `build.gradle.kts`-д release-д асаалттай (`isMinifyEnabled`, `isShrinkResources`).
- `build/symbols` хавтас **заавал хадгал** (commit хийхгүй, гэхдээ release бүрийн хувилбартай хамт нөөцөл): crash stack trace-ийг `flutter symbolize -d build/symbols -i stack.txt`-ээр уншина. Obfuscate хийсэн бол symbols-гүйгээр алдааг уншиж болохгүй.
- Хэрэглэх API-г `--dart-define=API_BASE_URL=...`-ээр заана (өгөгдмөл нь `https://api.pimath.mn/api`).
- `android/key.properties` байхгүй бол release нь debug түлхүүрээр гарын үсэг зурна. Ийм файлыг Play-д **оруулж болохгүй**. Түлхүүр, `key.properties` репод орохгүй (`key.properties.example` харна).
- `--analyze-size` нь `--split-debug-info`-той зэрэг ажиллахгүй. Тиймээс хэмжилтийг тусад нь хийсэн.

### 2.1 Хэмжилт (debug гарын үсэг, 2026-11-02)

| ABI | Obfuscate + split-debug-info | Үгүй |
|---|---|---|
| arm64-v8a | 26.5 MB (26 489 698 байт) | 28.4 MB |
| armeabi-v7a | 24.3 MB | 26.6 MB |
| x86_64 | 28.1 MB | 30.0 MB |

Зорилт (PERFORMANCE.md §2): arm64 APK 25 MB-аас бага. **Одоо 1.5 MB давсан.** Play-ийн AAB-аас татах хэмжээ APK-аас жижиг байдаг (AAB-ийг `bundletool get-size total`-аар хэмжинэ, [Э] Play данс шаардахгүй).

`--analyze-size` (arm64, obfuscate-гүй): `lib/` 24.5 MB (libflutter, libapp, залгааны .so), `assets` 2.15 MB, `classes.dex` 1.2 MB, `res` 0.47 MB.

Assets-ийн задаргаа:

- **Lucide фонт ~1.42 MB.** `lucide_icons_flutter` залгаас 7 фонт (`LucideVariable-w100…w600` тус бүр ~0.23 MB, `lucide.ttf` 26 KB) аппад оруулдаг, жин бүр tree-shake хийгдэхгүй. Бид ганц жин л хэрэглэнэ. Арга: `lib/core/ui/icons.dart` (wrapper аль хэдийн бий) дахь ашигладаг дүрсүүдийг `pyftsubset`-ээр нэг жижиг TTF болгож `pubspec.yaml`-д өөрийн фонт болгон зарлах, залгааг авах. Ойролцоогоор 1.3 MB хэмнэнэ. `lib/` болон `pubspec.yaml`-д өөрчлөлт орох тул энэ ажлыг эзэмшигчид хүсэлт болгон өгсөн (§7).
- KaTeX фонт 20 орчим файл ~0.4 MB (`flutter_math_fork`), Onest, Unbounded 5 файл ~0.21 MB.
- Нэмэлт хэмнэлт: `armeabi-v7a`-г Play-д хэвээр үлдээ (хуучин утас), харин вэбээс шууд түгээх APK-д зөвхөн arm64.

## 4. Насны ангилал

- Бүртгэлтэй хэрэглэгч: сурагч (суурь, дунд, ахлах анги), эцэг эх, багш. Сурагчдын нас ойролцоогоор 10-18.
- Apple насны асуулга: хүчирхийлэл, бэлгийн агуулга, мөрийтэй тоглоом, хэрэглэгчийн үүсгэсэн нийтийн агуулга (чат, сэтгэгдэл) **үгүй**, шүүлтүүргүй вэб хөтөч **үгүй**. Үр дүн 4+ орчим.
- Google Play (IARC): дээрхтэй адил **үгүй**. Хэрэглэгч хоорондын харилцаа (чат) байхгүй.
- «Target audience» асуулт: 13 хүртэлх насны хүүхэд хэрэглэгч байж болох тул Play-ийн **Families** бодлогод орох эсэхийг [Э] шийднэ. Хамгийн хялбар нь зорилтот насыг «13+ ба насанд хүрэгчид» гэж тохируулж, 13-аас доош сурагчийг эцэг эхийн дансаар нэвтрүүлэх. Үгүй бол Families бодлогын шаардлага (сертификатжсан сан, зар үгүй) нэмж хангана. Одоогийн апп зар, трекер ашигладаггүй тул хүнд биш.
- Apple «Kids» ангилал сонгохгүй (Education).
- Апп дотроос данс устгах хүсэлт: Профайл → «Бүртгэл устгах хүсэлт» (хийгдсэн). Play-д нэмэлтээр вэб хаяг хэрэгтэй (COMPLIANCE.md §2.16).

### 5.1 Google Play: Data safety

| Төрөл | Цуглуулах | Хуваалцах | Зорилго | Заавал/сонголт |
|---|---|---|---|---|
| Нэр | Тийм | Үгүй | Апп-ын үндсэн үйлчилгээ, данс | Заавал |
| Утасны дугаар | Тийм | Үгүй | Нэвтрэх, данс | Заавал |
| Зураг (гэрийн даалгавар, дэвтэр) | Тийм | Үгүй | Апп-ын үндсэн үйлчилгээ (багш шалгана) | Сонголтоор, илгээх үед |
| Сурагчийн дүн, ирц, төлбөрийн төлөв | Тийм | Үгүй | Апп-ын үндсэн үйлчилгээ | Заавал |
| Төхөөрөмжийн ID (push токен) | Push нэмэгдэх үед тийм | Үгүй (Firebase боловсруулагч) | Мэдэгдэл илгээх | [Э] Firebase-ийн дараа |

| Крэш лог, анализ | Үгүй (эзэн зөвшөөрөөгүй) | - | - | - |

- Дамжуулалт: HTTPS, шифрлэгдсэн. Токен нь төхөөрөмжийн хамгаалагдсан сангаар (`flutter_secure_storage`).
- Устгах хүсэлт: Play нь вэб хаяг шаарддаг. [Э] `pimath.mn` дээр «Бүртгэл устгах хүсэлт» хуудас бэлдэнэ.
- Зар сурталчилгаа: **байхгүй**. Reklam ID: **ашиглахгүй**.

### 5.2 Apple: App Privacy («Nutrition label»)

«Data Linked to You» (хэрэглэгчтэй холбоотой), «Tracking» **үгүй**:

- Contact Info: нэр, утасны дугаар (App Functionality)
- User Content: Photos (гэрийн даалгаврын зураг, App Functionality)
- Other User Content / Usage: дүн, ирц (App Functionality)
- Identifiers: Device ID (push токен) нэмэгдэх үед, App Functionality

Tracking: үгүй. `NSUserTrackingUsageDescription` нэмэхгүй. ATT хүсэлт байхгүй.

### 5.3 Зөвшөөрлийн бичвэр (Info.plist, монгол)

- Камер: «Гэрийн даалгавар, онолын дэвтрийнхээ зургийг авч багшдаа илгээх, номын хуудсан дээрх QR кодыг унших үед камер хэрэгтэй. Камерын зураг хадгалагдахгүй.» Өмнө нь `NSCameraUsageDescription` түлхүүр хоёр удаа орсон байсныг нэгтгэв.
- Зургийн сан: «Утсандаа авсан дэвтрийн зургаа сонгож илгээхэд зургийн сан хэрэгтэй.»
- `ITSAppUsesNonExemptEncryption = false`, Google нэвтрэлтийн `CFBundleURLTypes` (`$(GOOGLE_REVERSED_CLIENT_ID)`, `ios/Flutter/GoogleSignIn.xcconfig`). Info.plist-ийг генератор буцааж дарвал эдгээрийг алдахгүй байхыг шалга (§1).

## 6. Скриншотын төлөвлөгөө

Дүрэм: том монгол гарчиг + **бодит** нэг дэлгэц. Mockup (утасны хүрээ зураг), stock зураг, зохиомол өгөгдөл хэрэглэхгүй. Дэвсгэр `#273F74` эсвэл цагаан, гарчгийн фонт Onest (Unbounded-д Ү, Ө байхгүй). Гарчгийн төгсгөлд цэг тавихгүй. Тестийн сангаас (локал хуулбар) авсан, бодит хүний нэр, утас харагдахгүй дэлгэц.

| № | Гарчиг (≤3 мөр) | Дэлгэц |
|---|---|---|
| 1 | Өнөөдрийн хичээл нэг дор | Сурагчийн нүүр |
| 2 | Даалгавраа зурагаар илгээ | Гэрийн даалгавар, зураг, PDF болгох |
| 3 | Шалгалт өгөөд дүнгээ шууд хар | Шалгалтын дэлгэц эсвэл дүн |
| 4 | Алдсан бодлогоо эргэн хар | Эргэн харах (бодолттой) |
| 5 | Ирц, төлбөр, мэдэгдэл | Эцэг эхийн 7 хоногийн тойм |
| 6 | Багшид хялбар | Багшийн ангийн самбар, ирц |

Хэмжээ: Play 1080x1920+ (9:16), 2-8 ширхэг. Apple: 6.9 инч (1320x2868), 6.5 инч (1284x2778), iPad 13 инч (хэрэв iPad дэмжвэл). Харанхуй горимын тусдаа дэлгэц шаардлагагүй. Эхлээд 1-5-г ав.

## 7. Эзний алхам [Э] ба lib/ хүсэлт

### 7.1 [Э] шаардлагатай

1. **Apple Developer Program** (байгууллага): D-U-N-S дугаар (Dun & Bradstreet, үнэгүй, 1-4 долоо хоног), Apple-ын баталгаажуулалт. Хувь хүнээр бүртгэвэл дэлгүүрт нэр нь хувь хүний нэр болно.
2. **Google Play Console** (байгууллага): D-U-N-S, баталгаажуулалт. Шинэ хувь хүний данс бол нийтлэхээс өмнө 12 тестер, 14 хоногийн хаалттай туршилт шаардагдана (байгууллага энэ шаардлагаас чөлөөтэй эсэхийг Play-ийн одоогийн дүрмээр шалга).
3. **Bundle ID батлах**: `mn.piemath.app` (Android `applicationId`, iOS bundle). Дэлгүүрт гарсны дараа **хэзээ ч солигдохгүй** (PROGRESS.md «Эзний шийдвэр» #1).
4. **Нууцлалын бодлогын нийтийн URL**: `pimath.mn/privacy` (одоо вэбд бий). Шинэ домэйн авбал URL солигдоно. Мөн «Бүртгэл устгах» хуудас.
5. **Firebase төсөл** (push): `google-services.json`, `GoogleService-Info.plist` (репод хийхгүй), APNs түлхүүр (Apple данс хэрэгтэй).
6. **Release гарын үсгийн түлхүүр**: Android upload key (`keytool`), `android/key.properties` (репод хийхгүй, нөөцөлж хадгал). Play App Signing идэвхжүүл. iOS: distribution certificate, provisioning profile.
7. Холбоо барих имэйл, утас, дэмжлэгийн хаяг (дэлгүүрийн хуудсанд ил харагдана).
8. Насны ангилал, зорилтот насны шийдвэр (§4). Apple review-д туршилтын данс (нэр, утас) бэлд: бодит сурагчийн мэдээлэл бүү өг.
9. Apple: апп дотор төлбөр байхгүй тул IAP шаардахгүй. Номын эрх нээх нь вэб/төвөөр гэдгийг review тэмдэглэлд тодорхой бич (App Review 3.1.3).
