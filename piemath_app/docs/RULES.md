# Эзний хатуу дүрэм — апп

Эдгээр нь эзний бодит залруулгаас гарсан. Зөрчвөл ажил хүчингүй. Вэбийн дүрмийн бүрэн жагсаалт `../../STATUS.md` §3, §6.

## 1. Нэршил (эзэн 2026-11-01) — ХАМГИЙН ЧУХАЛ

- Брэнд нь **ЗӨВХӨН** `Piemath`, эсвэл `Шинэ ирээдүйн эзэд` (мөн `Шинэ ирээдүй`). Өөр нэр болохгүй.
- **«Pimath» хэзээ ч зөв биш.** Хуучин код, вэбд алдаагаар бичигдсэн — апп-д бүү хуул.
- Апп-ын нэр (дэлгүүр, нүүр дэлгэц): `Piemath`. Дэд гарчиг/бичвэрт `Шинэ ирээдүйн эзэд`.
- **Үл хамаарах — зөвхөн техникийн хаяг:** домэйн `pimath.mn`, `api.pimath.mn` нь одоо ажиллаж буй сервер.
  Эзэн шинэ домэйн авах хүртэл URL-д хэвээр (`--dart-define`-ээр солигдоно). Хэрэглэгчид харагдах
  бичвэрт «pimath» гэж бүү бич.
- Bundle ID санал: `mn.piemath.app` — дэлгүүрт гарсны дараа ХЭЗЭЭ Ч солигдохгүй тул эхний store build-ээс
  өмнө эзнээр батлуул (`PROGRESS.md`-ийн «Эзний шийдвэр» хэсэгт бич).

## 2. Хэрэглэгч, хэл

- Бүх бичвэр **монголоор** (кирилл, Ү ү Ө ө). Файл бүр UTF-8.
- **ОРОС ХЭЛ ХЭЗЭЭ Ч БАЙХГҮЙ** (эзэн 2026-11-01). Орос үг, өгүүлбэр, орос хэллэг (и, в, на, это, для, уже, только,
  Ошибка, Загрузка, Сохранить, Назад, гарагийн орос нэр …) UI бичвэр, алдааны мессеж, баримт, commit мессежид
  ХОРИОТОЙ. Монгол үг байгаа бол орос зээлдэх үгийн оронд монголыг сонго. `test/no_russian_test.dart` нь `lib/`-ийн
  бүх мөр (string literal)-ийг орос үгийн жагсаалтаар шалгадаг байх ёстой (M0-д бич) — унавал засаад commit хий.
- Хэрэглэгчид гол төлөв **хүүхэд** (9–12-р анги, цаашид бүх насны математикийн сурагч). Энгийн, тайлбарласан,
  хүндэтгэлтэй өнгө аяс; айлгах, ичээх, буруутгах үг ХОРИОТОЙ. Техникийн үг («API», «server», «null», «error 500») харуулахгүй.
- Хэрэглэгчдийн бараг бүгд **имэйлгүй, зөвхөн утастай**. Нэвтрэлт = утас + нууц үг. Анхны нууц үг = утасны дугаар
  (эзний дүрэм) — «хүчтэй нууц үг» санал бүү болго. Сэргээх/солих үед үсэг+тоо холилдсон байх (`STATUS.md` §7.2).

## 3. Дизайн

- Өнгө: **үндсэн хөх + цагаан.** Логоны хар хөх `#273F74`-оос гаргана; зөөлөн цэнхэр `#AFC4EF`, тодотгол `#76B6F7`.
  **Шар/алтан өнгө ХОРИОТОЙ** («бөөлжис хүргэм»). Өнгөт дэвсгэртэй карт ХОРИОТОЙ («AI маягийн гутамшиг») —
  карт саарал/цагаан, өнгө зөвхөн төлөвийн дүрсэнд. «AI-аар хийсэн нь мэдэгдэх» загвараас зайлсхий.
- Өнгийг кодонд шууд бүү бич — `ThemeData` + `ThemeExtension` токен (вэбийн `bg-surface`, `text-ink`, `text-brand` …-тай
  ижил утгатай нэрс). Цагаан/хар горим; өгөгдмөл нь төхөөрөмжийнх.
- **Emoji, unicode глиф ХОРИОТОЙ** — зөвхөн Lucide дүрс (`lucide_icons_flutter` эсвэл вэбийн SVG-ээс). Тусгаарлагч цэг `·`, `•`
  тэмдэгтээр биш, 3px тойрог widget-ээр (вэбийн `Meta`/`Dot`-той адил).
- Гарчиг, товч, картын бичвэрийн **төгсгөлд цэг тавихгүй.**
- Логоны ард цагаан хайрцаг тавихгүй; хар горимд хар хувилбар.
- Тайлбар (legend) жагсаалтын ДООР. Хуудсан доорх илүү тайлбар бичвэр хэрэггүй; жижиг тайлбар олшруулахгүй — «i» дүрс.
- Фонт: Onest (бие) + Unbounded (том тоо/гарчиг) — `../../web/public/fonts`-оос апп-д багцлах. Google Fonts-оос
  ажиллах үед татахгүй.

## 4. Математик

- Математик бичвэр **ҮРГЭЛЖ LaTeX**-ээр зурна. `π`, `²`, `⅓`, `·`, `√` гэх мэт энгийн тэмдэгт ХЭЗЭЭ Ч болохгүй.
- Үржих тэмдэг зөвхөн `\cdot`; том хар цэг `•`/`\bullet` хэзээ ч үгүй.
- Хариуны A–E байрлал: нэг мөрөнд 5 багтвал зай нь тэнцүү, мөрөө дүүргэнэ; багтахгүй бол 3+2; ганц хариу өнчин үлдэхгүй.
  Зурагт «Томруулах», «Зөв» гэх мэт илүүц шошго бүү нэм.

## 5. Навигаци

- «Буцах» = **өмнөх** дэлгэц (шууд нүүр биш). Гаднаас (QR, push) нээсэн бол өмнөх байхгүй → нүүр.
- Утсан дээр доод таб; **таблет (≥768dp) дээр зүүн rail цэс.**
- Хэдхэн товшилтоор хүссэн хэсэг рүүгээ — гүн шаталсан цэс бүү хий.

## 6. Өгөгдөл ба сервер

- **Прод өгөгдөл (2026-10-23-ноос) ХЭЗЭЭ Ч устгахгүй, дарж бичихгүй.** «Устгах» бүр зөөлөн (`deletedAt`).
  Үл хамаарах: гэрийн даалгаврын зураг/PDF 7 хоног, нөхөх тэмдэглэлийн зураг 14 хоног (серверийн cron).
- Прод сан, прод сервер, эзний локал сан руу **ХЭЗЭЭ Ч бүү холбогд**. Туршилт: mock эсвэл өөрийн орчинд асаасан
  зохиомол өгөгдөлтэй API (`../../api/test/smoke/README.md`). Жинхэнэ сурагчийн нэр, утас коммитод бүү оруул.
- **Репо PUBLIC.** Нууц түлхүүр, `.env`, keystore, `google-services.json`, хувийн мэдээлэл ХЭЗЭЭ Ч commit хийхгүй.
- **AI runtime-гүй:** апп Claude/LLM API дуудахгүй. Тайлбар, бодолтыг урьдчилан санд хийсэн (`solutionOutline`).
- Бизнесийн дүрэм (оноо, эрх, бодолт нээгдэх, төлбөр) **үргэлж серверт.** Апп зөвхөн харуулна.
  Хариуны түлхүүр, `Problem.token` апп руу хэзээ ч ирэхгүй (`../../api/src/common/strip-problem-token.interceptor.ts`).
- Гараг: эзэн МОНГОЛ дугаарлалт (1=Даваа…7=Ням). Dart `DateTime.weekday` мөн 1=Даваа…7=Ням — гэхдээ API-ийн
  зарим талбар JS (0=Ням…6=Бямба)-аар ирдэг. Хөрвүүлэлт НЭГ функцэд, тесттэй.
- Цагийн бүс: Улаанбаатар (UTC+8). Огноог серверээс ISO-оор авч UB цагаар харуул (`STATUS.md` §8.9 урхи).
- Багш+ (`TEACHER_PLUS`) хүний нэрийн ард үргэлж «+». Тасалсан шалтгаанд «өвчтэй» сонголт байхгүй.
  Энгийн багш төлбөрийн нийт дүн, урт хугацааны санхүү харахгүй — зөвхөн сурагч тус бүрийн төлөв.
- Хэний ч эрхийг эзэн хэлэхгүй бол өөрчлөхгүй.

## 7. Хориотой хэллэг

- «Математик болон Нийгмийн ухаанд төвлөрсөн» — оронд нь «элсэлтийн шалгалтад бэлдэх + математикийн хоцрогдол арилгах танхимын сургалт».
- Е-баримт функц нэмэхгүй.
- Функц устгахгүй — «сайжруулах» нь юм хасах гэсэн үг биш.
