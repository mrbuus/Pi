# Анимацын слот — дизайнерт өгөх шаардлага

Апп дотор анимац тавих байрууд аль хэдийн бэлэн. Файл ирээгүй байрууд одоогийн дүрсээ харуулна.
Дизайнер файлаа энэ хавтсанд хуулахад **код өөрчлөхгүйгээр** тоглоно.

Судалгаа: `docs/RESEARCH-2026-11.md` §4. Код: `lib/shared/anim/`. Нэвтрэх hero: `docs/LOGIN-HERO.md`.

## Файлаа яаж нэмэх вэ

1. Слотын нэрээр файлаа энэ хавтсанд (`piemath_app/assets/anim/`) хуулна. Нэрийг `manifest.yaml`-д
   яг бичсэнээр нь (жижиг үсэг):

   | Файл | Заавал эсэх |
   |---|---|
   | `<слот>.json` | анимац тоглуулахад заавал |
   | `<слот>.poster.webp` | зөвлөнө: анимац ачаалах хүртэл, хөдөлгөөн багасгах горимд, хуучин утсанд харагдана |
   | `<слот>.dark.json` | заавал биш: харанхуй горимын хувилбар |
   | `<слот>.poster.dark.webp` | заавал биш: харанхуй горимын poster |

2. Шалгах:

   ```bash
   export PATH=~/Development/flutter-3.47/bin:$PATH
   cd piemath_app
   flutter test test/shared/anim/
   ```

   Тест файлын хэмжээ `max_kb`-аас хэтэрсэн эсэхийг шалгана. Хэтэрвэл файлаа жижигрүүл.
3. Апп-аа дахин build хийнэ. Файл устгавал одоогийн дүрс рүү буцна.

## Формат

- Lottie: Bodymovin JSON. Зөвхөн shape давхарга. Растер зураг, expression, mask, blur, glow, 3D
  **хориотой**. 40-өөс ихгүй давхарга.
- 30fps (нэг удаагийнх 24fps байж болно). Апп 30fps-ээр тоглуулна.
- Дөрвөлжин 512x512 вектор, захаас 40px аюулгүй зай. Hero 1280x720, гол зүйл голдоо.
- Poster: `.webp`, 40KB-аас ихгүй (hero-гийнх 150KB). Анимацын эхний кадр.
- Давталттай анимацын эхлэл, төгсгөл ижил байна (тасралтгүй давтагдана).
- Rive: скриптгүй. Rive сан апп-д хараахан нэмэгдээгүй (APK хэмжээг шалгасны дараа).
- MP4: H.264 main, дуугүй, faststart (`docs/LOGIN-HERO.md`).

## Хүлээлгэн өгөх

Слот бүрт: эх файл (After Effects, Figma г.м.), экспорт (`.json`), `poster.webp`, хар горимд `.dark` хувилбар.

## Апп хэрхэн тоглуулдаг

- Poster-ыг шууд харуулж, анимацын эхний кадр бэлэн болмогц 180мс-д зөөлөн солино.
- Хөдөлгөөн багасгах горим (iOS Reduce Motion, Android Remove animations) болон хуучин сул утсанд
  зөвхөн poster харагдана.
- Дэлгэц нуугдах, апп арын горимд орох үед зогсоно. Нэг удаад зөвхөн нэг давталттай анимац тоглоно.
- Утас тухайн анимацыг удаан зурвал (2 секундэд кадрын 15%-иас олон нь 16мс хэтэрвэл) тэр слот
  poster болж, дараагийн нээлтэд ч poster хэвээр үлдэнэ.
- Сүлжээнээс анимац татахгүй. Бүх файл апп-д багцлагдана.
