# Бодлогын агуулгын засвар 2026-10-24 — агентын гэрээ

Зорилго: «Бусад ном» (100x100 V2, 200x200 V2, 300x300)-ийн 108 эвдэрсэн бодлогыг ЭХ ФАЙЛААС зөв
болгож, сайт (pimath.mn) дээр цэвэр, алдаагүй харагдуулах. Та ӨС-д ЮУ Ч БИЧИХГҮЙ — зөвхөн JSON
засварын файл бэлдэнэ. Хэрэглэх нь `node prisma/apply-content-fix.cjs` (эзний session).

## Оролт
- `current/<бүлэг>.json` — бодлого бүрийн ОДООГИЙН утга (statementText, choices, correctAnswer,
  choiceOptions, imageKey, бүлгийн нэр). `before.statementText`-д эндээс ЯГ хуулна (нэг ч тэмдэгт өөрчлөхгүй).
- Эх файл (Word + PDF): `~/new future/100x100 V2/`, `~/new future/200x200 V2/`,
  `~/Desktop/Books/300x300 V2/`. Бүлгийн нэрээр файлаа ол (жишээ нь «Рациональ тэнцэтгэл биш 15» →
  `Рациональ-тэнцэтгэл-биш-15.docx/pdf`; токенд `-A-`/`-B-` = Тест N-A/B хувилбар, сүүлийн тоо = бодлогын №).
  `200V2-INT1-NN`, `200V2-TRIGEQ1-NN` — хувилбаргүй бүлэг: эх файлыг бүлгийн нэр, нөхцөлийн агуулгаар тааруулж ол.
- Хариуны түлхүүр: `~/new future/100x100 V2/100x100-тестийн-хариу-A.docx`, `-B.docx`,
  `~/new future/200x200 V2/200x200-тестийн-хариу-A,B.docx`, `~/Desktop/Books/300x300 V2/300x300-тестийн-хариу.docx`.
- PDF хуудсыг зураг болгож НҮДЭЭР харж тулга (PyMuPDF, 150–300dpi). Docx нь томьёонд тустай (pandoc/python-docx).

## Гаралт — `<бүлэг>.json` (энэ хавтсанд, JSON массив)
```json
{ "token": "100V2-RATINEQ-15-A-05",
  "source": "Рациональ-тэнцэтгэл-биш-15.pdf х.1 №5",
  "before": { "statementText": "<current-оос ЯГ>" },
  "format": "CHOICE",
  "statementText": "Дараах зурагт $f(x)$ функцийн график өгөгдөв. $\\frac{(x^{2} + x - 6) \\cdot f(x)}{x + 3} \\leq 0$ тэнцэтгэл бишийг бод.",
  "image": "fig/100V2-RATINEQ-15-A-05.png",
  "choices": [ {"text": "$]-\\infty; -3] \\cup \\{1\\}$"}, … 5 ширхэг ],
  "correct": "E",
  "answerSource": "existing",
  "notes": "" }
```
- `format`: "CHOICE" (5 сонголт, `correct` A–E) эсвэл "FILL_NUMBER" (`answer`: `{"a":"3","bc":"12"}` —
  түлхүүр нь нөхцөл дэх нүдний үсэг, утга нь яг тэр тооны цифр).
- `answerSource`: "existing" (одоогийн хариу зөв, хэвээр), "key" (албан хариуны файлаас — одоогийнх нь
  дутуу/«ANSWER_KEY_MISSING» байсан), "solved" (түлхүүр олдоогүй, өөрөө бодсон — `notes`-д бодолт).
  Одоо байгаа хариуг ӨӨРЧЛӨХГҮЙ. Түлхүүртэй зөрвөл хэвээр үлдээгээд `notes`-д «ТҮЛХҮҮР ЗӨРӨВ: …» гэж бич.
- `image`: нөхцөл зураг/график шаардах ба одоо `imageKey` null бол PDF-ээс тайрч
  `fig/<token>.png` (300dpi, цагаан дэвсгэр, захыг тайрсан, нөхцөл/сонголтын бичвэргүй) хадгал.
  Зураг хэвээр зөв бол `image` талбарыг огт бичихгүй. Сонголт нь график бол `choices[i].image` = `fig/<token>-A.png`.
  Зураг бүрийг өөрөө Read-ээр нээж шалга.

## Бичих дүрэм (эзний хатуу дүрэм)
1. Монгол үг `$…$`-ээс ГАДНА, бүх математик `$…$` ДОТОР LaTeX.
2. Юникод математик тэмдэг ХОРИОТОЙ (− × ÷ ≤ ≥ ≠ √ π ² · ∠ ° ∞ ∈ ∪ …) — `-`, `\times`, `\leq`, `\sqrt{}`,
   `\pi`, `^{2}`, `^{\circ}`, `\infty`, `\in`, `\cup`. 𝑥, 𝐀 мэт тусгай үсэг хориотой.
3. Үржих: ЗӨВХӨН `\cdot`. «•», `\bullet` ХЭЗЭЭ Ч үгүй.
4. «/1 оноо/», «(A).», «*\*», markdown `**` үлдэгдэлгүй; илүү хоосон зай, мөр таслалгүй (дэд асуулт бол `\n`).
5. Интервал: `]-\infty; 3]`, `[2; 5[` гэх мэт — хаалт хос байх албагүй, гэхдээ `\left`/`\right` бүү хэрэглэ.
6. Нөхөх нүд `\lbrack a\rbrack` эсвэл `[ab]` — эх дээрх яг тэр үсэг, тоогоор. Бүх нүд хадгалагдана.
7. Систем: `\left\{ \begin{array}{l} … \\ … \end{array} \right.`
8. Эх дээр байгаа үг/тоог өөрчлөхгүй; эх дээр алдаа байвал хэвээр хуулж `notes`-д бич.
