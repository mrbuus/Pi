## 2. Импортыг саатуулах зүйлс
1. **RATINEQ-13-т хариуны түлхүүр байхгүй** (A ч, B ч). Мөн:
   - 02, 03, 05, 07, 08-р бодлогын сонголт зөвхөн зураг хэлбэртэй.
   - 09 ба 10-р бодлогын агуулга холилдсон.
2. **Зураг хадгалах байнгын газар байхгүй.** Render free нь deploy бүрт дискээ цэвэрлэдэг.
3. **B түлхүүрт үсгийн алдаа:** «Тест 6-A» гэж бичигдсэн, 6-B байх ёстой (Иррациональ тэгшитгэл).

## 3. Одоогийн прод (V2) дээр мөн байж болзошгүй алдаа
`reimport-latex.cjs`-ийн логикийг V3-т ажиллуулахад 268 бодлогын томьёо эвдэрсэн. V2-ийн прод өгөгдөлд ч ижил эвдрэл байх магадлалтай. Засвар a–h:
- a. `\{ \}` тэмдэгтийг хаалт гэж тоолдог.
- b. `\right.`-ийн цэгийг устгадаг.
- c. Интервалын `\left/\right` хос сонголтуудын хооронд тасардаг (хамгийн түгээмэл, ~200 бодлого).
- d. `\leqx` болж нийлдэг.
- e. Төгсгөлд ганц `\` үлддэг.
- f. «Амжилт хүсье!» гэсэн үг 92 бодлогод наалддаг.
- g. `⤇` тэмдэгтийг `\Rightarrow` болгох шаардлагатай.
- h. `"- 3"` гэж хуваагдсан тоог `$-3$` болгох.
