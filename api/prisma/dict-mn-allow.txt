# Зөв бичгийн шалгагчийн ЦАГААН ЖАГСААЛТ (dict-mn толинд байхгүй ч ЗӨВ үгс)
#
# Толь нь ~620,000 үндэстэй ч бүрэн гүйцэд БИШ. Монгол хэл нөхцөл залгавартай
# тул ховор хэлбэр байхгүй байж болно; мөн ХҮНИЙ НЭР, газар нутгийн нэр, гадаад
# үг, нэр томьёо нь угаасаа толинд байдаггүй. Бодлогын нөхцөлд «Бат 5 алим авав»
# гэх мэт нэр байнга орно — тэдгээрийг алдаа гэж тэмдэглэвэл шалгагч ашиггүй
# болж, багш нар дохиог сонсохоо больдог (alert fatigue).
#
# Нэг мөрөнд нэг үг. `#`-ээр эхэлсэн мөр тайлбар.
