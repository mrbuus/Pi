# Pi.mn v2 — Шинэ Ирээдүйн Эзэд

Өмнөх Pi.mn-ээс тусгаарласан, локал дээр туршиж хянах хувилбар. Жинхэнэ хэрэглэгчийн болон санхүүгийн өгөгдөл оруулаагүй. GitHub/main болон үйлдвэрлэлийн үйлчилгээнд өөрчлөлт хийгээгүй.

- [Асаах заавар](docs/v2/RUN-LOCAL.md)
- [Хийсэн ажил, тест, үлдсэн хязгаар](docs/v2/VALIDATION.md)
- [57 ажлын хяналтын жагсаалт](docs/v2/TASK-LIST.md)
- [Интернетгүй уншиж, тэмдэглэх хуудас](docs/v2/REVIEW.html)
- [Дараагийн хөгжүүлэлтийн даалгавар](docs/v2/MASTER-PROMPT.md)
- [Нэмсэн судалгааны тайлбар](docs/v2/RESEARCH-EXTENSION.md)

Вэб: http://localhost:3381. API: http://localhost:3380/api. Нэг командаар асаах: `./start.sh --production` (эхлээд API ба вэб build хийнэ). Зохиомол зургаан эрхийн account мэдээлэл зөвхөн ignored `.runtime/accounts.json` дотор.

Төвийн шинэ онлайн элсэлт хаалттай; бие даан ном/тестээр суралцах боломж тусдаа. Амжилтын баталсан бодит зургийг кодын тохиргоонд нэмнэ; тусдаа upload удирдлагагүй. Provider, бүх номын агуулгын шалгалт, элсэлт/цалин, cloud ачаалал, OCR болон урт хугацааны сургалтын үр нөлөө баталгаажаагүй тул энэ хувилбарыг үйлдвэрлэлийн бэлэн бүтээгдэхүүн гэж үзэхгүй.
